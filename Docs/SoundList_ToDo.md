# SteamAttack 사운드 제작 목록 (남은 것)

작성: 2026-10-28 · 기준: NGH 브랜치

이미 연결된 소리(아래 "연결 완료" 참고)를 뺀, **새로 만들거나 구해야 하는 사운드** 목록입니다.
파일을 구하면 `Assets/Prefabs/NGH/Resources/NGH_SfxLibrary.asset`(효과음 모음)에 칸을 추가해 연결하는 방식으로 붙이면 됩니다.

- 우선순위: ★★★ 바로 체감 큼 / ★★ 있으면 좋음 / ★ 나중에
- 형식 권장: 효과음 wav 44.1kHz 모노, 한 파일에 한 소리(여러 번 친 소리를 한 파일에 몰아 넣지 않기), 변형 2~4개
