## BHS — 보스

### B-1. 🔴 다리 수와 BossHealth 기준을 맞춰 주세요 (보스 처치 불가)
| | |
|---|---|
| **지금** | `BHS_Boss` 프리팹의 다리(`BossWallHealth`)는 **2개**(`BossWall`, `BossWall (1)`), `BossHealth`는 `WallCount = 4` 고정 |
| **문제** | 다리 2개를 다 부숴도 코어가 안 열림 → 보스 HP가 줄지 않아 **잡을 수 없음**. 보스 체력바도 처음부터 2칸이 깨져 보임 |
| **요청** | 다리 몇 개로 갈지는 BHS가 정함(회의 2.2). 정한 수와 코드 기준만 같게. 추천: `WallCount` 상수 대신 `GetComponentsInChildren<BossWallHealth>(true).Length`로 실제 다리 수를 세기 |
| **확인 방법** | Main 씬 `Merge_TestArea/BHS_BossZone` 켜고 Play → 다리 전부 파괴 → 코어 공격 시 HP 감소·사망 |
| **상세** | 노션 이슈 "현무 보스 다리 2개 vs BossHealth 4개 기준 — 보스 처치 불가" |
| **상태** | 대기 |

| **요청** | 예) 4개면 `Leg_0_FL`, `Leg_1_FR`, `Leg_2_BL`, `Leg_3_BR` / 2개면 `Leg_0_L`, `Leg_1_R` |
| **상태** | 대기 |

### B-3. 🟢 보스 공략 구조가 정해지면 NMJ에 알려 주세요

|---|---|

## YPH — 공용 플레이어 · 화승총 · 받아치기

### Y-1. 🔴 화승총 증기를 회의 결정대로: 발사 1회 = 증기 5
| | |
|---|---|
| **회의 결정** | 발사 시 증기 소모(임시 **5**), 명중해도 회복 없음 (회의 1.3, 2.1) |
| **지금** | `SteamGun`은 쏠 때가 아니라 **R로 탄 주머니를 채울 때** 증기를 냄 (1발당 1, 주머니 10발) |
| **영향** | NMJ 증기 HUD는 회의 기준으로 "남은 발 수 = 증기 ÷ 5"를 보여 줌 → 지금은 화면 숫자와 실제로 쏠 수 있는 횟수가 다름 |
| **상태** | 대기 |

### Y-2. 🟠 새 받아치기 코드에서 "성공" 신호를 보내 주세요
| | |
|---|---|
| **이유** | 받아치기 성공 → 적 경직 → 강공격 기회(회의 1.3). 그 순간 HUD의 強 글자를 붉게 빛나게 해서 "지금 강공격"을 알려 줌 |
| **지금** | NGH의 `PlayerParry.ParryAttempted` 이벤트를 듣고 있음 |
| **요청** | 패링을 새로 만들면 둘 중 하나: ① 같은 이벤트(성공 여부 포함)를 유지 ② 성공 시 `NMJ.SteamCylinderGauge.FlashStrongChance(경직 시간)` 한 줄 호출 |
| **상태** | 대기 |

### Y-3. 🟢 공용 플레이어 무기 칸 이름을 정식 이름으로
| | |
|---|---|
| **지금** | `YPH_HeroPlayerIntegration` 무기 칸: "환도", "**테스트 원거리(락온 불가 확인용)**" |
| **요청** | "화승총"으로 변경 (HUD는 이름 대신 무기 종류로 刀/銃을 표시해서 급하지는 않음) |
| **상태** | 대기 |

### Y-4. 🟢 공용 플레이어 프리팹에 NMJ가 붙인 것 — 수정할 때 유지해 주세요
| | |

| **내용** | `NMJ.InkHealthBar`(붓글씨 체력바), `NMJ.SteamCylinderGauge`(증기·무기 HUD) 추가 / NGH의 `chg_PlayerHUD`는 **꺼 둠** (NMJ HUD로 대체) |

| **상태** | 알림 |

## NGH — 플레이어 · 시간 역행 · 연출

### N-1. 🔴 시간 역행 증기 비용이 0으로 되어 있어요
| | |
|---|---|
| **지금** | 공용 플레이어의 `TimeRewind` 증기 비용 = **0** (스크립트 기본값은 70) |
| **회의·기획** | 시간 역행 = 증기 70 (기획 v4 3-2) |
| **요청** | 프리팹 값을 70으로. 테스트 때문에 0으로 둔 거라면 알려 주세요 (HUD 逆 눈금은 70 기준) |
| **상태** | 대기 |

### N-2. 🔴 받아치기 증기 규칙을 회의 결정대로
| | |
|---|---|
| **지금** | 공용 플레이어 `PlayerParry`: 시도할 때 증기 **10**, 성공하면 **+20**, 쿨타임 2초 |
| **회의 결정** | 성공해도 증기 회복 **없음**, 추가 소모 없음, **화승총 발사 비용(5)만** (회의 1.3). 실패 시 증기 차감은 기능만 만들고 미적용 |
| **참고** | 회의에서 패링은 YPH가 다시 만들기로 함(회의 1.2). 재구현 전까지 지금 코드의 값만이라도 맞춰 주면 좋음 |
| **상태** | 대기 |

### N-3. 🔴 강공격이 증기 30을 쓰도록
| | |
|---|---|
| **회의 결정** | 강공격 = 증기 소모형(임시 **30**) + 선딜. 특수 기술·과열은 따로 만들지 않고 강공격에 통합 (회의 1.3) |
| **지금** | 강공격(좌+우 클릭)이 증기를 쓰지 않음 |
| **요청** | 증기가 30 미만이면 강공격 불가(또는 약화). HUD 強 눈금이 이 기준 |
| **상태** | 대기 — 담당이 NGH/YPH 중 누구인지 회의에서 확인 필요 |

### N-4. 🟠 시간 역행 화면 필터를 황금색 → 청색으로
| | |
|---|---|
| **대상** | `NGH/TimeRewinder/RewindScreenTint.cs` |
| **이유** | 오방색에서 **청 = 시간**. 황은 어명·신핵 색 (`YPH.ObangColors.Cheong`) |
| **상태** | 대기 |

### N-5. 🟠 왼쪽 위 디버그 글자가 겹쳐요
| | |
|---|---|
| **지금** | `TimeRewind`의 디버그 표시(`showDebugGUI = true`)와 NMJ 퀘스트 디버그 키 안내가 화면 왼쪽 위 같은 자리에 겹쳐 찍힘 |
| **요청** | 기본은 끄고 키로 켜기 (NMJ 쪽도 같은 방식으로 바꿀 예정). 시연·녹화 화면에 나오지 않게 |
| **상태** | 대기 |

### N-6. 🟠 ESC 키가 겹쳐요 — 조작 안내 ↔ ESC 메뉴
| | |
|---|---|
| **지금** | `ControlsOverlay`가 ESC로 조작 안내 이미지를 열고 게임을 멈춤 |
| **회의 결정** | ESC = 인게임 메뉴(타이틀로 / 환경 설정 / 게임 종료), 열면 일시정지 (회의 1.6) |
| **제안** | ESC 메뉴 안에 "조작법" 버튼을 두고 거기서 지금의 조작 안내 이미지를 띄우기. ESC 메뉴 구현 담당이 정해지면 같이 정리 |
| **상태** | 협의 필요 |

### N-7. 🟢 사망 연출 · 재시작
| | |
|---|---|
| **회의 결정** | 종이가 타듯 군데군데 사라지는 소멸 셰이더(NGH 시도, 어려우면 다른 방식) (회의 1.7) |
| **요청** | 재시작 방식(자동/수동, 부활 위치)은 NMJ가 정해서 따로 요청 예정. 시연용 체크포인트·불러오기는 만들지 않기로 함 (회의 1.8) |
| **상태** | 보류 — NMJ 결정 대기 |
