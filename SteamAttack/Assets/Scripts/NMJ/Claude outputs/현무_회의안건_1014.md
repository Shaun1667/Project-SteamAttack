## 안건 1. 받아치기(패링) 무기 — 권총이냐 화승총이냐  ★ 가장 먼저

| | 내용 |
|---|---|
| 현황 | 코드(`NGH/Player/PlayerParry.cs`)는 **왼쪽 허리 권총 빨리뽑기**, 패링 피해 5. 기획 v3는 권총을 빼고 **등의 화승총으로 받아치기**(사격과 겸용) |
| 결정할 것 | 시연 빌드에서 받아치기를 어떤 무기로 보여줄지 |
| 선택지 | **A.** 기획대로 화승총 — 권총 모델·뽑기 동작 삭제, 받아치기 동작을 화승총으로 교체 / **B.** 코드대로 권총 유지 — 기획서·세계관을 권총으로 되돌림 / **C.** 동작은 권총 그대로, 설정상 이름만 바꿈 |
| 영향 | 애니메이션(NGH), 캐릭터 장비 모델(YPH), 세계관 법칙 7, 예상 Q&A |
| NMJ 제안 | 남은 기간을 생각하면 **B 또는 C**. 동심원 UI·판정은 그대로 쓸 수 있으므로 무엇을 고르든 UI는 바뀌지 않는다 |

## 안건 2. 사망·재시작 규칙

| | 내용 |
|---|---|
| 현황 | `GameOverScreen`: 어디서 죽든 Game Over 이미지 → 아무 키 → **그 자리에서** 다시 시작. 기획 v3: 길은 제자리 체력 50%, 현무전은 보스전 처음부터, 현무에게 2번 지면 현무 체력 30% 깎고 시작 |
| 결정할 것 | 시연 빌드의 사망 규칙, Game Over 화면 디자인 |
| 선택지 | **A.** 기획 v3대로 분기 / **B.** 지금처럼 어디서나 제자리 부활 (가장 단순) / **C.** B + 시연자 무적 키(F10)로 대신 |
| NMJ 제안 | 5분 시연은 끊기지 않는 게 우선이라 **B + C**도 충분. 다만 보스 체력은 처음으로 돌리지 않는다 |

## 안건 3. 현무 다리 — 한 대에 한 칸?

| | 내용 |
|---|---|
| 현황 | BHS 보스: 다리(`BossWallHealth`) 4개, 각 체력 20. 4개 다 깨지면 코어 노출 → 본체 체력. NMJ 체력바 1페이즈는 **다리 4칸**, 맞을 때마다 칸이 줄고 다 비면 자물쇠가 풀림 |
| 결정할 것 | 다리 하나를 깨는 데 몇 번 맞아야 하는지, 무엇으로 깨지는지 |
| 선택지 | **A.** 한 대 = 한 칸 (다리 체력을 한 방 피해 이하로) / **B.** 몇 대 맞아야 깨짐 (지금처럼, 칸이 조금씩 줄어듦) / **C.** **증기발도로만** 깨짐 (기획 v3: "가갑은 증기발도로만 부서진다") |
| 함께 정할 것 | 다리 오브젝트 이름에 번호 붙이기 (`Leg_0_FL`, `Leg_1_FR`, `Leg_2_BL`, `Leg_3_BR`) — 체력바 칸 순서 |
| NMJ 제안 | 기획과 맞추려면 **C**. 시간이 부족하면 A |

## 안건 4. 현무 2페이즈와 신핵 QTE 범위

| | 내용 |
|---|---|
| 현황 | 체력바 2페이즈, 신핵 QTE 모두 **보류**. 체력바 1페이즈는 다리가 다 깨지면 `OnAllLegsBroken` 이벤트를 보내도록 만들어 둠 |
| 결정할 것 | ① 2페이즈를 시연에 넣는가 ② 넣는다면 마무리를 QTE로 하는가 ③ BHS의 "코어"를 신핵으로 쓰는가 |
| QTE 세부 | 키 순서 F → Z → 좌클릭 → Q, 단계당 2초, 실패 시 1단계부터. 입력 방식: 한 번 누르기 / 연타 / 길게 누르기 중 선택 |
| 선택지 | **A.** 1페이즈만 + 다리 다 깨지면 바로 엔딩 / **B.** 1·2페이즈 + 체력 0이면 엔딩 (QTE 없음) / **C.** 1·2페이즈 + 신핵 QTE (기획 v3 전체) |
| NMJ 제안 | 10/24 동결을 지키려면 **B**. QTE는 시간이 남으면 추가 |
