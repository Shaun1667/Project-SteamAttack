## 1. 길 — Main 맵 위의 동선

Main 맵에 이미 있는 배치(좌표는 씬 기준)를 그대로 쓰고, 남쪽에서 북쪽으로 **한 방향으로만** 올라간다. **맵의 큰 틀은 유지하고 내부 배치·동선만 보완한다** (회의 1.5).

```
 북 ↑
 [건청궁 (0, 137)] ······ 오프닝 컷씬만 (플레이하지 않음)
        :
 [향원정 (0, 104)] ─ 안개문 → 보스 아레나 씬 로드      ④
        │
 [근정전 마당 (0, 35~56)] ─ 얼어붙은 품계석 사이, 잡몹 소규모   ③-2
        │
 [광화문 (0, -40)] ─ 얼음 문 → 깨지면 궁 안으로
 [해태 앞 (0, -58)] ─ 포졸 무리 (중간보스 보류)                ③
        │
 [육조거리 (0, -60 ~ -111)] ─ 관아 사이 큰길, 잡몹 + 첫 받아치기 ②
 [시작 (0, -111)] ─ 버려진 수레 옆
 남 ↓
```

| 구간 | Main 맵의 실제 위치 | 길이 | 활용하는 기존 오브젝트 |
|---|---|---|---|
| ① 오프닝 | 건청궁 (0, 137), 시점 표식 `시점_어명의 순간` | 컷씬 | 조선 최초의 전등, 전기등소 발전기(씬 오브젝트 이름 `물불 증기 발전기`), `어명의 순간` 인물 |
| ② 육조거리 | z −111 → −60, 폭 약 40m | 약 50m | 6조 관아, 버려진 수레, 괘서, 얼어붙은 백성 |
| ③ 광화문 앞 | 해태 사이 (0, −58), 시점 `시점_광화문과 백동수` | 반경 15m | 광화문, 해태 2기 (**백동수는 제외** — 씬의 `백검 백동수` 인물 배치는 숨김) |
| ③-2 궁 안 | 광화문 (0, −40) → 근정전 마당 → 향원정 | 약 140m | 어도(御道), 근정전, 품계석, 동·서행각 |
| ④ 향원정 | 연못 앞 (0, 약 85) | — | 향원정, 연못 물안개 → **안개문 트리거** |

- **뒤로 못 가게:** 시작 지점 남쪽은 쓰러진 수레와 얼음벽으로 막는다. 광화문은 얼음으로 닫아 두고, 광화문 앞 포졸 무리를 모두 쓰러뜨리면 얼음이 깨지며 문이 열린다.
- **운종가·삼청동 기기창·흑수회 제단**은 배경으로만 둔다(길에서 멀리 보이게).
- **보이지 않는 벽:** 육조거리 관아 사이, 궁 안 행각 바깥을 투명 콜라이더로 막아 길에서 벗어나지 않게 한다.
- **길 막기·바위·소품 배치는 기능 구현 이후** 세부 작업으로 한다 (회의 1.5).
- **맵 모델 정리:** Blender에서 지형과 개별 오브젝트를 분리한 뒤 다시 가져온다 (회의 1.5).
- 이동 거리는 시작부터 안개문까지 약 250m다. 달리면 40초 안쪽이라 시연 시간 대부분이 전투에 쓰인다.

## 2. 5분 흐름표

| 시간 | 구간 | 일어나는 일 | 보여줄 것 |
|---|---|---|---|
| 0:00~0:20 | ① 오프닝 | 자막 "고종 24년(1887) 봄, 경복궁 건청궁" → 전등 점화 → 발전기 폭주 → 멈춘 눈송이 → 고종의 어명 → 육조거리로 화면 전환 | 세계관 한 번에, **시연의 시작** |

| 2:40~4:40 | ④ 현무 | 안개문 → 아레나 로드 → **1페이즈**(공략 구조는 4-3) → *(2페이즈: 1페이즈 완성 후 결정)* | 보스전, **시간 역행으로 피하기** |
| 4:40~5:00 | 엔딩 | **보스 처치 문구** → 해빙, 눈이 다시 떨어짐 → **엔딩 크레딧** | **시연의 끝** |

- **시간 역행은 체력 회복과 회피 둘 다에 쓴다.** 현무에게 **시간 역행으로만 피할 수 있는 공격·필살기**를 하나 두고, 그 직전에 "피할 수 없다 — 되감아라 (Q)" 안내로 한 번에 배우게 한다. 어떤 공격을 쓸지, 몇 페이즈에 둘지는 **미정(BHS)**.
- 그 전에 광화문 앞에서 체력이 절반 아래로 떨어지면 화면 가장자리에 "Q"를 한 번 띄워 미리 보여준다.
- 회복약이 없으므로 **체력을 되찾는 방법은 시간 역행 하나뿐**이다.

### 3-2. 핵심 수치

수치 뒤 *(임시)* 는 회의에서 정한 임시값, **미정** 은 아직 안 정한 값이다.

| 시스템 | 값 |
|---|---|
| 플레이어 | 체력 100, 공격력 10 |
| 칼 일반 공격 | 적중 시 증기 회복 — 회복량 **미정** (자원 수급·강공격·총 사용 빈도를 보고 결정) |
| 강공격 | 증기 **30** *(임시)* 소모, 선딜 있음. 피해량·선딜 세부 수치 **미정** (사용 빈도·패링 후 연계 테스트로 조정) |
| 화승총 사격 | 우클릭 조준 → 좌클릭 발사. 히트스캔 25m. 발사 1회 증기 **5** *(임시)*. 명중해도 회복 없음 |
| 받아치기(패링) | CTRL. 판정 폭 기본 **±1초** *(임시, 테스트 후 조정)*. 대상: 일반 적 강공격 · 보스 일부 공격 |
| 받아치기 성공 | 적 공격 무효 + **적 경직**(경직 중 강공격 기회). 경직 시간 **미정** (강공격을 안정적으로 넣을 시간). 시각 이펙트·효과음 피드백. 증기 회복·추가 소모 없음 (화승총 발사 비용은 따로 듦) |
| 받아치기 실패 | 정상 피해. 실패 유형 구분 없음. 실패 시 증기 차감은 기능만 만들고 **현재 플레이에는 적용 안 함** |
| 증기 | 최대 100. 얻기: 칼 일반 공격 적중. 쓰기: 강공격, 화승총 발사(사격·받아치기), 시간 역행 |
| 시간 역행 | Q, 5초 전으로, 증기 −70. 위치·방향·체력만 되돌리고 **증기는 되돌리지 않음**. 연출 0.8초 동안 무적 |

- **받아치기 보상은 경직과 강공격 기회뿐이다.** 약점 노출, 다음 공격 피해 증가 같은 별도 보상은 넣지 않는다.
- 근거리·원거리 받아치기는 **하나의 시스템, 같은 규칙**으로 만든다 (회의 1.2).
- 증기가 화승총 발사 비용보다 적으면 사격과 받아치기를 쓸 수 없다 (v3 규칙 유지, 수치만 변경).
- 받아치기 가능한 공격에는 **예고 표시를 유지**한다.

## 4. 적과 보스

### 4-1. 길 위의 적 (2종)

| 적 | 체력 | 공격 | 받아치기 가능한 공격 | 배치 |
|---|---|---|---|---|
| 근접 — 창을 쓰는 변이 포졸 | 50 | 창 찌르기 10 | **강공격 15** (예고 표시) | 육조거리 3, 광화문 앞 3, 궁 안 2(선택) |
| 원거리 — 흑수회 궁수 | 40 | 화살 8, 2.5초 간격 | 없음 | 육조거리 1 (관아 지붕 위), 광화문 앞 1 (해태 뒤) |

- 기본 공격 패턴으로 구성하고, **쓸 수 있는 기존 모델·모션**을 쓴다 (회의 1.5).
- **일반 적 AI와 받아치기·적 공통 인터페이스는 YPH**가 만든다. 적 AI의 기존 호출 방식은 유지한다 (회의 1.2).
- 일반 적 에셋(애니메이션·의상 Cloth 문제, 멘토 자료, 에셋 구매·도구)은 후속 확인 (회의 2.3).
- Main 맵의 `13_인물 / 변이병`, `흑수회 광신도` 배치 위치를 스폰 위치 후보로 쓴다.

### 4-2. 광화문 앞 — 얼음 문 (중간보스 보류)

| 항목 | 내용 |
|---|---|
| 구성 | 포졸 3 + 궁수 1이 얼음으로 봉해진 광화문을 등지고 선다 |
| 역할 | **받아치기 → 경직 → 강공격**을 여러 번 반복해 손에 익히는 자리. 칼 공격으로 증기를 모아 강공격에 쓰는 흐름을 익힌다 |
| 끝 | 마지막 한 명이 쓰러지면 얼음 문이 깨지고 "한 호흡에, 한 점에" 자막 |
| 중간보스 | 채택 여부는 **후속 회의**에서 결정 (회의 2.3). 채택하면 이 구간을 1분 결투로 바꾸고 동선·얼음 문·자막 위치는 그대로 쓴다 |

### 4-3. 최종보스 — 현무 (보스 아레나 씬, 2분)

**1페이즈를 먼저 완성한다** (회의 1.1). 공략 구조와 세부 패턴은 BHS가 정한다.

| 항목 | 내용 | 결정 |
|---|---|---|
| 기본 패턴 | **돌진 · 근접 내려찍기 · 브레스** | 확정 (회의 1.4) |
| 추가 패턴 | 원거리·광역 패턴 — 공격 형태·범위, 낙하·추적·분산 방식 | 미정(BHS) |
| 공략 구조 | 다리·무릎을 공략하면 넘어지는 관계, 코어 공격과 총기 사용 연계 | 미정(BHS) |
| 시간 역행 전용 공격 | 시간 역행으로만 피할 수 있는 공격·필살기. 구성·연계, 회피 타이밍 | 미정(BHS) |
| 받아치기 | 보스 **일부** 공격만 받아칠 수 있고, 받아칠 수 있는 공격은 예고 표시 | 확정 (회의 1.3, 1.4) |

- 보스 패턴의 **속도·범위는 인스펙터에서 조정**할 수 있게 만든다.
- 돌진 애니메이션 연결: 측면 개방 → 로켓 전개 → 수납. 기존 애니메이션 연결 문제도 보완한다.
- 피격 판정 태그는 **공통 보스 태그**로 정리한다 (BHS).
- 보스방 규모는 보스 모델을 배치한 뒤 크기·활동 공간을 확인한다 (회의 2.3).

- **현재 구현과의 차이 (이슈):** BHS 보스 코드는 다리(`BossWallHealth`) 4개가 부서져야 코어를 열지만, `BHS_Boss` 프리팹의 다리는 2개라 보스를 잡을 수 없다. 공략 구조를 정할 때 다리 수와 코드 기준을 맞춰야 한다. 보스 체력바는 다리 수에 맞춰 칸을 조정한다 (NMJ).

## 7. 완료 체크리스트

1. 육조거리 시작부터 엔딩까지 씬 전환 1번(안개문)으로 이어진다.
2. 시연자가 5분 ± 30초 안에 3회 연속 끝낸다.
3. 육조거리에서 받아치기를 반드시 한 번 본다.
4. 받아치기 성공 → 적 경직 → 강공격이 이어진다.
5. 칼 일반 공격으로 증기가 차고, 강공격·화승총·시간 역행이 증기를 쓴다.
6. 시간 역행으로만 피할 수 있는 현무 공격을 시간 역행으로 넘길 수 있다.
7. 현무 1페이즈를 공략해 잡을 수 있고, 처치 문구와 엔딩 크레딧이 나온다.
8. 사망해도 흐름이 끊기지 않는다 (재시작 방식은 NMJ 결정대로).
9. 길에서 벗어나거나 되돌아갈 수 없다.
10. 타이틀·ESC 메뉴·환경 설정이 동작하고, ESC 메뉴를 열면 게임이 멈춘다.
11. 개발자 창에서 보스전 등 지정 구간으로 바로 이동할 수 있다.

### 회의록만으로 정해지지 않아 확인이 필요한 것

- **시간 역행 증기 −70:** 회의에서 다루지 않아 v3 값을 남겼다. 증기 회복이 칼 일반 공격뿐이라 너무 무거울 수 있다 → 칼 적중 회복량과 같이 정한다.
- **받아치기 쿨타임 2초:** 회의에서 다루지 않아 v3 값을 남겼다.
- **"근거리·원거리 패링"의 뜻:** 근거리 공격·원거리 공격(화살)을 모두 받아친다는 뜻인지, 같은 시스템이라는 뜻인지 확인 필요. 지금은 패링 대상(일반 적 강공격·보스 일부 공격)을 따라 궁수 화살은 받아칠 수 없게 두었다.
- **"한 호흡에, 한 점에" 자막:** v3에서는 증기발도를 예고하는 자막이었다. 증기발도가 빠졌으니 유지할지 정한다.
