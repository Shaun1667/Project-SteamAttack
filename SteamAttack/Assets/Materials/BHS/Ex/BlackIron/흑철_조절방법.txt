현무 흑철 테두리 조절 — SteamAttack

Assets/Materials/BHS/Ex/BlackIron/Materials 폴더에서 *_EdgeIron 머티리얼을 선택하세요.
등껍질은 BHS_material_0_EdgeIron입니다. 여러 머티리얼을 함께 선택해 일괄 조절할 수 있습니다.

Black Iron Controls
- Iron Color: 선택된 흑철 영역의 색 배율. 흰색은 원래 색 유지. HDR Intensity로 밝기를 조절할 수 있습니다.
- Iron Metallic: 금속성. 현재 대부분 0.78 (기존 값이 더 높은 코어 주변은 유지).
- Iron Smoothness: 반사의 선명도/매끈함. 현재 대부분 0.52. 높이면 날카로운 광택, 낮추면 거친 금속.
- Mask Preview (0 = Off): 1로 올리면 적용 영역을 흑백으로 확인. 확인 후 0으로 복구.
- Panel Protection Mask (Black = Iron): 판 보호용 마스크. 그래프에서 반전해 테두리를 선택하고 깊은 그림자와 발광 영역을 추가로 제외합니다.

색은 유지하고 광택만 바꾸려면 Iron Smoothness부터 조절하세요.
Original Surface의 Color / Original Metallic / Smoothness는 전체 기본 표면 값이므로 흑철만 바꿀 때는 Iron 항목을 사용하세요.

범위
ProjectMad2의 기존 마스크 18장을 동일한 원본 텍스처인지 검증한 뒤 복사해 사용했습니다.
원본 텍스처 색과 어둡기에 기반한 마스크라 세부 경계 일부는 부드럽게 섞입니다.
Shader Graph에서 모서리/테두리 쪽을 선택하도록 반전하고 그림자·눈·코어 발광 부분을 보호했습니다.
각 부위에 정확히 원하는 경계가 더 있으면 해당 부위 마스크를 수작업으로 다듬을 수 있습니다.

구성
Shaders: HyunMuEdgeIron.shadergraph 1개 (URP Lit Shader Graph, C#/HLSL 스크립트 추가 없음)
Textures: 기존 판 영역 마스크 사본 18개 (1024 / 선형 / BC4)
Materials: 현재 SteamAttack 설정에서 복사한 조절용 머티리얼 18개
현무 프리팹의 렌더러 82곳에 연결했습니다. 원본 머티리얼 및 모델 파일은 보존했습니다.
눈/코어의 Emission Map과 _EmissionColor 이름을 유지해 기존 전조·사망 발광 제어와 연결됩니다.

이 폴더는 원본 Base Map/Normal Map/Emission Map과 프로젝트 URP 설정에 의존합니다.
다른 프로젝트로 옮길 때는 해당 텍스처도 함께 포함하거나 Export Package > Include dependencies를 사용하세요.
원복하려면 각 렌더러에 기존 BHS_HyunMu_Materials 또는 Effect_Materials의 원본 머티리얼을 다시 연결하면 됩니다.
