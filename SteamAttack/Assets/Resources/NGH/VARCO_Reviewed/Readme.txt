# 검수 완료 사운드와 자동 재생

검수에서 채택된 WAV만 포함합니다. 같은 소리의 이전 채택본은 최신 채택본으로 대체했습니다. AcceptedManifest.csv에는 파일과 원본 SHA-256이 있습니다.

ReviewedAudio가 Resources에서 파일을 찾아 이동, 행동, 피격, 역행, 증기, 적 공격, 현무 패턴, 퀘스트, 대화, 일시정지와 월드 이벤트에 재생합니다. 적이 플레이어를 인지하는 동안 선택된 전투 BGM을 재생하고, 이전 배경음을 일시 정지했다가 전투 후 재개합니다. 최신 검수에서 채택된 가벼운 피격음과 다크 판타지 타이틀 음악도 각각의 재생 지점에 연결했습니다.

주의: 눈/돌 발소리와 벽 타격은 콜라이더 이름을 사용해 구분합니다. 돌에는 stone 또는 박석, 벽에는 wall 또는 벽이 이름에 포함되어야 합니다. 바람은 지정된 월드 씬에서 재생하고 등불·마을 소리는 VARCO_PR_Cheongsachorong, VARCO_PR_TorchStand, VARCO_PR_Jumak 이름의 오브젝트에 근접 음원으로 붙습니다. 다른 이름이나 동적 생성 시에는 연결 확인이 필요합니다.

원래 연결된 소리는 삭제하지 않았으므로 실제 씬에서 소리가 중복되는지, 피격·발소리 동기화, 음악 전환·반복 연결, 볼륨을 확인하세요. Unity의 실제 임포트 및 게임 플레이 테스트는 별도 확인이 필요합니다.
