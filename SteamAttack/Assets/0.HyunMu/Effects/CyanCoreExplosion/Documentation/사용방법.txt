청록 코어 폭발 — Cyan Core Explosion
=================================

하늘색에 가까운 청록색 불길, 흰회색 연기, 금속 파편이 한 방향으로 분출되는 이펙트입니다.
일반 골렘/보스 모델이나 게임 전투 시스템 없이도 단독으로 재생됩니다.

필요 환경
---------
Unity 6 + Universal Render Pipeline(URP).
제작/확인 환경: Unity 6000.3.23f1, URP 17.3.0.
Built-in/HDRP 프로젝트에는 그대로 호환되지 않습니다.
새 프로젝트라면 Universal 3D(URP) 템플릿을 사용하세요.

다른 프로젝트로 가져오기
-----------------------
1. 옮길 프로젝트를 Unity로 엽니다.
2. Assets > Import Package > Custom Package... 메뉴에서
   CyanCoreExplosion_URP.unitypackage를 선택하고 Import를 누릅니다.
3. Assets/Effects/CyanCoreExplosion 폴더가 생깁니다.

폴더로 옮길 때는 CyanCoreExplosion 폴더 전체와 모든 .meta 파일을 함께 복사하세요.
프리팹 파일 하나만 복사하면 재질/셰이더/스크립트 연결이 끊어집니다.
URP 패키지는 Unity Package Manager로 별도 설치하는 프로젝트 의존성입니다.

가장 쉽게 확인하기
------------------
1. Demo/CyanCoreExplosion_Demo.unity를 엽니다.
2. Play 버튼을 누르면 약 3.6초 간격으로 반복 재생됩니다.
3. 일회성 이펙트만 쓰려면 Prefabs/CyanCoreExplosion.prefab을 씬으로 드래그하고 Play를 누르세요.
   프리팹은 1회 재생된 후 약 3.2초에 스스로 사라집니다.

내 오브젝트에서 원하는 순간에 재생하기
--------------------------------------
1. 발사 위치에 빈 GameObject를 만들고 Cyan Core Explosion Spawner 컴포넌트를 추가합니다.
2. Effect Prefab 칸에 Prefabs/CyanCoreExplosion.prefab을 넣습니다.
3. Emission Point에 원하는 발사 위치 Transform을 넣습니다. 비워 두면 자기 위치를 씁니다.
4. 파란색 Z축 화살표가 불을 뿜을 방향입니다. 오브젝트를 회전해 방향을 정합니다.
5. Effect Scale로 크기를 조정합니다. 1은 기본, 1.65는 기존 보스 크기입니다.
6. 시작할 때 자동 재생하려면 Play On Start를 켭니다.
   전투 이벤트 등에 연결할 때는 Play On Start와 Repeat For Preview를 끕니다.
7. UnityEvent에서 CyanCoreExplosionSpawner.PlayEffect()를 연결하거나,
   같은 GameObject의 애니메이션 이벤트에서 PlayEffect를 호출하면 재생됩니다.
   체력/사망 판정 자체는 사용하는 게임에서 연결해야 합니다.

폴더 구성
---------
Prefabs        : 실제로 사용하는 완성 이펙트
Materials      : 불길, 빛, 연기, 금속 파편 재질
Meshes         : 금속 파편 모양
Shaders        : 불길/연기 표현용 URP 셰이더
Scripts        : 자동 재생/빛 감소/정리, 재사용용 재생 컴포넌트
Demo           : 다른 게임 파일이 필요 없는 독립 예제 씬
Documentation  : 이 설명서

Scripts/LabCoreExplosionBurst.cs의 MadLab 이름은 기존 네임스페이스일 뿐입니다.
이 스크립트는 UnityEngine만 사용하며 ProjectMad의 전투/체력 스크립트가 필요하지 않습니다.
현재 게임의 사망 연결 스크립트는 이 묶음에 포함하지 않습니다.

주의
----
Time.timeScale이 0이면 이펙트와 미리보기 반복도 일시정지됩니다.
효과음은 포함되어 있지 않습니다.
이 패키지는 이펙트 파일만 포함하며 캐릭터, 건물, 음악, 프로젝트 설정을 포함하지 않습니다.
