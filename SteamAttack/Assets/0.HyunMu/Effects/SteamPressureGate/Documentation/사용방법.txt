고압 증기 차단문 / Steam Pressure Gate
Unity 6000.3.23f1 / URP 17.3에서 확인
제작일: 2026-10-27

구리 배관과 여섯 개의 압력 노즐이 흰 회색 증기를 분사해 통로를 가립니다.
노즐 주변은 뜨거운 주황색이며 압력계 바늘과 밸브가 상태에 따라 움직입니다.
증기와 열기 표현은 직접 작성한 절차적 셰이더와 Unity 파티클을 사용합니다.

사용:
- Prefabs/SteamPressureGate.prefab을 씬에 놓습니다.
- 원점은 문 아래 중앙이며 X축이 가로, Y축이 높이입니다.
- 기본 차단 폭 4.6m / 높이 3.6m입니다.
- 문 전체 크기는 루트 Transform의 Scale로 조절하세요.
- Play 시 Start Locked 설정에 따라 압력이 켜집니다.
- SetLocked(true) / Lock(): 증기 분사와 충돌을 켭니다.
- SetLocked(false) / Unlock(): 즉시 충돌을 해제하고 분사를 멈춥니다.
- 분사가 멎은 후 남은 증기는 약 1.65초 안에 흩어집니다.
- 비활성화하면 증기를 정리하고, 다시 켜면 기존 잠금 상태를 유지합니다.
- Time.timeScale=0이면 증기와 압력계 변화도 함께 멈춥니다.
- 단독 효과에는 피해 기능이 없으며 통행을 막는 BoxCollider만 있습니다.
- 컴포넌트의 컨텍스트 메뉴에서 Pressurize / Lock, Release steam / Unlock을 시험할 수 있습니다.

독립 데모:
Demo/SteamPressureGate_Demo.unity를 열고 Play를 누르세요.
Hierarchy의 SteamPressureGate에서 Lock/Unlock을 실행할 수 있습니다.

다른 프로젝트:
SteamPressureGate_URP.unitypackage를 가져오거나 이 폴더 전체를 .meta와 함께 복사하세요.
이 폴더 밖의 게임 에셋/스크립트는 필요하지 않습니다.
URP용입니다. Built-in/HDRP에서는 셰이더 변환이 필요합니다.
