파란 나선 레이저 문 / Blue Helix Laser Gate
작성: 2026-10-27
확인 환경: Unity 6000.3.23f1 / Universal Render Pipeline 17.3

1. 바로 사용하기
- Prefabs/BlueHelixLaserGate.prefab을 Hierarchy로 드래그합니다.
- 원점은 문 아래 중앙입니다. 가로는 로컬 X, 높이는 로컬 Y입니다.
- 다섯 줄의 레이저가 가로로 뻗고, 각 직선 주위에 나선이 회전합니다.
- 기본 폭 4.6m, 차단 높이 3.6m입니다.
- 전체 문 크기는 프리팹 루트 Transform의 Scale X/Y/Z로 조절하세요.
  크기를 함께 바꾸면 레이저, 발사구, 충돌 영역이 함께 변합니다.
- 시작하면 켜진 상태입니다. Start Locked를 끄면 열린 상태로 시작합니다.

2. 열고 닫기
- BlueHelixLaserGate.Unlock() 또는 SetLocked(false): 충돌을 즉시 해제하고 빛을 약 0.22초 동안 소멸합니다.
- BlueHelixLaserGate.Lock() 또는 SetLocked(true): 충돌을 켜고 빛이 돌아옵니다.
- UnityEvent에서도 Lock / Unlock을 연결할 수 있습니다.
- Play Mode에서 컴포넌트 우측 메뉴의 Lock gate / Unlock gate로 시험할 수 있습니다.
- 전체 GameObject를 껐다 켜면 현재 잠금 상태를 유지합니다.
- 이 효과에는 공격/피해 기능이 없습니다. BoxCollider로 통행만 차단합니다.

3. 모양 조정
- Helix Radius: 나선 반지름
- Helix Turns: 한 줄에 감기는 횟수
- Rotations Per Second: 나선 회전 속도
- Fade Seconds: 켜짐/꺼짐 전환 시간
- Beam Length는 내부 선 길이입니다. 발사구와 충돌 영역까지 바꾸려면 위 안내대로 전체 Scale을 사용하세요.
- Materials/BlueLaserCore.mat: 중심 레이저 색
- Materials/BlueLaserSpiral.mat: 나선 색
- 카메라 방향에 맞춰 보이는 두 LineRenderer가 각 줄을 구성합니다.
- 일시정지(Time.timeScale = 0) 시 나선 회전과 소멸도 멈춥니다.

4. 독립 데모
Demo/BlueHelixLaserGate_Demo.unity를 열고 Play를 누르세요.
원래 게임의 캐릭터/몬스터/게임 매니저 없이 레이저 문만 표시합니다.
Hierarchy의 BlueHelixLaserGate에서 Lock gate / Unlock gate로 동작을 확인하세요.

5. 다른 프로젝트로 이동
BlueHelixLaserGate_URP.unitypackage를 가져오거나
Assets/Effects/BlueHelixLaserGate 폴더 전체를 .meta 파일과 함께 복사하세요.
이 폴더 외의 Game 에셋은 필요하지 않습니다.
URP가 설치된 프로젝트에서 사용하세요. Built-in/HDRP는 별도 셰이더 변환이 필요합니다.

6. ProjectMad2 연결
게임 연결은 Assets/Game/Scripts/Managers/LabExitDoor.cs에 있습니다.
기존 일반 적과 보스 처치 조건을 그대로 사용합니다.
잠김: 레이저와 충돌 켜짐 / 상태등 파랑
열림: 레이저 소멸, 충돌 해제 / 상태등 초록
기존 철판은 씬에 남겨 두고 렌더러와 충돌을 껐습니다.
다른 프로젝트에서는 이 게임 연결 스크립트를 가져올 필요가 없습니다.

검증:
- 게임 내 12개 동작 점검 통과: 회전, 일시정지, 캐릭터 차단, 보스 처치 전/후 잠금,
  레이저 소멸, 캐릭터 통과, 클리어, 메뉴 재시작.
- 테스트의 적 처치는 체력 API로 실행했습니다.

독립 데모 추가 검증: 게임 매니저 없이 구동, 잠금 해제, 비활성 후 재활성, 다시 잠금까지 4개 점검 통과. 전체 16개 점검 통과.
