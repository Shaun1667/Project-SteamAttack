재사용 지면 충격파 / TurtleShockwave

1. 사용 환경
Unity 6 + Universal Render Pipeline의 3D Universal Renderer에서 검증했습니다.
Built-in, HDRP, URP 2D Renderer용 셰이더는 포함하지 않습니다.
외부 모델, 현무 공격 코드, 데미지 시스템에 의존하지 않는 시각 효과입니다.

2. 배치와 재생
Prefabs/TurtleShockwave 프리팹을 원하는 위치에 놓고 Play를 누르면 1회 재생합니다.
Loop를 켜면 Repeat Delay 간격으로 반복합니다.
비활성화했다가 다시 활성화하면 재생하며, 같은 메시와 렌더러를 재사용합니다.
실행 중 컴포넌트 메뉴의 Play / Stop으로 수동 재생할 수도 있습니다.
다른 게임 코드에서 ReusableGroundShockwave.Play(), PlayAt(worldPosition), Stop()을 호출할 수 있습니다.
인스펙터의 Play On Enable을 끄면 자동 재생하지 않습니다.

3. 조절
Radius: 최종 반경 / Speed: 퍼지는 속도 / Width: 파동 띠의 폭 (모두 월드 단위)
Crest Height: 압력막이 솟는 높이 / Refraction Strength: 바닥이 휘어 보이는 강도
Rim Width: 밝은 테두리 두께 / Color: 테두리 색과 전체 불투명도
Ground Mask: 바닥으로 사용할 레이어만 선택할 수 있습니다.
Probe Height, Probe Depth: 위/아래 지면 탐색 거리입니다.
콜라이더가 있는 경사면은 높이를 따라갑니다. 콜라이더가 없으면 배치 높이의 평면에서 재생합니다.
기본 지면 탐색은 Trigger와 Rigidbody가 달린 콜라이더를 제외합니다.
지면은 재생 시작 시 샘플링하므로 진행 중 움직이거나 변형된 지형은 다음 재생에서 반영됩니다.
Transform Scale 대신 Radius/Width/Crest Height로 크기를 조절하세요.

4. 굴절 방식
바닥 원본 메시나 Terrain을 실제로 변경하지 않습니다.
별도의 압력막 메시가 솟고, 카메라에 보이는 불투명 배경을 굴절시켜 바닥이 늘어나 보이게 합니다.
Auto Configure Game Cameras는 실행 중 Game 카메라의 Opaque/Depth Texture를 켜고
재생 종료 시 기존 옵션으로 복원합니다. URP 에셋 설정을 변경하지 않습니다.
투명 물체, 별도의 Overlay 카메라 구성, XR은 프로젝트별로 확인이 필요합니다.
굴절을 끄려면 Refraction Strength를 0으로 설정하세요.
이 효과 자체에는 콜라이더/피해 판정이 없습니다.

5. 다른 프로젝트로 이동
Exports/TurtleShockwave_URP.unitypackage를 Import하면 프리팹/머티리얼/셰이더/스크립트가 함께 이동합니다.
탐색기로 복사할 경우 아래 폴더와 파일의 .meta까지 함께 복사해야 합니다.
- Assets/0.HyunMu/Effects/TurtleShockwave 전체
- Assets/0.HyunMu/ExScripts/ReusableGroundShockwave.cs 와 .meta
현무 원본 전체나 공격 스크립트는 복사할 필요가 없습니다.

6. 현무 연결
ProjectMad2의 BossAreaAttack은 기존 판정의 안쪽/바깥쪽 반경을 RenderWave에 전달합니다.
공격별 새로운 생성 없이 캐시한 프리팹을 재활성화합니다.
데미지와 공격 타이밍은 기존 공격이 담당하며, 이 프리팹은 해당 반경을 표시합니다.
