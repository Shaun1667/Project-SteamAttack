# Laser Scorch Sweep — 재사용 가능한 시각 효과

푸른 나선 레이저가 포신 끝에서 한 번 훑고, 바닥 흔적이 1.25초 뒤 전체적으로 동시에 폭발합니다. 큰 각진 돌과 다각형 균열은 제거했으며, 불규칙한 그을음·약한 잔열·회색 연기와 미세한 재로 표현합니다.
체력·피해량·대상 탐색·피격 판정은 포함하지 않습니다. 가져가는 프로젝트의 전투 시스템에서 처리하면 됩니다.

## 재생
Demo/LaserScorchSweep_Demo.unity를 열고 Unity 상단 Play(▶)를 눌러 Game 창에서 봅니다.
Auto replay (demo only)가 켜져 있으면 연출과 잔흔 정리가 끝나고 1초 뒤 다시 재생합니다.
한 번씩 보려면 Auto replay를 끄고, 종료 후 Replay one sweep을 누릅니다.
현재 연출은 끝까지 진행합니다. 체력 표적과 체력 UI는 제거했습니다.

## 다른 프로젝트에서 사용
URP 프로젝트에 이 폴더 또는 LaserScorchSweep_URP.unitypackage를 가져옵니다.
Prefabs/LaserScorchSweepAttack.prefab을 씬 또는 포탑의 자식으로 배치합니다. 포탑 모형은 데모 씬에 있습니다.

- 루트의 +Z가 부채꼴 중심입니다. 루트를 바닥 높이에 둡니다.
- Muzzle: 회전하는 포신의 자식 Transform을 포신 끝에 만들어 연결합니다. 데모는 AimingHead/BarrelTip입니다.
- Aiming Head는 선택 사항이며 연결하면 레이저 접촉 지점을 향해 회전합니다.
- ScorchHelixBeam은 중심광을 따라 BlueHelixLaserGate 스타일의 푸른 나선을 표시합니다.
- 재사용 프리팹의 Play On Start는 꺼져 있고 데모에서만 켜져 있습니다.
- Fire()로 한 번 재생합니다. 진행 중이거나 바닥/필수 참조가 없으면 false를 반환합니다. IsBusy가 false일 때 다시 호출할 수 있습니다.
- Cancel() 또는 비활성화는 연출과 예약된 폭발을 취소합니다.
- 자동 반복은 데모 UI에서만 제공하며, 각 연출은 한쪽 끝에서 반대 끝으로 한 번만 훑습니다.
- Ground Mask에는 바닥 레이어만 포함하세요. 바닥 Collider는 흔적을 지면 높이에 맞추는 용도입니다. 기본값은 Ignore Raycast 레이어를 제외합니다.
- 바닥 메시를 실제로 파괴하지 않고 부드러운 그을음 메시와 파티클로 흔적을 표현합니다.
- 발사 시 지면을 샘플링하므로 이후 포탑이 움직여도 흔적은 제자리에 남습니다.

기본값: 각도 95도 / 반경 7m / 쓸기 1.65초 / 대기 1.25초 / 전체 동시 폭발 / 33개 지점 / 흔적 너비 1.15m / 잔흔 정리 3초.
Time.timeScale=0에서 연출과 데모 자동 재생이 멈춥니다.

## 외부 시스템 연결 (선택 사항)
On Detonated 이벤트는 전체 폭발이 시작될 때 한 번 호출됩니다.
Inspector에서 기존 프로젝트의 메서드를 연결하거나 코드에서 OnDetonated.AddListener(...)로 구독할 수 있습니다.
이벤트를 연결하지 않아도 시각 효과는 정상 재생되며 이벤트 자체는 피해를 계산하지 않습니다.
폭발 이전에 Cancel()을 호출하면 이벤트도 발생하지 않습니다.
GroundSampleCount와 TryGetSample(index, out point)로 현재 흔적의 지면 좌표를 읽을 수 있습니다.

## 호환성
Unity 6000.3.23f1 / URP 17.3에서 검증했습니다. Built-in/HDRP 전용 셰이더는 포함하지 않습니다.
BlueHelixLaserGate의 셰이더와 재질을 이 폴더 안에 독립 복사했으므로 원본 게이트 폴더나 현재 게임의 코드 없이 가져갈 수 있습니다.

## 반복 재생과 자원 재사용
효과 컴포넌트가 시작될 때 지면 메시 1개와 폭발용 파티클 3개(연기·섬광·미세한 재)를 한 번 준비합니다. 기본 설정에서는 33개 위치를 따라 적은 수의 파티클들을 고르게 동시에 방출합니다. 별도의 큰 돌 메시나 파편 GameObject는 만들지 않습니다.
연출이 끝나면 저장된 오브젝트를 비활성화하고 파티클을 비웁니다. 다음 연출은 같은 오브젝트·메시·좌표 배열·삼각형 버퍼를 재사용합니다. 리소스 해제는 효과를 가진 오브젝트가 파괴되거나 씬이 닫힐 때 수행합니다.
기본 33개 지점에서 지면 메시는 99개 정점·128개 삼각형입니다. 지면 높이 검사용 Raycast와 파티클 렌더링 비용은 남아 있으므로 많은 포탑을 동시에 사용할 때는 대상 기기에서 별도로 성능을 확인하세요.
ScorchGroundExplosion 프리팹을 단독으로 배치하면 한 번 재생 후 비활성화됩니다. 다시 활성화하면 같은 인스턴스로 재생됩니다. 포탑 연출 안에서는 공유 방출기로 자동 관리됩니다.

연기가 바닥을 만나는 경계는 깊이 텍스처를 사용해 부드럽게 처리합니다. 데모 카메라에는 Depth Texture를 켜 두었습니다. 다른 프로젝트에서도 같은 경계 처리가 필요하면 카메라 또는 URP Asset의 Depth Texture를 켜세요.
