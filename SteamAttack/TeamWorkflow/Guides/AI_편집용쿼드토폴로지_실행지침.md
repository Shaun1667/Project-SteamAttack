# AI 실행 지침: 정돈된 편집용 쿼드 토폴로지

너는 기존 3D 캐릭터의 리토폴로지를 수행하는 AI 작업자다. 사용자가 이 문서를 따라 작업하라고 요청하면 아래 절차를 실제 모델에 적용하라. 설명이나 계획서 작성만으로 요청을 끝내지 마라.

이 문서를 작성·수정·검토하는 요청만 받았다면 모델을 수정하지 마라. 사용자에게 승인받은 대상과 범위 안에서 실행하고, 최신 사용자 지시를 우선하라. 이 파일을 전역 AGENTS.md나 자동 실행 훅으로 설치하지 마라.

**실행 순서: 기준 확인 → 원본 위의 루프 설계 → 대표 부위의 작은 패치 검증 → 검증된 방식으로 확장 → 면 수 확정 → UV·재질 이전 → 최종 검사.**

작은 패치는 귀 한쪽, 손가락과 손바닥의 연결부처럼 따로 검사할 수 있는 국소 메시다. 처음부터 전체 캐릭터를 자동으로 맞춘 뒤 결함을 고치는 방식으로 시작하지 마라. 아래 초기 검증을 통과한 증거가 없으면 전체 제작으로 넘어가지 마라.

## 목표와 작업 원칙

**원본의 형태를 유지하면서, 주요 부위의 모서리 줄을 선택해 수정하기 쉽고 실제 변형에도 견디는 전체 쿼드 메시를 만들어라.**

- 얼굴·몸·의상의 디자인을 새로 만들지 마라. 원본 위에 작업 메시를 만들어 연결을 다시 설계하는 것은 허용하되, 원본과 다른 얼굴·비율·실루엣으로 바꾸지 마라.
- 원본 보존, 편집성, 형태, 변형, 면 수 예산을 모두 요구 조건으로 취급하라. 하나를 맞추려고 다른 조건을 조용히 포기하지 마라.
- 먼저 형태와 굽힘 방향에 맞는 루프를 설계하고, 그 사이를 쿼드로 연결하라. 사각형 개수는 결과를 검사하는 항목이지 루프 설계를 대신하는 목표가 아니다.
- 모든 면이 같은 크기일 필요는 없다. 곡률·변형이 큰 곳에 밀도를 배분하고, 가려지거나 평평한 곳은 성기게 유지하라.
- 3개·5개 등의 모서리가 모이는 정점인 폴은 계획적으로 사용하라. 폴을 전부 없애려 하지 말고, 필요한 이유와 위치를 설명할 수 있게 하라.
- 단계별 통과는 네가 증거로 판정하는 자체 검사다. 이미 승인된 범위의 일반 작업마다 사용자에게 승인을 다시 요구하지 마라.
- 목표 면 수는 처음부터 배분하되, 원본 형태에 맞추기 전에 정확한 총개수를 고정하지 마라. 아직 맞추지 않은 템플릿을 목표 개수까지 줄이는 것을 진척으로 세지 마라.
- 진행률은 시도 횟수·렌더 수·스크립트 수 대신 **검사를 통과한 부위**로 판단하라. 작은 부위를 완성할 수 없는 방법으로 큰 부위를 계속 처리하지 마라.

## 시작 입력 확인

사용자 메시지와 현재 장면에서 아래 정보를 먼저 확보하라. 이미 답한 질문을 반복하지 마라. 파일이나 범위가 실제로 모호하고 확인 없이는 안전하게 작업할 수 없을 때만 질문하라.

| 입력 | 확인할 내용 |
|---|---|
| 기준 파일·장면 | 실제 열린 파일, 저장되지 않은 변경, 사용할 원본과 과거 백업의 차이 |
| 대상 | 수정할 오브젝트 이름. 목록에 없는 부품은 수정하지 않기 |
| 면 수 | 쿼드인지 삼각형인지, 한쪽당인지 합계인지, 정확한 개수인지 상한·근삿값인지 |
| 보존할 형태 | 얼굴 비율, 관절 위치, 목 접합, 실루엣, 구멍·슬릿, 큰 장식 |
| 우선 부위 | 정밀 편집·변형이 필요한 영역과 가려져도 되는 영역 |
| 기존 데이터 | UV·재질·이미지·리그·웨이트·Shape Key·모디파이어·대칭·스케일 |
| 검증할 움직임 | 눈 감기, 입 벌리기, 팔꿈치·손가락·목·발목 굽힘 등 대상에 필요한 동작 |
| 산출 범위 | 편집용 .blend, UV·텍스처 이전, FBX 내보내기, Unity 검증 중 요청된 범위 |

현재 장면과 접근 가능한 도구를 실제로 조회하라. 사용할 수 없는 UI 조작이나 수작업을 수행했다고 말하지 마라. 연결이 끊기면 원인을 확인하고, 백업 사본을 별도 프로세스에서 처리할 수 있는지 판단하라. 디스크 파일만 수정했다면 현재 Blender 창에 반영했다고 보고하지 마라.

## 전체 작업 전에 반드시 통과할 초기 검증

### 도구와 원본의 적합성

- 사용할 기능이 실제 설치되어 있고 호출되는지 작은 사본에서 확인하라. 실행 전 입력 조건과 실패 출력을 확인하고, 사각형 생성 기능을 곧바로 편집용 리토폴로지 기능으로 간주하지 마라.
- 각 대상의 열린 경계·겹친 면·고립 조각·법선 방향을 먼저 분류하라. 허용된 목 경계와 실제 찢어진 면을 구별하라. 원본에 이미 있던 결함과 작업 중 새로 생긴 결함을 따로 기록하라.
- 원본의 눈·입이 닫힌 표면인지, 안구·구강·손가락 사이·장식 구멍이 실제로 있는지 확인하라. 외부 템플릿의 구조가 원본과 다르면 그대로 투영하지 마라. 새 안구·구강 제작이 필요하다면 기존 리토폴로지와 다른 범위임을 먼저 밝히고 그 범위만 확인하라.
- 좌표계·단위·오브젝트 스케일·음수 스케일을 기록하라. 목 등 공유 경계는 기존 대응을 우선 보존한다. 바꿀 이유가 있으면 두 부품의 대응과 검사 방법부터 정하라.

### 대표 패치 시험

대상마다 실패 위험이 큰 부위를 먼저 고르되, 같은 종류의 방식은 한쪽에서 먼저 증명하라.

| 대상 | 초기 시험 부위 | 통과해야 할 위험 |
|---|---|---|
| Head | 한쪽 귀의 앞뒤·머리 연결부, 입꼬리와 입술 경계 | 얇은 면의 앞뒤가 붙지 않음, 입술 대응 순서와 얼굴 윤곽 유지 |
| Body | 손가락 뿌리·사이와 관절, 팔꿈치 | 다른 손가락으로 투영되지 않음, 관절 고리 유지, 굽힘 시 접힘·관통 없음 |
| Boots | 한쪽 발목과 인접 장식·가죽 경계 | 발목 흐름, 장식 테두리·구멍·두께, 서로 다른 굽힘 방식 유지 |

1. 원본에서 경계·주요 굴곡·관절 위치를 측정하고 패치에 대응시켜라. 눈대중으로 추정한 좌표는 추정이라고 표시하고 검증 전 전체 변형의 고정점으로 쓰지 마라.
2. 원본 위에 몇 줄의 쿼드를 직접 연결해라. 외부 베이스 메시를 쓰려면 그 패치의 앞뒤·경계·랜드마크(눈꼬리·관절 같은 기준점)가 원본과 대응함을 먼저 보여라. 패치 합격 전에는 전신 템플릿 맞춤이나 전체 자동 감량을 실행하지 마라.
3. **연결 → 표면 맞춤 → 양방향 형태 검사 → 루프 이동·복구 → 필요한 작은 굽힘 → UV 시험**까지 해당 패치에서 실행하라. UV 시험은 체크무늬와 작은 색상 이전으로 가능성을 확인하는 단계이며 최종 베이크를 반복하는 단계가 아니다.
4. 얇은 패치는 앞뒤와 단면을 함께 확인하라. 넓은 외곽선만 맞고 내부가 겹쳤으면 실패다. 검사 과정에서 만든 임시 경계는 허용 목록에 적고 실제 조립 때 어떻게 이을지 정하라.

패치의 경계·참조 표면·최대 이동량·형태 오차 허용치를 실행 전에 짧게 기록하라. 허용치는 원본 크기·최종 카메라·부위 중요도에 근거하고 모든 모델에 같은 mm 값을 쓰지 마라. 초과 결과에 맞춰 허용치를 넓히지 마라. 화면에서 보이는 형태 손실이나 새 관통은 작은 평균 오차로 허용하지 마라.

**통과 증거:** 원본과 같은 시점의 패치 전후·와이어, 선택·이동·복구와 굽힘 결과, 양방향 거리와 최대 오차 위치, 경계·교차 판정, UV 시험 결과. 하나라도 실패하면 해당 방법을 전체 모델에 확장하지 마라.

### 재시도와 시간 사용

아래 숫자는 성공을 보장하는 시간이 아니라, 실패한 방식을 오래 반복하지 않기 위한 기본 점검 기준이다. 사용자 지정 시간·범위가 있으면 그것을 우선한다.

- 한 결함에는 **최초 시도와 원인이 확인된 수정 1회**까지 시험하라. 같은 결함이 남으면 그 방법을 중단하고 마지막 정상 패치로 돌아가 대응 표면이나 연결 구조를 바꿔라. Seed·가중치·평활화 횟수·스크립트 파일명만 바꾸는 것은 새 방법이 아니다.
- 재시도 전에 `관찰한 실패 → 원인 가설과 근거 → 바꿀 요소 → 좋아져야 할 지표 → 실제 결과`를 한 줄로 남겨라. 원인 없이 새 보정기를 추가하지 마라.
- 전체 작업 시작 후 **15분 시점에 합격한 대표 패치가 없으면** 전체 작업 확대를 멈추고 실패 원인과 방식 변경을 사용자에게 알린다. **30분까지도 하나도 통과하지 못하면** 같은 자동 실험을 계속하지 마라. 근거가 있는 다른 실행 경로가 있는지 판단하고, 없다면 원본·후보·제약을 보존해 수행 한계를 보고하라. 시간이 지났다는 이유로 품질 조건을 낮추거나 완료로 처리하지 마라.
- 경과 시간은 실제 시계나 실행 로그로 확인하라. 파일 수정 시각만으로 계산 시간·사용자 대기 시간·실패 원인을 단정하지 마라. 이미 통과한 패치를 확장하는 작업에 위 시간을 일률적인 전체 작업 제한으로 적용하지 마라.
- 장시간 계산은 작업 단계·진행 상태를 확인할 수 있게 실행하라. 취소할 때는 직접 시작한 작업 프로세스를 식별하고, 사용자의 Blender 창이나 다른 작업을 종료하지 마라.
- 보정 시도는 마지막 합격 사본에서 재현 가능하게 시작하고 불합격 결과 위에 변형을 계속 누적하지 마라. 검사 통과 전 전체 장면 저장·고해상도 렌더·전체 베이크를 반복하지 마라. 해당 패치와 필요한 비교 뷰만 우선 저장한다.

## 금지할 대체 작업

다음 결과를 정돈된 편집용 리토폴로지의 완성본으로 제출하지 마라.

- `Decimate → 인접 삼각형을 두 개씩 묶기 → 개수 맞추기`만 수행한 메시.
- 자동 QuadriFlow·Voxel Remesh 결과를 루프 설계·편집·변형 검사 없이 채택한 메시.
- 목표 숫자를 맞추기 위해 임의의 면에 Inset·Subdivide를 반복해 면을 늘린 메시.
- 긴 삼각형 두 개를 합쳐 만든 비틀린 쿼드, 큰 구멍을 한 정점에서 부채꼴로 메운 연결.
- Shade Smooth·노멀 맵·조명·텍스처로 잘못된 연결이나 찌그러짐을 가린 결과.
- UV 문제를 피하기 위해 모든 면을 낱장 UV로 분리한 결과.
- 렌더 한 장이나 `모든 면이 쿼드`, `구멍 0개` 검사만으로 완료를 주장하는 결과.
- 외부 인체 템플릿을 원본에 전역 변형·최근접 투영한 뒤, 부위별 대응 검증 없이 채택한 결과.
- 오목한 면 수나 후보→원본 거리만 줄인 것을 형태 보존·자기교차 해결로 간주한 결과.

자동 도구는 보조로 사용할 수 있다. 다만 결과가 아래의 구조·편집·형태·변형 검사를 모두 통과해야 한다. 도구가 목표 루프를 만들지 못하면 해당 부위를 직접 다시 연결하라. 같은 자동 알고리즘의 숫자와 Seed만 바꿔 무작정 반복하지 마라.

## 실행 순서

### 1. 원본 보존과 현재 상태 기록

1. 작업 전 장면을 별도 .blend로 저장하라. 사용자 원본을 덮어쓰지 마라.
2. 대상의 면·정점·연결 성분·경계, UV·재질, 변형 데이터, 오브젝트 변환을 기록하라. 연결이 없는 장식과 실제로 찢어진 경계를 구분하라.
3. 원본 참조와 작업 메시를 분리하라. 원본의 좌표·재질·UV를 유지하고, 작업용 데이터 수정이 공유 데이터 때문에 원본에 전파되지 않는지 확인하라.
4. 정면·뒤·좌우·네 대각선의 기준 캡처를 저장하라. 중요한 얇은 장식과 접합부는 확대 캡처도 남겨라.

**통과 조건:** 복구 가능한 백업이 있고 대상·기준 형태·예산 단위가 명확하다. 저장된 이전 파일과 현재 장면이 다르면 어느 상태를 기준으로 했는지 설명할 수 있다.

부위별 기준 원본도 고정하라. 과거 고해상도 파일은 세부 참조로 사용할 수 있지만 현재 승인된 목·배치·실루엣을 되돌리는 기준으로 섞지 마라. 기준을 바꿨다면 해당 비교 검사를 다시 수행하라.

### 2. 부위별 루프 설계

면을 채우기 전에 대상의 주요 루프와 밀도 전환을 계획하라. 작업 기록에 각 주요 루프의 위치, 방향, 대략적인 정점 수, 연결할 부위, 폴을 둘 위치를 적고 정면·측면 이미지에 표시하라. 처음부터 최종 면 수를 채우려 하지 마라.

계획한 관절·눈꺼풀·입술·장식 경계를 실제 정점 집합이나 명확한 선택 영역으로 표시하라. 줄 간격이 좁다는 이유로 중요한 관절 고리를 삭제하지 않도록 보호하고, 가려진 부분에서 먼저 밀도를 조정하라. 정점 번호는 연결을 바꾸면 달라질 수 있으므로 대응 정보를 함께 갱신하라.

| 부위 | 반드시 설계할 흐름 | 집중 확인 |
|---|---|---|
| 눈 | 눈꺼풀 테두리를 감싸는 고리와 주변 여유 고리 | 눈 감기, 안쪽·바깥쪽 눈꼬리, 눈알과의 간격 |
| 입·인중 | 입술 둘레, 입꼬리에서 볼로 이어지는 연결, 코 아래에서 윗입술로 내려오는 흐름 | 입 벌리기·입꼬리 이동. 필요한 입 안쪽 연결 |
| 코·볼·턱 | 코 옆에서 볼로 퍼지고 턱 아래로 이어지는 흐름 | 얼굴 비율과 턱선. 복잡한 폴이 입꼬리에 집중되지 않게 하기 |
| 귀 | 바깥 테두리와 주요 안쪽 굴곡 | 귀 앞뒤가 붙거나 납작해지지 않는지 |
| 목 | 머리에서 목·어깨로 이어지는 줄과 접합 경계 | Head·Body 경계의 대응 정점·위치·노멀·웨이트 |
| 어깨·팔꿈치·손목 | 관절 둘레의 고리와 굽힘 양쪽의 보조 줄 | 겨드랑이·팔꿈치 안쪽의 눌림과 바깥쪽 볼륨 |
| 손 | 손가락별 관절 고리, 손가락 사이, 엄지 기저부 | 손가락 쥐기·벌림·엄지 회전 |
| 가려진 몸통·두피 | 큰 윤곽을 유지하는 성긴 격자 | 노출 부위에서 갑자기 밀도가 바뀌지 않는지 |
| 부츠 통·발목 | 통 둘레의 고리, 세로 줄, 발목 앞뒤의 굽힘 여유 | 발목을 가로지르는 지나치게 큰 면 방지 |
| 발등·발끝·밑창 | 발 길이 방향과 횡단 방향의 줄, 밑창 둘레 | 발끝과 밑창의 윤곽 |
| 버클·금속 장식 | 테두리를 따라 도는 연결과 필요한 두께 | 테두리·구멍 보존. 가죽과 다른 변형 방식 |
| 천·슬릿·밑단 | 고정 부위에서 내려오는 흐름, 슬릿과 밑단의 경계 | 원단 간격과 열린 부분 보존. 소매·치마의 예상 굽힘 방향 |

대상과 무관한 부위는 만들지 마라. 모든 관절에 같은 루프 개수를 일괄 적용하지 마라. 실제로 분리된 장식은 별도 연결 성분으로 유지할 수 있지만, 연속된 피부나 가죽을 편의상 잘라 두지 마라.

**통과 조건:** 주요 루프의 용도가 설명되고, 어느 줄로 볼륨을 수정하며 어디서 밀도가 줄어드는지 알 수 있다. 계획 없이 자동 변환부터 시작했다면 이 단계로 돌아와라.

### 3. 성긴 쿼드 구조 제작

먼저 위의 대표 패치 시험을 수행하라. 아래 절차로 전체에 확장하는 것은 해당 방식의 패치가 합격한 뒤다. 한쪽 귀의 성공이 손가락·버클의 대응 검증까지 대신하지는 않는다.

1. 기준 루프부터 만들고 그 사이를 규칙적인 사각형 줄로 연결하라. UI에서는 Poly Build·돌출·Bridge Edge Loops를, 코드에서는 명시적으로 설계한 정점 고리와 면 연결을 사용할 수 있다.
2. 두 경계를 이을 때 정점 수·순환 순서·대응 위치를 확인하라. 같은 수의 고리라도 시작점이나 방향이 틀리면 연결이 꼬인다. 밀도가 다른 영역은 전환 부위를 설계해 연결하라.
3. 3·5방향 폴 등은 밀도·방향 전환에 사용하고, 관절 접힘 중심·눈꺼풀·입꼬리 같은 변형 집중부에서 벗어나게 배치하라.
4. 넓고 단순한 부분을 완성한 뒤 세부 장식을 추가하라. 부츠는 통·발목·발등·밑창의 구조를 먼저 안정시켜라.
5. 좌우 대칭 여부를 실제로 확인한 뒤 Mirror나 반대쪽 복제를 사용하라. 로컬 축·원점·음수 스케일을 확인하고 비대칭 디테일까지 덮어쓰지 마라.
6. 부위 하나가 완성될 때마다 텍스처를 끈 와이어프레임과 루프 선택을 확인하라. 잘못된 연결은 그 부위에서 다시 만들어라.

부품 하나의 형태·편집·변형을 확인하고 UV·재질까지 이전해 저장 가능한 결과를 확보한 뒤 같은 방식의 나머지 부품으로 확장하라. Head/Body처럼 서로 의존하는 목 경계는 함께 검증하되 네 부품 전체를 미검증 후보로 동시에 쌓지 마라.

**통과 조건:** 주요 루프가 의도한 경계·폴까지 이어지고, 주변 면이 기능에 맞는 격자를 이룬다. 의미 없이 방향이 뒤섞였으면 면 수가 맞아도 다음 단계로 넘어가지 마라.

### 4. 원본 형태에 맞추기

1. 면 스냅·Shrinkwrap·표면 투영으로 정점을 원본에 맞춰라. 이 기능은 정점 위치를 보조할 뿐 루프 설계를 대신하지 않는다.
2. 귀 앞/뒤, 위/아래 입술, 손가락별 표면, 가죽/금속을 **서로 다른 대응 영역**으로 제한하라. 투영 방향·최대 거리·앞뒤 구분·고정 경계를 정한 뒤 맞춰라. 법선 방향을 점수에 더한 전역 최근접 탐색도 다른 부위에 붙을 수 있다. 유효한 대응이 없으면 오류로 남기고, 전체 원본에서 가장 가까운 점으로 조용히 대체하지 마라.
3. 간격을 조정한 뒤 다시 원본과 비교하라. 정리·평활화로 코·턱·손끝·장식이 줄어들거나 부풀지 않게 하라.
4. 8방향에서 같은 카메라·배율로 원본과 비교하라. 중요한 접합·구멍·장식은 별도 확대하라. 텍스처를 끈 형상과 최종 재질을 모두 확인하라.
5. 첫 패치부터 **후보→원본과 원본→후보를 모두** 검사하라. 한 방향만 가까우면 귀·입술·장식을 덮지 못한 후보도 좋아 보일 수 있다. 정점 외에 면 내부·경계·주요 윤곽을 표본으로 포함하고, 실제 표본 방식과 한계를 기록하라. 단위·표본 수·평균·상위 오차·최대 오차·그 위치를 남겨라. 포인트 클라우드까지의 거리와 삼각형 표면까지의 거리를 섞어 비교하지 마라.
6. 맞춤·평활화·루프 삭제 직후에는 새 관통·접힘·경계 이동을 검사하라. BVH 등으로 나온 겹침 목록은 정확한 삼각형 교차·접촉 검사와 해당 부위 화면으로 확인하라. 의도된 접합, 원본 결함, 새 관통, 판정 불가를 구분하고 미판정 목록이 있으면 합격시키지 마라.
7. 전체 형상에 잘 맞는다는 이유로 귀·손가락·목까지 같은 투영을 쓰지 마라. 두께가 무너지거나 대응 순서가 뒤집히면 마지막 합격 사본으로 돌아가 패치를 다시 연결하라. 평활화·최적화의 반복 횟수를 늘려 문제를 숨기지 마라.

**통과 조건:** 중요한 윤곽·비율·장식·접합이 유지되고, 의도하지 않은 차이가 해결되었다. 해결하지 못한 외형 손실을 작은 숫자나 매끈한 음영으로 정당화하지 마라.

### 5. 편집성과 변형을 실제로 시험하기

검사용 사본에서 아래를 실행하고 결과를 복구하라. 조작이 가능하다는 설명만 남기지 마라.

- 대표 루프를 선택하고 선택된 범위를 캡처하라. UI의 루프 선택 또는 동등한 연결 추적으로 계획한 줄이 이어지는지 확인하라.
- 루프를 소폭 이동·슬라이드·확대해 부위의 볼륨을 바꿔 보라. 엉뚱한 부위까지 끌려가거나 면이 뒤집히면 연결을 수정하라.
- 기존 리그가 있으면 필요한 자세를 재생하라. 없다면 검사 사본에 필요한 최소 본과 웨이트 또는 동등한 변형 시험을 구성하라. 검사 사본의 임시 설정을 실제 리그 완성으로 보고하지 마라.
- 얼굴은 눈 감기·입 벌리기·입꼬리 이동, 몸은 팔꿈치·손가락·목 등, 부츠는 발목과 실제 포함된 관절을 시험하라. 요구 범위와 원본 구조에 맞는 동작만 실행하라.
- 문제를 토폴로지와 웨이트로 나눠 진단하라. 웨이트를 조정해도 계속 뾰족하게 접히면 루프 위치·밀도·폴을 수정하라. 금속 장식을 가죽처럼 찌그러뜨리지 마라.

**통과 조건:** 실제 선택·편집·변형에서 의도한 범위가 움직이고 주요 눌림·틈·교차가 없다. 필요한 변형을 시험할 수 없다면 정적 편집본으로만 기록하고 검증 범위를 낮춰 보고하라. 변형 검증을 요구받은 작업을 완료했다고 말하지 마라.

### 6. 면 수와 연결 품질 확정

1. 과한 줄은 평평하거나 가려진 곳에서 줄이고, 실루엣·관절에 필요한 줄은 남겨라. 연결을 바꾼 부위는 4~5단계를 다시 검사하라.
2. 정확한 개수를 요구받았다면 **형태·편집·변형을 통과한 구조에서** 루프 분할 수와 부위별 배분을 조정해 맞춰라. 숫자를 맞추는 변경이 보호한 고리를 훼손하면 되돌려라. 상한이나 근삿값이면 억지로 예산을 소진하지 마라.
3. 편집 원본의 모든 면이 쿼드인지 검사하라. 모디파이어 적용 전 기본 메시와 실제 내보낼 평가 결과의 면 수를 구분하라.
4. 고립 정점·중복 면·퇴화 면·자기교차·방향 오류·원치 않는 연결을 제거하라. 오목한 쿼드는 0개를 목표로 정리하고, 판정이 애매한 비평면 면은 실제 분할·변형을 확인하라. 문제가 남으면 위치와 이유를 기록하고 자동 합격시키지 마라.
5. 열린 경계는 허용 목록과 비교하라. 목 접합·옷 끝·부츠 입구 등을 무조건 메우지 마라. 허용되지 않은 틈이나 세 면 이상이 붙는 잘못된 모서리는 수정하라.

**통과 조건:** 요구된 예산과 구조 검사를 충족하고 편집성·형태·변형도 유지된다. 예산을 맞추려면 이미 합의된 형태나 핵심 루프를 포기해야 하는 경우, 후보·비교 증거·대안을 준비해 그 충돌만 사용자에게 알려라.

자동 맞춤이나 특정 도구의 실패만으로 예산이 부족하다고 결론 내리지 마라. 부위별 면 배분과 필요한 루프를 실제로 비교한 근거가 있어야 한다.

### 7. UV·텍스처 이전

UV·재질 보존이 요청 범위에 포함되면 수행하라. 기존 텍스처를 사용하던 모델을 수정하면서 새 UV에 맞는 재질 이전을 조용히 생략하지 마라.

1. 형태·면 연결을 먼저 확정하고 편집용 쿼드 파일을 저장하라. 얼굴·귀·손·부츠 통·밑창 등 관리 가능한 UV 덩어리로 펼쳐라.
2. 눈에 덜 띄는 절개선을 계획하고 체크무늬로 늘어짐·밀도·의도하지 않은 겹침을 검사하라. 자동 UV 결과도 직접 검수하라.
3. 별도 내보내기 사본에서 삼각형 분할·노멀 기준을 정하고 베이크와 내보내기에 같은 기준을 사용하라. 편집 원본을 삼각형으로 덮어쓰지 마라.
4. 원본 색상과 노멀을 새 UV에 이전하라. 투사 거리·케이지를 작은 부위에서 시험해 반대편 표면이 묻거나 장식이 누락되지 않게 하라.
5. 색상에 새 조명·그림자를 굽지 마라. 원본 이미지에 이미 포함된 그림자 보수는 별도 요청 범위를 확인하라. 구멍·실루엣 손실을 노멀 맵으로 대체하지 마라.
6. 결과 이미지를 저장·포함하고 .blend를 다시 열어 실제 연결과 외형을 확인하라.

**통과 조건:** 새 UV에서 원래 색감·패턴·주요 표면 디테일이 유지되고 저장 파일에서 재현된다. 메시 연결 변경이 필요해졌다면 이전 단계로 돌아가 수정한 뒤 영향을 받는 베이크를 다시 수행하라.

### 8. 전달과 완료 판정

1. 작업용 후보·원본 참조·검사 사본과 실제 결과를 구분하라. 사용자에게 열어야 할 파일을 하나로 명확하게 알려라.
2. 최종 .blend를 다시 열어 대상 오브젝트·면 수·재질·이미지·배치를 확인하라. 대상 외 부품이 바뀌지 않았는지 확인하라.
3. FBX·Unity 검증을 요청받았다면 실제 내보내기 사본과 PNG를 전달하고 가져오기·노멀·스케일·좌우 반전·애니메이션 재생을 확인하라. 요청되지 않았다면 작업 범위를 임의로 확장하지 마라.
4. 완성 파일, 핵심 루프의 와이어·선택 캡처, 8방향 전후 비교, 변형 결과, 간단한 검증 기록을 남겨라. 긴 기능 보고서보다 실제 결과를 판정할 수 있는 증거를 우선하라.

- 원본→후보 최대 정점 표본 거리는 Head 6.820, Body 44.864로 기록됐다. 당시 코드는 장면 좌표에 1,000을 곱해 mm로 표기했으므로 **1단위=1m라는 가정이 있는 수치**다. 새 실행에서는 단위를 확인하고 최대 오차 위치를 직접 검사한다.
- 비인접 삼각형 겹침 Head 617쌍·Body 52쌍은 **교차 의심 목록**이다. 확정된 관통 개수로 인용하지 않는다. Body의 오목한 면 0개도 이 목록을 해결한 증거가 아니다.
- 후보의 UV·재질은 없었고 실제 루프 편집·변형 검증은 미실행이었다. 부츠는 각각 기존 6,000쿼드 상태였다. 이 결과는 3,000쿼드 예산 자체가 불가능하다는 증거가 아니다.

사용자가 지적한 약 1시간의 대기는 실행 비용 문제로 받아들인다. 이 개정에서는 도구별 소요 시간을 따로 계측하지 않았으므로 어느 연산이 몇 분을 소비했다고 단정하지 않는다. 확인한 낭비는 작은 부위의 합격 없이 전체 후보 제작·보정을 이어간 실행 순서다.

## 도구 동작을 확인할 공식 자료

필요하면 설치된 Blender 버전의 API·메뉴를 확인하라. 아래 자료의 버전이나 화면 배치가 현재 설치본과 같다고 가정하지 마라.

- [Blender Render Baking](https://docs.blender.org/manual/id/5.0/render/cycles/baking.html): Selected to Active와 케이지·노멀 이전.
