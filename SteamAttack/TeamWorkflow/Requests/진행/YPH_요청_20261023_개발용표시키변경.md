## 1. 한 줄 요약

개발용 표시(왼쪽 위 "개발용 표시 ON" 상자, 범위 원·판정 상자)를 켜는 키를 **0 → `** 로 바꾸고, 안내 문구도 같이 바꿔 주세요.

## 2. 왜 필요한가

- 개발자 창을 따로 띄우지 않고 **개발용 표시에 합쳤습니다** (NMJ, 10/23).
  - ` 를 누르면 개발용 표시가 켜지고, Alt를 누른 채 왼쪽 위 상자에 마우스를 대면 무적·원펀맨·리젠·순간이동 판이 펼쳐집니다.
- 그런데 YPH 쪽 0 키도 같은 표시를 켜고 끕니다. 키가 두 개라 헷갈리고, 0은 다른 시험 키(숫자패드 HUD 등)와 겹칩니다.

## 3. 해 줄 일

1. `Assets/Scripts/YPH/Enemy/DebugView.cs` `PollToggleKey()` — 0 키 처리를 지워 주세요. (` 는 NMJ가 이미 `DebugView.SetEnabled`로 켜고 끕니다. 0 대신 `를 여기서 받으면 두 번 뒤집혀 안 켜지니, **지우기만** 해 주세요.)
2. `EnemyDebugTools.cs` 안내 첫 줄 `개발용 표시 ON  0: 끄기` → `` 개발용 표시 ON  `: 끄기 · Alt+마우스: 개발자 기능 ``
3. 주석·로그의 "0 키" 문구 (`DebugView.cs`, `EnemyAttackHitbox.cs`, `EnemyHpBar.cs`) → "` 키"

## 4. 확인 방법

Main 플레이 → ` → 왼쪽 위 상자가 뜬다 → 0을 눌러도 꺼지지 않는다 → Alt를 누른 채 상자에 마우스를 대면 기능 판이 펼쳐진다.
