# 요청: 보스 씬에서 Main으로 돌아올 때 오프닝이 다시 나오지 않게

| 항목 | 내용 |
|---|---|
| 요청일 | 2026-10-20 |
| 요청자 | YPH |
| 받는 사람 | NMJ |
| 우선순위 | 🟡 보통 |
| 희망 기한 | 2026-10-21 (기능 마감, D-091) |
| 관련 기획서 | [시연 흐름](../../Design/월드/시연흐름.md), [아웃게임](../../Design/UI/아웃게임.md) (D-103) |
| 상태 | 요청됨 |

## 1. 한 줄 요약

보스 씬에서 Main으로 돌아오면 `NMJ.NmjOpening`이 처음부터 다시 재생됩니다. 한 번 본 오프닝은 새 게임을 시작하기 전까지 다시 틀지 않게 해 주세요.

## 2. 대상 파일

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Assets/Scripts/NMJ/UI/NmjOpening.cs` | 스크립트 | 변경 (본 적 있음 표시) |
| `Assets/Scripts/NMJ/UI/TitleScreen.cs` | 스크립트 | 변경 (새 게임 때 표시 초기화, 한 줄) |

## 3. 왜 필요한가

10.19 회의에서 프롤로그 반복을 고치기로 정했습니다(D-103). 시연 중 보스전 뒤 Main으로 돌아올 때 오프닝 20초가 다시 나오면 흐름이 끊깁니다.

담당은 회의에서 이름이 확정되지 않았습니다(`00_프로젝트.md` 확인 필요). 오프닝 코드가 NMJ 파일이라 NMJ에게 요청합니다. 다른 사람이 맡기로 하면 받는 사람을 바꿉니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** `Start()`에서 `playOnStart`이면 항상 `Play()`. 막는 조건은 `IsPlaying`(지금 재생 중)뿐이라, 씬을 다시 불러오면 또 재생됨 (`9082bf7`, NMJ `4ec7dc6` 같음)
- **원하는 모습:** 같은 게임 안에서는 처음 한 번만 재생. 타이틀에서 새 게임을 고르면 다시 재생

## 5. 구체적인 변경 방법

1. `NmjOpening`에 정적 표시를 하나 둡니다.

```csharp
public static bool HasPlayed { get; private set; }
public static void ResetPlayed() => HasPlayed = false;   // 새 게임 시작 때 호출

[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
private static void ResetStatics() { IsPlaying = false; HasPlayed = false; }

private void Start()
{
    if (!playOnStart || HasPlayed || (Application.isEditor && !playInEditor)) return;
    Play();
}

// Play() 안 IsPlaying = true; 다음 줄
HasPlayed = true;
```

2. `TitleScreen`에서 새 게임으로 씬을 넘기기 직전에 `NmjOpening.ResetPlayed();`를 부릅니다.
3. `[ContextMenu("미리 보기")]`로 부르는 `Play()`는 `HasPlayed`와 관계없이 그대로 재생됩니다.

## 6. 영향 범위

- 이 파일을 참조하는 곳: `NMJ_Story` 프리팹(오프닝 배치), `IsPlaying`을 읽는 곳(그대로 유지)
- 같이 영향받을 수 있는 다른 작업자·기능: 보스 씬 이동(`NGH.ScenePortal`), 개발자 창 이동·시연자 키 "처음부터 다시"(D-051, D-098). "처음부터 다시"가 오프닝까지 다시 보여야 하면 거기서도 `ResetPlayed()` 호출
- 씬·프리팹이면: 해당 없음 (스크립트만)

## 7. 확인 방법

1. 타이틀 → 새 게임: 오프닝 재생
2. 보스 씬으로 이동한 뒤 Main으로 복귀: 오프닝 없음
3. 일시정지 메뉴로 타이틀 → 새 게임: 오프닝 다시 재생

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 보스전 뒤 복귀할 때마다 오프닝 20초가 다시 나옴. ESC로 넘길 수는 있음
- **대안:** 없음 (YPH가 고칠 수 없는 파일)

## 9. 첨부
