## 1. 한 줄 요약

YPH Main 테스트 씬의 새 궁수 프리팹을 Main의 궁수 배치에 적용해 주세요.

## 2. 대상 파일

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Assets/Prefabs/NMJ/NMJ_EnemySpawns.prefab` | 프리팹 | 궁수 인스턴스 교체 |
| `Assets/Scenes/Common/Main.unity` | 씬 | 교체 결과 확인 및 필요한 씬 연결 확인 |
| `Assets/Prefabs/YPH/Enemy/YPH_HeuksuArcher_Rigged.prefab` | 프리팹 | 교체에 사용할 원본 |
| `Assets/Scenes/YPH/YPH_MainPlayerTest.unity` | 씬 | 새 궁수 참고 |

## 3. 왜 필요한가

YPH 테스트 씬의 새 궁수 모델과 활·화살 소품을 Main에서도 사용하기 위해서입니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** YPH 테스트 씬에서 새 궁수 프리팹을 사용합니다. Main의 기존 배치 상태는 적용 전 다시 확인이 필요합니다.
- **원하는 모습:** Main의 기존 궁수 배치가 새 궁수 프리팹을 사용하고, 기존 배치 위치와 방향 및 사격 동작이 유지됩니다.

## 5. 구체적인 변경 방법

1. `NMJ_EnemySpawns.prefab`과 Main의 현재 궁수 배치를 확인하고 각 인스턴스의 부모, 위치, 회전과 씬별 덮어쓰기 값을 기록해 주세요.
2. 기존 궁수 인스턴스를 `YPH_HeuksuArcher_Rigged.prefab`으로 교체하고 기록한 배치와 필요한 참조를 복원해 주세요. 원본 프리팹 내부를 덮어쓰면 기존 인스턴스의 참조가 달라질 수 있으므로 인스턴스 단위로 교체해 주세요.
3. 자세한 기존 배치와 확인 순서는 [Main 적용 가이드 7번](../../Features/Main적용가이드.md#7-새-궁수로-교체-4번)을 참고하되, 문서의 위치와 수치가 현재 파일과 다른 경우 현재 배치를 우선 확인해 주세요.

## 6. 영향 범위

- `NMJ_EnemySpawns`를 사용하는 씬의 궁수 배치와 참조에 영향을 줄 수 있습니다.
- 씬·프리팹의 현재 작업자는 확인 필요입니다. 편집 전 담당자끼리 협의해 주세요.

## 7. 확인 방법

1. Main에서 궁수의 위치·방향, 모델·재질·활·화살을 확인합니다.
2. Play에서 궁수 인지와 사격, 피격·사망 및 Console 오류 여부를 확인합니다.
3. 프리팹을 사용하는 다른 씬에도 영향이 없는지 확인합니다.

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** Main의 궁수에 YPH 테스트 씬의 새 모델이 반영되지 않을 수 있습니다.
- **대안:** 적용 전까지 YPH 테스트 씬에서 새 궁수를 확인합니다.
