# 요청: 환도 강공격 입력을 기획서대로 우클릭 단독으로

|---|---|
| 요청일 | 2026-10-16 |
| 요청자 | YPH |
| 받는 사람 | NGH |
| 우선순위 | 🟡 보통 |
| 희망 기한 | 2026-10-18 이후 (기능 마감 뒤 다듬기 때) |
| 관련 기획서 | `Design/전투/근거리무기.md` 2번, `Design/전투/기본조작.md` 조작표 |
| 상태 | 요청됨 |

## 1. 한 줄 요약

환도를 들고 있을 때 **우클릭 한 번**으로 강공격이 나가게 해 주세요. 지금은 좌클릭과 우클릭을 0.08초 안에 같이 눌러야만 나갑니다.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/NGH/Player/PlayerController.cs` | 스크립트 | `ReadAttackInput` 근접 입력 변경 |

## 3. 왜 필요한가

- 기획서는 "좌클릭 약공격, 우클릭 강공격"입니다(`근거리무기.md` 2번, `기본조작.md` 조작표). 동시 클릭은 기획서·회의록·결정 로그 어디에도 없습니다
- 동시 클릭은 2026-10-07 "애니메이션 테스트" 커밋에서 들어와 v0.2 빌드까지 이어졌습니다
- 0.08초 안에 두 버튼을 함께 누르기는 어렵습니다. YPH 시험 씬에서 사용자가 우클릭으로 강공격을 시도했다가 "강공격이 없다"고 판단했습니다
- 받아치기 성공 뒤 경직 시간 안에 강공격을 넣는 것이 받아치기의 보상입니다(D-067, D-068). 강공격을 쉽게 낼 수 있어야 이 흐름이 성립합니다

## 4. 현재 상태 → 원하는 상태

| 항목 | 현재 | 원하는 모습 |
|---|---|---|
| 환도 + 좌클릭 | `bothClickWindow`(0.08초)만큼 기다렸다가 약공격 | 바로 약공격 |
| 환도 + 우클릭 | 아무 동작 없음 | 강공격 |
| 환도 + 좌우 동시 클릭 | 강공격 | 먼저 들어온 입력대로 처리 (특별 처리 없음) |
| 화승총 + 우클릭 | 조준 (`CombatBridge`) | 그대로 |

## 5. 구체적인 변경 방법

`ReadAttackInput`의 근접 부분을 아래처럼 바꿉니다. 동시 클릭 대기가 없어지므로 `_leftClickAt`·`_rightClickAt`·`bothClickWindow`는 필요 없어집니다.

```csharp
// PlayerController.ReadAttackInput (근접 무기일 때)
if (mouse.leftButton.wasPressedThisFrame) Request(ActionState.LightAttack);
else if (mouse.rightButton.wasPressedThisFrame) Request(ActionState.HeavyAttack);
```

- 약공격 콤보 이어 붙이기(`comboGraceTime`)와 입력 예약(`bufferWindow`)은 `Request`에 있으므로 그대로 동작합니다
- 일부러 동시 클릭으로 바꾼 이유가 있다면(예: 다른 키와 겹침) 아래 처리 기록에 적어 주세요. 그 경우 기획서를 바꿀지는 NMJ와 정합니다(D-037)

## 6. 영향 범위

- 이 파일을 참조하는 곳: `ReadAttackInput` 안에서만 변경. `Request`·`StartAction`은 그대로
- 같이 영향받을 수 있는 다른 작업자·기능: 요청 `근접적중약강구분`의 강공격 증기 지불(`HeavyAttackGate`)은 동작 시작 부분에 있어서 입력 방식과 상관없음. 조작 안내(`NGH_ControlsGuide`)에 "좌우 동시" 문구가 있으면 함께 수정
- 씬·프리팹: 해당 없음 (`bothClickWindow` 값이 씬에 남아도 쓰지 않음)

## 7. 확인 방법

1. 환도를 든 상태에서 우클릭 → 강공격
2. 좌클릭 연타 → 약공격 1~5타 콤보가 지금처럼 이어짐
3. 화승총을 든 상태에서 우클릭 홀드 → 조준, 조준 중 좌클릭 → 사격
4. 받아치기 성공 직후 우클릭 → 적 경직 시간 안에 강공격이 들어감

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 시연자가 강공격을 거의 낼 수 없어서, 받아치기 → 강공격 흐름과 강공격 증기 소모(D-071)를 보여 주기 어려움
- **대안:** 동시 클릭 대기 시간을 늘림(예: 0.2초). 하지만 약공격이 그만큼 늦게 나가고, 기획서와도 계속 다름
