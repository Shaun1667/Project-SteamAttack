## 1. 한 줄 요약

현무의 흑철 찍기·뱀의 목 찌르기를 받아칠 수 있도록, 현무 쪽에서 `YPH.IParryTarget`을 구현하고 `YPH.ParryTargets`에 등록해 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/BHS/Boss/` 의 현무 공격 스크립트 (예: `BossFSM` 또는 흑철 찍기·뱀 찌르기용 `BossAttack`) | 스크립트 | `IParryTarget` 구현 추가 |
| `Assets/Scripts/BHS/HP/BossHealth.cs` | 스크립트 | 약점 노출(다음 공격 1회 3배) 추가 |

## 3. 왜 필요한가

현무 기획서의 공략 순서는 **흑철 찍기 받아치기 → 증기 +20 → 100 → Z(증기발도)로 가갑 파괴**입니다. 받아치기가 안 되면 증기발도까지 이어지지 않아 보스전이 성립하지 않습니다.

D-061로 받아치기를 다음처럼 나눴습니다.
- 플레이어 입력·판정·동심원: NGH
- 공통 규약: YPH
- 현무는 규약만 구현하면 됩니다. 판정, 동심원 UI, 증기 처리는 NGH의 `PlayerParry`·`ParryRingUI`가 알아서 합니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** 받아치기 대상은 `YPH.EnemyAI`뿐이라 현무는 받아칠 수 없음. `BossHealth`에 약점 노출 없음
- **원하는 모습:** 흑철 찍기·뱀의 목 찌르기 준비 중에 발톱 끝·뱀 머리에 흰 동심원 → 겹칠 때 Ctrl → 공격 취소, 자세 붕괴, 약점 노출(다음 공격 1회 3배, 3초)

## 5. 구체적인 변경 방법

YPH가 10/16까지 아래 규약을 커밋합니다(`Assets/Scripts/YPH/Enemy/`).

```csharp
namespace YPH
{
    public interface IParryTarget
    {
        Vector3 ParryPoint { get; }          // 동심원 위치·거리 기준 (발톱 끝, 뱀 머리)
        bool IsParryWindowOpen { get; }      // 받아칠 수 있는 공격 준비 중인가
        float ParryOverlapTime { get; }      // 두 원이 겹치는 시각 (Time.time 기준)
        bool IsParryStunned { get; }         // 받아치기에 당해 자세가 무너진 상태인가
        bool ApplyParry(float damage, Vector3 from);  // 판정 성공 후 호출: 공격 취소·자세 붕괴·약점 노출
    }

    public static class ParryTargets
    {
        public static void Register(IParryTarget target);    // OnEnable
        public static void Unregister(IParryTarget target);  // OnDisable
        public static void NotifyAttackStarted(IParryTarget target, float secondsUntilOverlap);  // 공격 준비 시작 때
    }
}
```

BHS 쪽에서 할 일입니다. 구조는 BHS 코드에 맞게 자유롭게 정해 주세요. 아래는 `BossAttack`의 준비(`readyTime`) → 공격 → 회복 흐름에 맞춘 예시입니다.

1. 받아칠 수 있는 공격(흑철 찍기, 뱀의 목 찌르기)에 "받아치기 가능" 표시를 둡니다. 예: `BossAttack`에 `public bool parryable;`
2. 현무 쪽 한 곳(예: `BossFSM`)이 `IParryTarget`을 구현하고, `OnEnable`에서 `ParryTargets.Register(this)`, `OnDisable`에서 `Unregister(this)`를 부릅니다.
3. 받아칠 수 있는 공격이 시작되면 아래처럼 처리합니다.
   - `IsParryWindowOpen = true`
   - `ParryOverlapTime` = 판정 시각(준비가 끝나 공격이 닿는 시각)
   - `ParryTargets.NotifyAttackStarted(this, ParryOverlapTime - Time.time)` 호출
   - 판정이 지나거나 공격이 끝나면 `IsParryWindowOpen = false`
4. `ParryPoint`는 지금 공격하는 부위의 위치를 돌려줍니다(흑철 찍기는 찍는 발 끝, 뱀 찌르기는 뱀 머리).
5. `ApplyParry(damage, from)`이 불리면 아래처럼 처리하고 `true`를 돌려줍니다.
   - 진행 중인 공격의 `CancelAttack()`
   - 자세 붕괴 상태(`IsParryStunned = true`, 지속 시간은 BHS가 정함)
   - `BossHealth`에 약점 노출 3초
6. `BossHealth.TakeDamage`에서 약점 노출 중이면 피해 ×3을 한 번만 적용하고 약점을 해제합니다(기획 패링 배율 규칙: 다음 공격 1회, 다른 배율과 곱하지 않음).

참고 구현: `YPH.EnemyAI`(`ForceParried`)와 `YPH.EnemyHealth`(`ExposeWeakness`, `weaknessMultiplier`)

## 6. 영향 범위

- 이 파일을 참조하는 곳: NGH `PlayerParry`·`ParryRingUI`가 `ParryTargets`를 통해서만 읽음(BHS 코드를 직접 참조하지 않음)
- 같이 영향받을 수 있는 다른 작업자·기능: 받아치기(NGH, 별도 요청 `YPH_요청_20261015_받아치기공통규약적용.md`)
- 씬·프리팹이면: 현무 프리팹에서 받아칠 수 있는 공격의 `parryable` 체크만 필요

## 7. 확인 방법

1. 흑철 찍기 준비 중 발 끝에 흰 동심원이 뜸
2. 겹칠 때 Ctrl → 찍기가 취소되고 현무가 자세 붕괴, 증기 +20
3. 바로 다음 공격 1회 피해가 3배, 그다음은 1배
4. 꼬리 휩쓸기·냉기 브레스에는 동심원이 뜨지 않음

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 현무전에서 받아치기 → 증기발도 순환이 안 돼 공략이 성립하지 않음
- **대안:** 시연 디버그 키로 증기를 채우는 방법뿐(기획 의도와 다름)
