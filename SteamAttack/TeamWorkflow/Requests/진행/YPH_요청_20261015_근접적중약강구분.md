## 1. 한 줄 요약

근접 적중 때 강공격인지 `SteamHitRefill`에 알려 주세요(약공격만 증기 회복). 그리고 강공격 동작이 실제로 시작될 때 증기를 내게 해 주세요. 증기가 모자라면 강공격이 나가지 않습니다.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/NGH/Player/CombatBridge.cs` | 스크립트 | 적중 시 강공격 여부 전달, 강공격 증기 확인 연결 |
| `Assets/Scripts/NGH/Player/PlayerController.cs` | 스크립트 | 강공격 시작 직전 확인 입구 추가 |

## 3. 왜 필요한가

2026-10-15 회의에서 증기 규칙이 바뀌었습니다.
- 칼 **일반 공격** 적중 시 증기 회복(D-070). 강공격 적중은 회복하지 않음
- 강공격은 **증기를 쓰는** 강한 공격이고 선딜이 있음. 받아치기 후 안정적으로 넣는 공격(D-071)
- 특수 기술(증기발도)·과열은 따로 만들지 않고 강공격으로 합침(D-071)

지금 상태와 맞지 않는 점은 두 가지입니다.
- `CombatBridge.HandleMeleeHit()`가 공격 종류 없이 `hitRefill.NotifyHit(target)`만 불러서, 강공격도 증기를 회복함
- 강공격(좌+우 동시 클릭)은 증기 없이 나감

강공격인지는 `PlayerController`만 알고, 증기는 YPH 쪽(`SteamTank`)에 있습니다. 그래서 두 코드를 이어 주는 부분이 NGH 쪽에 필요합니다.

## 4. 현재 상태 → 원하는 상태

| 항목 | 현재 | 원하는 모습 |
|---|---|---|
| 약공격 적중 | 증기 +10 | 증기 회복 (양은 YPH 인스펙터, 플레이 피드백으로 조정) |
| 강공격 적중 | 증기 +10 | 회복 없음 |
| 강공격 사용 | 증기 변화 없음 | 시작할 때 증기 소모 (임시 30) |
| 증기 부족 시 강공격 | 나감 | 나가지 않음 |

## 5. 구체적인 변경 방법

YPH가 10/17까지 `SteamHitRefill`에 아래 두 메서드를 추가합니다. 기존 `NotifyHit(target)`은 남겨 두므로 커밋 순서가 바뀌어도 컴파일이 깨지지 않습니다. 수류탄의 기존 호출도 그대로 둡니다.

```csharp
// YPH 쪽에 추가될 메서드 (회복량·소모량은 YPH 인스펙터에서 조정)
public void NotifyHit(IDamageable target, bool heavy);  // heavy면 회복 없음, 아니면 약공격 회복량만큼
public bool TryPayHeavyAttack();                        // 강공격 증기(임시 30)를 내고 true. 모자라면 내지 않고 false
```

NGH 쪽 변경:

1. `HandleMeleeHit`에서 강공격 여부를 넘깁니다.

```csharp
private void HandleMeleeHit(Damageable target)
{
    if (hitRefill == null || target == null) return;
    IDamageable damageable = target.GetComponentInParent<IDamageable>();
    bool heavy = player.CurrentAction == PlayerController.ActionState.HeavyAttack;
    hitRefill.NotifyHit(damageable ?? new ChgTarget(target), heavy);
}
```

2. `PlayerController`에 강공격 확인 입구를 두고, **강공격 동작이 실제로 시작되는 곳**에서 부릅니다. 현재는 `case ActionState.HeavyAttack:`가 있는 동작 시작 부분(521줄 근처)입니다.
   - 입력(683줄 `Request`)에서 부르지 않는 이유가 있습니다. 구르기 중 버퍼에서 버려진 입력에도 증기가 빠지기 때문입니다.

```csharp
// PlayerController (NGH)
/// <summary>강공격을 시작하기 직전에 부릅니다. false면 강공격을 시작하지 않습니다. 비어 있으면 항상 시작합니다.</summary>
public System.Func<bool> HeavyAttackGate { get; set; }

// 동작 시작 부분
if (action == ActionState.HeavyAttack && HeavyAttackGate != null && !HeavyAttackGate())
    return;   // 강공격을 시작하지 않고 대기 상태 유지
```

3. `CombatBridge`에서 연결합니다.

```csharp
// OnEnable
if (player != null && hitRefill != null) player.HeavyAttackGate = hitRefill.TryPayHeavyAttack;
// OnDisable
if (player != null) player.HeavyAttackGate = null;
```

- 강공격 선딜·피해량은 이 요청 범위가 아닙니다. NGH 근거리무기 기획서의 반영 대기(D-071)에서 다룹니다.

## 6. 영향 범위

- 이 파일을 참조하는 곳: `CombatBridge`가 `OnHitLanded`를 구독하는 부분만 변경
- 같이 영향받을 수 있는 다른 작업자·기능: 증기 시스템(YPH), 근거리 무기·강공격(NGH)
- 씬·프리팹: 해당 없음

## 7. 확인 방법

1. 증기 0에서 약공격 1타 적중 → 증기가 오름
2. 강공격 적중 → 적중으로는 오르지 않음
3. 증기 30 이상에서 강공격 → 시작할 때 30 줄고 공격이 나감
4. 증기 30 미만에서 강공격 → 나가지 않고 증기 그대로
5. 구르기 중 강공격 입력이 버려지면 → 증기 그대로

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 강공격이 공짜이고 맞히면 증기까지 회복해서, "증기를 모아 강공격에 쓴다"는 핵심 규칙이 성립하지 않음
- **대안:** 증기 확인을 입력 시점(683줄)에서만 함. 구현은 쉽지만 버려진 입력에도 증기가 빠질 수 있음
