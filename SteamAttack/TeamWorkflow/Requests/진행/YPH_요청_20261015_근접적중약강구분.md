## 1. 한 줄 요약

근접 공격이 맞았을 때 약공격(+5)인지 강공격(+10)인지 `SteamHitRefill`에 알려 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/NGH/Player/CombatBridge.cs` | 스크립트 | `HandleMeleeHit`에서 강공격 여부 전달 |

## 3. 왜 필요한가

증기 시스템 기획서의 수치표는 약공격 적중 +5, 강공격 적중 +10입니다. 지금 `CombatBridge.HandleMeleeHit()`는 공격 종류 없이 `hitRefill.NotifyHit(target)`만 불러서, `SteamHitRefill`이 모든 근접 적중에 같은 값(`_refillPerHit` 10)을 줍니다. 공격 종류는 `PlayerController.CurrentAction`에만 있어서 NGH 쪽에서 넘겨줘야 합니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** 약공격·강공격 모두 +10
- **원하는 모습:** 약공격(1~5타 연속기) +5, 강공격 +10

## 5. 구체적인 변경 방법

YPH가 `SteamHitRefill`에 공격 종류를 받는 메서드를 10/16까지 추가합니다. 기존 `NotifyHit(target)`도 그대로 남겨 두므로 순서가 바뀌어도 깨지지 않습니다.

```csharp
// YPH 쪽에 추가될 메서드
public void NotifyHit(IDamageable target, bool heavy);   // heavy면 +10, 아니면 +5 (인스펙터에서 조정)
```

NGH 쪽은 한 줄만 바꿔 주세요.

```csharp
private void HandleMeleeHit(Damageable target)
{
    if (hitRefill == null || target == null) return;
    IDamageable damageable = target.GetComponentInParent<IDamageable>();
    bool heavy = player.CurrentAction == PlayerController.ActionState.HeavyAttack;
    hitRefill.NotifyHit(damageable ?? new ChgTarget(target), heavy);
}
```

## 6. 영향 범위

- 이 파일을 참조하는 곳: 없음(`OnHitLanded` 구독부만 변경)
- 같이 영향받을 수 있는 다른 작업자·기능: 증기 시스템(YPH)
- 씬·프리팹이면: 해당 없음

## 7. 확인 방법

1. 증기 0에서 약공격 1타 적중 → 5
2. 강공격(좌+우 동시 클릭) 적중 → 10 증가

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 증기가 기획보다 빨리 차서 증기발도·시간 역행 밸런스가 달라짐
- **대안:** 회복량을 7.5 하나로 맞추는 임시안. 기획서와 달라서 권하지 않음

## 9. 첨부

- 확인 필요: 증기발도(Z) 적중은 기획 수치표에 없어서 이번 요청에서는 회복 대상이 아님. 회복이 필요하면 NMJ 확인 후 따로 정함
