# 요청: YPH 이름 정리 후 남은 NGH 공유 이름과 모델 경로 정리

| 항목 | 내용 |
|---|---|

| 요청자 | YPH |
| 받는 사람 | NGH |
| 우선순위 | 🟢 여유 |
| 희망 기한 | 다음 이름 정리 작업 때 |
| 관련 기획서 | [프로젝트](../../Design/00_프로젝트.md) |
| 상태 | 요청됨 |

## 1. 한 줄 요약

YPH에서 독립적으로 바꿀 수 있는 이름은 정리했으며, NGH 코드가 문자열로 찾는 표식·모델·검 이름은 양쪽을 함께 변경해야 합니다.

## 2. 대상 파일

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Assets/Scripts/NGH/Player/Damageable.cs` | 스크립트 | 표식 이름 변경 |
| `Assets/Scripts/YPH/Enemy/EnemyHealth.cs` | 스크립트 | NGH 변경과 함께 `LockMarkerName` 갱신 |
| `Assets/Scripts/NGH/HeroConversion.cs` | 스크립트 | 모델·검 이름 검색 갱신 |
| `Assets/Prefabs/YPH/HeroPlayer/YPH_HeroPlayerIntegration.prefab` | 프리팹 | 공유 모델·검·메시 이름 동시 갱신 |
| `Assets/Animations/YPH/HeroPlayer/YPH_SourceHumanCalibration.asset` | Avatar | 원본 모델 이름 변경 시 재생성·검증 |

## 3. 왜 필요한가

사용자가 YPH 수정 범위에 남은 CHG 이름을 정리하도록 요청했습니다. 이름만 개별적으로 바꾸면 NGH 코드의 문자열 검색과 YPH의 표식 제외 처리가 서로 달라집니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** `chg_LockMarker`, `chg_Model`, `chg_sword`, `chg_body`가 연결 이름으로 남아 있습니다.
- **원하는 모습:** 현재 기능을 나타내는 이름으로 바꾸되 생성·검색·애니메이션 경로를 함께 맞춥니다.

## 5. 구체적인 변경 방법

1. `Damageable`의 표식 생성 키와 `EnemyHealth.LockMarkerName`을 같은 새 이름으로 바꿉니다. 한쪽만 바꾸면 적 몸을 숨길 때 표식 렌더러도 처리할 수 있습니다.
2. `HeroConversion.OldModelName`과 검 검색 조건을 프리팹의 새 이름과 함께 바꿉니다. NGH 원본 프리팹·변환 도구의 참조도 검색합니다.
3. `chg_body`와 원본 모델 이름은 Avatar의 이름·해시 및 애니메이션 경로를 확인한 뒤 변경합니다. `YPH_SourceHumanCalibration.asset`의 문자열만 손으로 고치지 않습니다.
4. 외부 CHG 원본 에셋을 옮긴다면 `.meta`와 GUID를 유지하고 `AttackClipBuilder`, `LocomotionClipBuilder`, `MocapComboBuilder`, `RewindFloatBuilder`의 경로를 함께 갱신합니다. 이번 YPH 작업에서는 해당 원본을 옮기지 않았습니다.

## 6. 영향 범위

- 락온 표식, 적 사망·부활, Hero 변환 도구, Avatar·애니메이션 연결.
- YPH와 NGH가 함께 변경해야 합니다.
- NGH 프리팹의 현재 편집 담당자 확인: 아니오. 처리 전에 확인이 필요합니다.

## 7. 확인 방법

- 락온 표시 중 적 피격·사망·부활 후 표식 표시가 정상인지 확인합니다.
- Hero 변환 도구가 모델·검을 찾고, 대기·걷기·발도·공격 애니메이션이 재생되는지 확인합니다.
- GUID와 파일 참조, Missing Script 유무를 점검합니다.

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 기능은 유지되지만 옛 이름이 남습니다.
- **대안:** 이번에는 공유 문자열과 원본 모델·Avatar 이름을 보존했습니다. 실행 오류를 만들면서 이름만 지우지는 않습니다.
