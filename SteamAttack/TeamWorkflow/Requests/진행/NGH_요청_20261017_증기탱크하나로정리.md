## 1. 한 줄 요약

`Main`·`BossArena` 플레이어에 `YPH.SteamTank`(증기 탱크)가 2개 있습니다. 화승총·칼 회복은 한쪽, 받아치기·시간 역행·HUD는 다른 쪽을 봅니다. 탱크를 **`YPH_SteamBackpack` 프리팹 인스턴스 하나**로 합치고 모두 그것을 보게 해 주세요.

## 2. 대상 파일

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Assets/Scenes/Common/Main.unity` | 씬 | 플레이어 루트에 추가된 `YPH_SteamBackpack` 삭제, 연결 변경 |
| `Assets/Scenes/Common/BossArena_Hyangwonjeong.unity` | 씬 | 같은 구성이 있으면 같은 처리 |
| `Assets/Prefabs/NGH/NGH_Player.prefab` | 프리팹 | `mixamorig:Spine2` 아래 복사본을 `YPH_SteamBackpack` 프리팹 인스턴스로 교체, 탱크 연결 |

## 3. 왜 필요한가

**비유:** 플레이어 등에 물통이 두 개 달려 있는데, 총은 왼쪽 물통 물을 쓰고 시간 역행은 오른쪽 물통 물을 쓰는 상황입니다. 게이지는 한쪽만 보여 줍니다.

| 쓰는 곳 | 보는 탱크 | 찾는 방법 |
|---|---|---|
| `YPH.SteamGun`(화승총 발사 비용), `YPH.SteamHitRefill`(칼 적중 +10) | 씬에서 플레이어 루트에 추가한 `YPH_SteamBackpack` | 인스펙터 연결 `_tank` |
| `YPH.ParryController` | 프리팹 안 `mixamorig:Spine2/YPH_SteamBackpack` | 인스펙터 연결 `_tank` |
| `NGH.TimeRewind` | 자식 중 먼저 찾힌 것(추정: 프리팹 안) | `GetComponentInChildren<SteamTank>()` |
| `NMJ.SteamCylinderGauge`(HUD) | 부모 → 루트 자식 → 씬 전체 순서로 처음 찾힌 것 | `GetComponentInParent` 등 |

- 시간 역행 비용을 70으로 올리면(요청 `시간역행증기70`), 칼로 모은 증기가 아닌 **다른 탱크**에서 70을 검사·지불합니다. 증기를 모아도 시간 역행이 안 되거나, 반대로 0인데 됩니다.
- HUD 게이지가 화승총이 쓰는 탱크와 다르면 게이지가 줄지 않는 것처럼 보입니다.
- 백팩 모델이 두 개 겹쳐 보일 수 있습니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** 탱크 2개(프리팹 안 1, 씬에서 추가 1). 쓰는 곳마다 다른 탱크를 봄
- **원하는 모습:** `NGH_Player.prefab`의 `mixamorig:Spine2` 아래에 **`Prefabs/YPH/YPH_SteamBackpack.prefab`의 프리팹 인스턴스(중첩 프리팹) 하나만** 있음. 위 표의 모든 사용처가 이 탱크를 봄
- **왜 복사본이 아니라 프리팹 인스턴스인가:** 지금 `Spine2` 아래 백팩은 YPH 프리팹과 연결이 끊긴 복사본입니다. YPH가 곧 스팀백 모델을 새것으로 바꾸는데(YPH 프리팹만 수정), 복사본은 따라 바뀌지 않습니다. 프리팹 인스턴스로 두면 YPH가 프리팹을 고칠 때 플레이어에도 자동으로 반영됩니다

## 5. 구체적인 변경 방법

1. YPH 브랜치를 병합합니다.
2. `NGH_Player.prefab`을 프리팹 모드로 엽니다. `mixamorig:Spine2/YPH_SteamBackpack`(복사본)의 Transform 값(위치·회전·크기)을 적어 둡니다. 지금 값: 위치 (0, −0.568, −19.862), 회전 X 약 5.6°(쿼터니언 0.0487, 0, 0, 0.9988), 크기 36
3. Project 창의 `Prefabs/YPH/YPH_SteamBackpack.prefab`을 `mixamorig:Spine2` 아래로 끌어다 놓고 Transform을 **위치 (0, −1.5, −10.3), 회전 쿼터니언 (0.0487, 0, 0, 0.9988), 크기 36**으로 넣습니다. 스팀백이 새 모델로 바뀌어(2026-10-17) 2번의 옛 위치 대신 이 값을 씁니다. YPH 시험 씬(`Scenes/YPH/YPH_MainPlayerTest`)에서 이 값으로 등에 맞는 것을 확인했습니다
4. 복사본을 참조하던 컴포넌트(`ParryController._tank` 등, 복사본 우클릭 → Find References)의 `Tank` 칸을 새 인스턴스로 바꿉니다. `SteamGun`·`SteamHitRefill`이 프리팹에 있으면 그 `Tank` 칸도 새 인스턴스로 연결합니다
5. 복사본을 삭제하고 프리팹을 저장합니다.
6. `Main.unity`를 엽니다. 플레이어 루트 바로 아래에 씬에서 추가한 `YPH_SteamBackpack`이 있으면, 이것을 참조하던 칸(`SteamGun`, `SteamHitRefill` 등 씬 덮어쓰기)을 프리팹 안 인스턴스로 다시 연결한 뒤 삭제하고 저장합니다.
7. `BossArena_Hyangwonjeong.unity`도 같은 구성이면 같은 방법으로 처리합니다.

코드 수정은 없습니다. 크기 36은 `mixamorig` 뼈의 단위(센티미터 기준) 때문이며 그대로 둡니다.

## 6. 영향 범위

- 이 파일을 참조하는 곳: `SteamGun`, `SteamHitRefill`, `ParryController`, `TimeRewind`, NMJ `SteamCylinderGauge`, NGH `PlayerHUD`(꺼져 있음, D-086)
- 같이 영향받을 수 있는 다른 작업자·기능: NMJ HUD 증기 게이지, 시간 역행(NGH), 화승총·받아치기(YPH)
- 씬·프리팹이면: 두 씬과 `NGH_Player`는 NGH·공용 소유. YPH는 `NGH_Player`를 반환했으므로 지금 고치지 않음

## 7. 확인 방법

1. Play 시작 시 Hierarchy에서 `SteamTank`가 붙은 오브젝트가 플레이어 아래 **1개**이고, 파란 프리팹 아이콘(`YPH_SteamBackpack` 인스턴스)
2. 화승총을 쏘면 HUD 증기 게이지가 5씩 줄고, 칼로 적을 때리면 10씩 오름
3. 증기 70 이상에서 시간 역행 사용 → 게이지가 70 줄어듦. 70 미만이면 사용 불가
4. 콘솔에 `Missing`·`NullReference` 없음

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 시간 역행 비용 70이 들어가는 순간 증기 규칙이 어긋납니다. 시연 중 "증기가 있는데 시간 역행이 안 됨" 같은 버그로 보입니다.
- **대안:** 시간 역행 비용 70 적용을 이 정리 뒤로 미룸.
