## 1. 한 줄 요약

강공격의 흰 초승달 바깥 가장자리에 **주홍 칼금 한 줄**과 **베는 방향으로 튀는 불티**를 얹고, 증기가 가득일 때는 **붉은 김**까지 더하는 이펙트입니다. NMJ가 시험판을 만들어 두었으니, 플레이로 보고 **그대로 쓸지 / NGH 이펙트에 직접 넣을지** 골라 주세요.

## 2. 먼저 보는 법 (1분)

1. 공용 `Main` 플레이
2. **Insert** → 개발자 창 → **`검 이펙트`** 버튼을 누를 때마다 바뀝니다
   - `기존` → `C2 붉은 칼금` → `C3 붉은 김` → `자동` (증기 가득이면 C3, 아니면 C2)
3. **우클릭 강공격**을 써 봅니다. 시작 지점 앞 허수아비를 베면 맞는 순간도 볼 수 있습니다

- 일반 공격(1~5타)은 어떤 설정이든 기존 NGH 이펙트 그대로입니다.
- 기본값은 `기존`입니다. 버튼을 누르기 전에는 아무것도 바뀌지 않습니다.

## 3. 어떻게 보이나 (시험판)

| 순간 | C2 붉은 칼금 | C3 붉은 김 (증기 가득) |
|---|---|---|
| 휘두르는 중 | 흰 초승달 바깥 가장자리를 따라 주홍 한 줄. **칼 바로 뒤가 가장 굵고 주황빛으로 뜨겁고**, 오래된 꼬리는 바늘처럼 가늘어지며 검붉게 식음 | C2 + 칼끝 바깥으로 옅은 붉은 김 |
| 맞는 순간 | 칼금 한가운데가 한 번 번쩍. **베는 방향으로** 불티 8개 (헛스윙은 2~3개) | 불티 14개 |
| 사라질 때 | 칼금이 꼬리부터 먹혀 들어가고, 먹히는 경계가 불씨처럼 빛나다 작은 불씨로 흩어짐 | 붉은 김이 위로 올라가며 사라짐 |

## 4. 촌스럽지 않게 지킨 원칙 (정식으로 만들 때도 같이 지켜 주세요)

1. **빛나는 곳은 아주 좁게.** 화면 빛 번짐 기준(블룸 문턱 0.95)을 넘는 건 칼금 한가운데의 가는 심 한 줄뿐입니다. 전체가 번쩍이면 싸 보입니다.
2. **'더하기'로 그리지 않기.** 빛을 더하는 방식은 흰 눈과 흰 초승달 위에서 흰색으로 날아가 주홍이 안 보입니다. 덮어 그려야 보입니다.
3. **비대칭.** 칼 바로 뒤는 두툼하고 꼬리는 바늘처럼 가늘게. 양 끝이 같으면 도장 찍은 것처럼 보입니다.
4. **색은 '식는 순서'로.** 뜨거운 주황 → 주홍 → 검붉음. 한 색에 투명도만 줄이면 밋밋합니다.
5. **불티는 베는 방향으로만.** 사방으로 터뜨리지 않고, 강공격 기준 6~10개를 넘기지 않습니다.
6. **옆에서 보이는 면은 흐리게.** 궤적 면을 옆에서 보면 선 하나로 뭉개져 땅 위의 검은 줄처럼 보입니다. 시험판 초기에 실제로 생겼고, 지금은 고쳤습니다.

## 5. 해 줄 일 (가, 나 중 하나)

**가. 시험판을 그대로 쓴다** (NGH 파일 수정 없음)
- 보고 "좋다 / 이렇게 바꿔 달라"만 알려 주세요.
- NMJ가 기본값을 `자동`으로 바꾸고 개발자 창 버튼을 정리합니다.

**나. NGH 이펙트에 직접 넣는다**
- 시험판 셰이더(아래 6번)를 참고해 `NGH_FX_Slash` 강공격 항목에 칼금 층을 넣어 주세요.
- 넣고 나면 알려 주세요. NMJ 시험판을 지웁니다.

**같이 봐 주면 좋은 것 (선택, 손맛)**
- **강공격 히트스톱:** 맞힐 때 0.07~0.1초 멈춤. 지금은 받아치기에만 있습니다(`CombatBridge.parryHitStop`).
- **흰 초승달이 사라지는 시간:** 지금 시험판 칼금은 흰 초승달과 거의 같이 사라집니다. 칼금이 흰 초승달보다 조금 늦게 남아야 '베고 간 자리'가 보입니다. 흰 초승달이 몇 초에 사라지는지 알려 주시면 맞추겠습니다.
- **꼬리 길이를 '칼이 지난 뒤 흐른 시간'으로:** `AttackFx`가 경로 64점을 구울 때, 각 점을 칼이 지난 시각도 같이 구워 두면 빠르게 벤 구간은 길게, 느린 구간은 짧게 남아 속도가 읽힙니다. 시험판은 칼금에만 이 방식을 따로 쓰고 있습니다.

## 7. 영향 범위

- **NGH 파일은 고치지 않았습니다.**
  - `AttackFx.entries`에서 강공격의 칼 경로(`pathOuter`/`pathInner`)를 읽기만 합니다. 그래서 칼금이 칼과 정확히 겹칩니다.
  - `PlayerController.OnHitLanded`를 듣기만 합니다.
- 칼금은 렌더 큐 3010으로, NGH 흰 이펙트(3000) 위에 그려집니다.
- 칼의 경로 이름(`pathOuter`/`pathInner`/`pathPrefix`/`swingRange`)이나 `OnHitLanded`가 바뀌면 시험판이 같이 고쳐져야 합니다. 바꿀 일이 있으면 알려 주세요.

## 8. 확인 방법

1. 2번 순서대로 `C2` / `C3` / `기존`을 바꿔 가며 강공격
2. 흰 눈 위에서 주홍 칼금이 보이는가
3. 땅에 검은 줄이 생기지 않는가
4. 일반 공격은 그대로인가

## 9. 안 하면 생기는 문제 / 대안

- **안 하면:** 강공격과 일반 공격이 화면에서 잘 구별되지 않고, 증기 가득(붉은 증기, 세계관 법칙 5) 상태가 이펙트로 드러나지 않습니다.
- **대안:** '가'를 고르면 NGH 작업 없이 시험판으로 시연할 수 있습니다.

## 10. 첨부

- C2 / C3 / 기존을 같은 순간(반쯤 그었을 때 · 다 그은 순간 · 사라지는 중)에 찍은 비교 사진이 NMJ 로컬에 있습니다. 필요하면 디스코드로 보내겠습니다.
- 시험판 주요 값 (`NmjSwordSlash.cs`의 `LookC2`/`LookC3`, 셰이더 기본값)

| 값 | C2 | C3 | 뜻 |
|---|---|---|---|
| 칼금이 식는 시간 | 0.32초 | 0.40초 | 칼이 지난 뒤 이 시간이 지나면 꼬리가 다 가늘어짐 |
| 사라지는 시간 | 0.45초 | 0.5초 | 다 그은 뒤 칼금이 먹혀 없어지기까지 |
| 불티 (헛스윙 / 맞힘) | 3 / 8 | 4 / 14 | |
| 칼금 색 | 뜨거움 `(1.0, 0.55, 0.25)` → 주홍 `(0.95, 0.22, 0.10)` → 식음 `(0.48, 0.08, 0.05)` | 같음 | 선형 RGB |
| 심 밝기 | `(3.2, 2.4, 1.9)` | 같음 | 빛 번짐은 여기만 |
