## 1. 한 줄 요약

수류탄은 게임에서 빠졌고(D-028) 화승총은 탄약이 없어졌으므로(D-040), `CombatBridge`의 수류탄 연결과 G키(수류탄 제작)·R키(탄 주머니 충전)를 지워 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/NGH/Player/CombatBridge.cs` | 스크립트 | 수류탄·탄 충전 관련 필드와 코드 삭제 |
| `Main`·`BossArena`·NGH 테스트 씬의 `CombatBridge` 컴포넌트 | 씬 | 필드가 사라지는 것뿐이라 따로 고칠 것 없음 |

## 3. 왜 필요한가

- YPH가 화승총을 기획(탄약 없음, 발당 증기 10)에 맞추면서 `SteamGun`의 탄 주머니(`TryChargePouch`, `PouchRounds`, `PouchCapacity`, `ChamberLoaded`)를 없앱니다.
- 수류탄 스크립트(`SteamGrenadeThrower`, `Grenade`, `GrenadeHandView`)와 프리팹도 지웁니다.
- `CombatBridge`가 이것들을 참조하고 있어서, NGH 쪽 참조가 먼저 빠져야 YPH가 지울 수 있습니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** `CombatBridge`에 `grenadeWeapon`, `thrower`, `grenadeHandView`, `chargeKey`(R), `craftKey`(G) 필드와 처리 코드가 있음
- **원하는 모습:** 화승총·조준·근접 증기 회복만 남음. R·G키는 비어 있음

## 5. 구체적인 변경 방법

1. 필드 삭제: `grenadeWeapon`, `thrower`, `grenadeHandView`, `chargeKey`, `craftKey`, `grenadeShown`, `grenadeShownInitialized`
2. `GrenadeReady` 프로퍼티 삭제
3. `Update()`에서 손 수류탄 표시 블록, R키 `TryChargePouch` 블록, G키 `TryCraft` 블록 삭제
4. `HandleShotStarted()`의 `grenadeWeapon` 분기 삭제, 화승총 로그에서 약실·주머니 값 대신 `gun.CurrentState`만 출력
5. 클래스 요약 주석의 R·G 설명 삭제

## 6. 영향 범위

- 이 파일을 참조하는 곳: 씬의 `CombatBridge` 컴포넌트(직렬화 필드만 사라짐)
- 같이 영향받을 수 있는 다른 작업자·기능: 원거리 무기(YPH). 수류탄 무기 칸이 `WeaponHolder`에 남아 있으면 같이 빼 주세요(2차 병합에서 이미 뺐다면 해당 없음)
- 씬·프리팹이면: 씬 수정 없음

## 7. 확인 방법

1. 컴파일 에러 없음
2. Play에서 R·G를 눌러도 아무 일 없음
3. 화승총 조준·발사, 근접 적중 증기 회복은 그대로

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** YPH가 탄 주머니·수류탄 코드를 지우는 순간 `CombatBridge` 컴파일이 깨짐
- **대안(순서 보장):** 이 요청이 처리될 때까지 YPH는 `TryChargePouch()`, `ChamberLoaded`, `PouchRounds`, `PouchCapacity`를 "삭제 예정" 주석만 단 빈 동작으로 남겨 두고, 처리 확인 후 지움. `[Obsolete]`는 NGH 파일에 컴파일 경고를 내므로 쓰지 않음

## 9. 첨부

- 관련 결정: D-028(수류탄 제외), D-040(탄약 없음)
