## 1. 한 줄 요약

개발자 창(NMJ)을 `` ` ``(~ 키)로도 열게 했는데, `NGH.TimeRewind`의 디버그 표시도 같은 키라 개발자 창을 열면 왼쪽 위 "Time Rewind / Recorded …" 글자가 같이 켜집니다. 디버그 표시 키를 다른 키로 옮겨 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/NGH/TimeRewinder/TimeRewind.cs` (133줄 `debugGUIToggleKey = Key.Backquote`) | 스크립트 | 변경 (기본값) |
| `Assets/Prefabs/NGH/NGH_Player.prefab` (`debugGUIToggleKey: 4`) | 프리팹 | 변경 |

## 3. 왜 필요한가

사용자 요청으로 개발자 창(무적·원펀맨·구간 이동 등)을 `` ` ``으로 열게 했습니다(Insert도 그대로). 개발자 창은 NMJ 코드(`NMJ.NmjDevWindow`)이고, 디버그 표시 키는 NGH 코드·프리팹이라 NMJ가 고치지 않았습니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** `` ` ``을 누르면 개발자 창이 열리면서 시간 역행 디버그 글자도 함께 켜짐 (한 번 더 누르면 둘 다 꺼짐)
- **원하는 모습:** `` ` ``은 개발자 창만 열고, 디버그 표시는 다른 키로 켬

## 5. 구체적인 변경 방법

1. `TimeRewind.cs` 133줄 기본값을 비어 있는 키로 바꿉니다. 예: `Home` (코드·키 예약표 어디에서도 안 씀. F1~F11은 퀘스트 디버그, F9~F12는 시연자 키라 피함)
2. `NGH_Player.prefab`의 `TimeRewind` 컴포넌트 `Debug GUI Toggle Key`도 같은 키로 바꿉니다 (프리팹에 4 = Backquote로 저장돼 있음)
3. (선택) 디버그 표시를 개발자 창의 버튼으로 옮기고 싶으면 NMJ에게 알려 주세요 — 공개 속성 하나(`public bool ShowDebugGUI { get; set; }`)만 있으면 개발자 창에 버튼을 붙일 수 있습니다

```csharp
[SerializeField] private Key debugGUIToggleKey = Key.Home;
```

## 6. 영향 범위

- 이 파일을 참조하는 곳: 없음 (키 값만 바뀜)
- 같이 영향받을 수 있는 다른 작업자·기능: `YPH_HeroPlayerIntegration.prefab`에도 `TimeRewind`가 있음 (`showDebugGUI: 1`로 저장됨) — 같은 키로 맞추면 좋음
- 씬·프리팹이면: 지금 이 파일을 고치는 사람이 있는지 확인했는가 (아니오 — NGH 확인 필요)

## 7. 확인 방법

공용 Main에서 Play → `` ` `` → 개발자 창만 열리고 왼쪽 위 "Time Rewind" 글자는 나오지 않는다. 새 키를 누르면 디버그 글자가 켜진다.

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 개발자 창을 `` ` ``으로 열 때마다 디버그 글자가 같이 켜지고 꺼짐. 시연 중 개발자 창을 쓰면 화면에 디버그 글자가 보일 수 있음
- **대안(요청이 어려울 때 내가 할 수 있는 우회책):** 개발자 창을 Insert로만 열기 (지금도 Insert는 됨)
