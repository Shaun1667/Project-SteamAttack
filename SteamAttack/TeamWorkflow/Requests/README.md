# 개발자 요청

남의 영역(다른 작업자 폴더, `Common`, `ProjectSettings`, 공용 씬·프리팹) 수정이 필요할 때 쓰는 요청서입니다(D-057).

- 양식: [요청문서_템플릿.md](../Templates/요청문서_템플릿.md)
- 파일명: `<요청자 이니셜>_요청_YYYYMMDD_짧은제목.md`
- 폴더: 새 요청과 처리 중인 요청은 `진행/`, 처리가 끝난 요청(`완료`·`반려`)은 `완료/`에 둡니다. 상태를 바꾸면 폴더도 옮깁니다. 검사 스크립트가 상태와 폴더가 다르면 알려 줍니다.
- 만든 뒤 커밋하고 받는 사람에게 알립니다. 받는 사람은 처리 후 요청서 맨 아래 `처리 기록`과 머리의 `상태`를 고칩니다.
- 열린 요청(상태가 `완료`·`반려`가 아닌 것)은 [현황](../Meetings/현황.md)에 받는 사람별로 모입니다.
