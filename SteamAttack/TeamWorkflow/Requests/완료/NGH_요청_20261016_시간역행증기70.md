# 요청: 공용 플레이어의 시간 역행 증기 비용을 70으로

| 항목 | 내용 |
|---|---|
| 요청일 | 2026-10-16 |
| 요청자 | NMJ |
| 받는 사람 | NGH |
| 우선순위 | 🔴 막힘 |
| 희망 기한 | 2026-10-18 |
| 관련 기획서 | `Design/전투/시간역행.md` (D-042) |
| 상태 | 완료 |

## 1. 한 줄 요약

공용 플레이어의 `TimeRewind` 증기 비용이 0입니다. 70으로 바꿔 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| 공용 플레이어 프리팹의 `TimeRewind` 컴포넌트 | 프리팹 | 값 변경 |

## 3. 왜 필요한가

기획은 시간 역행 1회에 증기 70입니다(D-042). 스크립트 기본값은 70인데 프리팹 값이 0이라 무제한으로 쓸 수 있습니다. HUD의 逆 눈금도 70 기준입니다.

## 4. 현재 상태 → 원하는 상태

| 항목 | 현재 | 원하는 모습 |
|---|---|---|
| `TimeRewind` 증기 비용 | 0 | 70 |

## 5. 구체적인 변경 방법

프리팹 값을 70으로 바꿉니다. 테스트 때문에 0으로 둔 것이면 NMJ에게 알려 주세요.

> 받아치기 작업 동안 공용 플레이어 프리팹은 YPH가 작업합니다(D-081, D-083). 그동안이면 YPH에게 값 변경을 부탁해 주세요.

## 6. 영향 범위

- NMJ HUD 逆 눈금

## 7. 확인 방법

1. 증기 70 미만에서 Q → 시간 역행 안 됨
2. 70 이상에서 Q → 되감기 후 증기 70 감소

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 시간 역행이 공짜라 증기 규칙이 성립하지 않음
- **대안:** 없음
