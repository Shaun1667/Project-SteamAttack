## 1. 한 줄 요약

YPH가 받아치기를 다시 만들기 전까지, 공용 플레이어의 옛 `PlayerParry` 값만이라도 회의 결정에 맞춰 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| 공용 플레이어 프리팹의 `PlayerParry` 컴포넌트 | 프리팹 | 값 변경 |

## 3. 왜 필요한가

2026-10-15 회의 결정: 받아치기에 성공해도 증기 회복·추가 소모 없음, 화승총 발사 비용만, 실패 시 차감은 기능만 두고 미적용(D-067, D-069). 지금 값은 시도 시 증기 10, 성공 시 +20입니다.

## 4. 현재 상태 → 원하는 상태

| 항목 | 현재 | 원하는 모습 |
|---|---|---|
| 시도 시 증기 | −10 | 0 (화승총 발사 비용은 따로) |
| 성공 시 증기 | +20 | 0 |

## 5. 구체적인 변경 방법

인스펙터의 증기 소모·획득 값을 0으로 바꿉니다. 코드 수정은 필요 없습니다.

## 6. 영향 범위

- YPH 재구현 요청(`NGH_요청_20261015_받아치기공통규약적용.md`): 재구현이 끝나면 옛 `PlayerParry`는 지워짐

## 7. 확인 방법

1. 받아치기 성공·실패 모두 증기가 바뀌지 않음

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 재구현 전 테스트에서 증기 흐름이 기획과 다름
- **대안:** YPH 재구현을 기다림

## 9. 첨부

- 받아치기 작업 동안 공용 플레이어 프리팹은 YPH가 작업합니다(D-081, D-083). 그동안이면 YPH가 값을 바꿉니다
