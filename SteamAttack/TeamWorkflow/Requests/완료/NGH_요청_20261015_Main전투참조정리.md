## 1. 한 줄 요약

`Main`에 남은 삭제된 CHG 병사 배치를 제거하고, 모델 교체 후의 현재 총 슬롯에 `CombatBridge.gunWeapon`을 연결해 주세요. CHG 원본 에셋을 복구하는 요청이 아닙니다.

**2026-10-15 정정:** 처음에는 삭제 배경을 확인하지 않고 원본 복구를 요청했습니다. 사용자 지적 후 D-052와 삭제 커밋 `623cb47`을 확인해, 확정된 삭제를 유지하고 씬에 남은 참조를 정리하는 요청으로 고쳤습니다.

## 2. 대상 파일

아래 에셋 경로는 Unity 프로젝트 루트 `SteamAttack/` 기준입니다.

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Assets/Scenes/Common/Main.unity` | 씬 | 삭제된 CHG 병사 배치 제거, 현재 무기 참조 연결 |
| `Assets/Prefabs/NGH/NGH_Player.prefab` | 프리팹 | Main 참조와 실제 무기 구성 비교. 프리팹 자체 변경 필요 여부는 NGH 판단 |

## 3. 왜 필요한가

- **병사 배치:** [D-052](../../Meetings/README.md)와 [현재 인수 분담](../../Design/00_프로젝트.md)에 따라 CHG 작업물을 정리한 상태입니다. 2026-10-13 커밋 `623cb47`은 병사 프리팹과 관련 자산을 의도적으로 삭제했고, Main의 병사 2개를 에디터에서 제거해야 한다고 명시합니다. 현재 Missing Prefab 오류는 이 배치가 남아 있어서 발생합니다.
- **총 연결:** 별도 커밋 `10a4c1a`(2026-10-13, 플레이어 모델 교체)에서 Main이 가리키던 옛 Weapon 객체 ID가 사라졌습니다. Play 중 `CombatBridge.gunWeapon`은 null이었습니다. `GunReady`와 `HandleShotStarted`가 이 참조를 사용하므로 현재 총 슬롯으로 다시 연결해야 일반 입력부터의 조준·발사를 확인할 수 있습니다.

두 항목은 A1 발사 규칙 변경으로 생긴 문제가 아닙니다. 병사 에셋 삭제가 의도됐다는 사실과, 현재 Main의 일반 조작 검증이 끝나지 않았다는 사실을 구분합니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** 삭제된 병사 인스턴스가 Main에 남았고 총의 무기 칸도 이전 객체를 가리킵니다. 저장된 `gunWeapon` 값이 처음부터 0인 것은 아닙니다. Main의 fileID `1442819864`는 NGH_Player의 원본 객체 `4558058189110418245`를 가리키지만 모델 교체 커밋에서 해당 객체 ID가 제거됐습니다.
- **원하는 모습:** 삭제된 CHG 병사 배치가 정리되고 현재 총 무기 칸이 연결되어, 현재 적 또는 별도 시험 표적에 일반 조작으로 화승총의 발당 증기 10·피해 20을 확인할 수 있습니다. 정식 적 모델·AI 제작은 YPH의 기존 분담을 따릅니다.

## 5. 구체적인 변경 방법

1. Main·NGH_Player를 편집 중인 팀원이 있는지 먼저 확인하고 씬 담당자를 정합니다.
2. Main에서 아래 두 GUID를 가리키는 Missing Prefab 배치 `chg_Soldier1`·`chg_Soldier2`를 제거합니다. 커밋 `623cb47`의 후속 정리이며, 삭제된 원본 에셋을 되살리지 않습니다.
3. Main의 NGH 플레이어에 붙은 `CombatBridge`를 선택하고 `gunWeapon`을 실제 `WeaponHolder`의 총 슬롯과 같은 `NGH.Weapon` 컴포넌트로 연결합니다. 무기 교체로 원본 객체가 바뀌었다면 씬의 다른 무기 참조도 확인합니다.
4. [사격 전 발사 가능 확인 요청](NGH_요청_20261015_사격전발사가능확인.md)과 [수류탄·탄 충전 키 제거 요청](NGH_요청_20261015_수류탄과탄충전키제거.md)은 별도 요청으로 처리합니다. 이번 문서는 Main에 남은 이전 전투 참조 정리만 다룹니다.

## 6. 영향 범위

- 이 파일을 참조하는 곳: Main 시작 흐름과 해당 씬의 플레이어·적 전투.
- 같이 영향받을 수 있는 작업자·기능: NGH 입력·장비, YPH 화승총·조준, 기존 적 구성.
- 씬·프리팹 편집 중인 사람 확인: **아니오.** YPH는 읽기와 저장 없는 Play 검사만 했습니다. 실제 수정 전 NGH가 확인해야 합니다.
- YPH 주인공 모델·HeroPlayer·Cloth 테스트의 미커밋 작업은 이 요청의 수정 대상이 아닙니다.

## 7. 확인 방법

1. Main을 열 때 아래 Missing Prefab 오류 두 개가 사라집니다.
2. Play에서 `CombatBridge.gunWeapon`이 null이 아니고, 현재 총 슬롯의 컴포넌트와 같습니다.
3. 일반 장착·발도·조준·발사 조작으로 충분한 HP의 적에게 피해 20, 탱크 증기 −10, 명중 회복 없음이 확인됩니다. 조작 제한은 사격 전 확인 요청의 적용 여부와 나눠 검사합니다.
4. Domain Reload·Scene Reload를 끈 현재 설정에서 Play를 멈췄다가 다시 실행해 같은 결과를 확인합니다.

YPH는 입력을 거치지 않고 기존 `SteamGun`을 직접 호출하는 검사에서 기존 `EnemyDamageRelay`·`EnemyHealth`를 통한 HP 100→80, 증기 50→40을 연속 두 번 확인했습니다. 런타임 적 HP와 조준 원점만 시험용으로 조절했으며 에셋은 저장하지 않았습니다. 이 결과는 일반 조작 통합 검증을 대신하지 않습니다.

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** Main에 삭제된 에셋 오류가 남고, 기존 총 입력 연결도 확인할 수 없습니다. YPH 시험 씬에서 통과한 A1 구현 결과를 무효로 만드는 것은 아닙니다.
- **대안:** YPH 시험 씬에서 A1 규칙을 검증할 수 있습니다. 완료한 검사와 한계는 [원거리 무기 기능 문서](../../Features/원거리무기.md)의 12번에 기록했습니다.
