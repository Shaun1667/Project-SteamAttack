## 1. 한 줄 요약

좌클릭으로 사격 동작을 시작하기 전에 "지금 쏠 수 있나?"를 먼저 묻고, 쏠 수 없으면 사격 동작을 시작하지 않게 해 주세요.

## 2. 대상 파일

| 경로 | 종류 (스크립트/씬/프리팹/설정/기타) | 수정 방식 (추가/변경/삭제) |
|---|---|---|
| `Assets/Scripts/NGH/Player/PlayerController.cs` | 스크립트 | 사격 요청 전 확인 창구 추가 |
| `Assets/Scripts/NGH/Player/CombatBridge.cs` | 스크립트 | 확인 창구에 화승총 조건 연결 |

## 3. 왜 필요한가

기획서 규칙은 "우클릭 조준 중 좌클릭으로 발사", "증기가 10 미만이면 사격 불가"입니다. 지금은 `PlayerController.ReadAttackInput()`이 원거리 무기일 때 좌클릭만 보고 바로 `Request(ActionState.Shot)`을 부릅니다(673행). 화승총이 발사 가능한지는 그 뒤 `ShotStarted` → `CombatBridge.HandleShotStarted()` → `SteamGun.TryFire()`에서야 확인합니다. 그래서 증기가 없거나 조준하지 않아도 **쏘는 동작이 재생**됩니다. 빌드 v0.2 플레이테스트에서 "총알 없으면 안 쏴지도록"으로 지적된 문제입니다.

좌클릭을 읽고 사격 상태를 시작하는 코드가 NGH 파일 안에 있어서 요청합니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** 원거리 무기를 들고 좌클릭하면 언제나 사격 동작 → 그 뒤 총이 못 쏘면 아무 일도 없음
- **원하는 모습:** 좌클릭 → 쏠 수 있으면 지금처럼 사격 동작 + 발사. 쏠 수 없으면 사격 동작 없이 실패 피드백만(딸깍 소리, 증기 부족이면 증기 게이지 깜빡임·"증기 부족" 문구 — 피드백은 YPH가 만듦)

## 5. 구체적인 변경 방법

YPH가 `SteamGun`에 아래 두 가지를 10/15에 추가합니다(A1 작업).

- `public bool CanFire` — 재장전이 끝났고 증기가 10 이상이면 true
- `public void NotifyFireBlocked()` — 쏠 수 없을 때 실패 피드백 재생

NGH 쪽은 다음처럼 바꿔 주세요. 이름과 형태는 편하게 바꿔도 됩니다.

1. `PlayerController`에 사격 확인 창구를 추가합니다.

```csharp
/// <summary>사격 동작을 시작해도 되는지 묻는 창구. null이면 항상 허용. false면 사격 동작을 시작하지 않는다.</summary>
public System.Func<Weapon, bool> ShotGate;

// ReadAttackInput()의 원거리 분기
if (mouse.leftButton.wasPressedThisFrame)
{
    Weapon current = weapons ? weapons.Current : null;
    if (ShotGate == null || ShotGate(current)) Request(ActionState.Shot);
}
```

2. `CombatBridge`에서 창구에 화승총 조건을 연결합니다(`OnEnable`에서 등록, `OnDisable`에서 null).

```csharp
private bool CanStartShot(Weapon weapon)
{
    if (weapon != gunWeapon || gun == null) return true;      // 화승총이 아니면 관여하지 않음
    bool aiming = GunReady && Mouse.current != null && Mouse.current.rightButton.isPressed;
    if (aiming && gun.CanFire) return true;
    gun.NotifyFireBlocked();                                   // 실패 피드백은 YPH가 처리
    return false;
}
```

## 6. 영향 범위

- 이 파일을 참조하는 곳: `ShotStarted`를 구독하는 `CombatBridge`. 근접 공격 입력은 바꾸지 않음
- 같이 영향받을 수 있는 다른 작업자·기능: 원거리 무기(YPH)
- 씬·프리팹이면: 해당 없음(스크립트만)

## 7. 확인 방법

1. 화승총 장착, 우클릭 없이 좌클릭 → 사격 동작 없음, 딸깍 소리
2. 증기 10 미만에서 조준 + 좌클릭 → 사격 동작 없음, 증기 부족 피드백
3. 증기 10 이상에서 조준 + 좌클릭 → 지금처럼 사격 동작 + 발사, 증기 −10
4. 환도 들고 좌클릭 → 근접 공격 그대로

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 쏠 수 없는데 쏘는 동작이 나와서 시연에서 버그처럼 보임
- **대안:** `CombatBridge`에서 실패 시 사격 동작을 바로 취소하는 방법이 있지만, 동작이 잠깐 보여서 권하지 않음

## 9. 첨부

- 관련 결정: D-040(원거리 무기), D-061(받아치기 담당과는 별개)
- `SteamGun.CanFire`, `NotifyFireBlocked`는 YPH 브랜치에 10/15 커밋 예정. 그 전에 작업하면 컴파일 에러가 나므로 YPH 커밋을 받은 뒤 진행
