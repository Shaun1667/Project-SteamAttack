## 1. 한 줄 요약

적에게 살아 있는지 확인할 속성과 피해를 받을 공개 메서드를 제공해 주세요.

## 2. 대상 파일

| 경로 (`Assets/` 기준) | 종류 | 수정 방식 |
|---|---|---|
| `Scripts/NGH/NGH_EnemyAI.cs` 또는 별도 NGH HP 컴포넌트 | 스크립트 | 피해·사망 API 추가 |
| 실제 사용하는 NGH 적·보스 프리팹 | 프리팹 | 피해 컴포넌트 및 태그 확인 |

## 3. 왜 필요한가

총과 수류탄은 살아 있는 적에게 피해를 준 뒤 증기를 회복합니다. 현재 `NGH_EnemyAI`에는 HP·`TakeDamage`·`IsAlive`가 없어 적 추적·공격과 피해 처리를 연결할 수 없습니다.

## 4. 현재 상태 → 원하는 상태

- 현재: NGH AI 코드는 이미 작업 트리에 있습니다. YPH 전투는 자체 `YPH_TargetDummy`로만 피해를 확인합니다.
- 원하는 모습: NGH가 HP와 사망·풀 반환을 관리하고 YPH는 공개 API를 감싸는 어댑터를 별도로 붙입니다.

## 5. 구체적인 변경 방법

1. 피해 담당 컴포넌트에 아래 형태를 제공해 주세요. HP 이름과 내부 구현은 NGH가 결정합니다.

```csharp
public bool IsAlive { get; }
public void TakeDamage(float amount, UnityEngine.Vector3 hitFrom);
```

2. `hitFrom`은 총의 조준 원점 또는 수류탄 폭발 위치입니다. 죽은 대상은 추가 피해를 받지 않도록 하고, 풀에서 다시 꺼낼 때 HP·생존 상태를 초기화해 주세요.
3. 피해 컴포넌트와 후속 YPH 어댑터가 붙을 오브젝트는 일반 적 `Enemy`, 보스 `Boss` 태그로 맞춰 주세요. 자식 콜라이더에서 `GetComponentInParent`로 찾을 수 있어야 합니다.
4. 사망 직후 같은 호출 안에서 오브젝트를 즉시 파괴하지 않는 방식(일반 `Destroy` 또는 비활성화/풀 반환)을 알려 주세요. 명중 후 태그를 읽어 치명타 회복을 처리합니다.
5. API가 확정되면 YPH가 `YPH_IDamageable` 어댑터를 작성합니다. NGH가 YPH 스크립트에 직접 의존할 필요는 없습니다.

## 6. 영향 범위

- 참조: 적 AI의 사망 처리, 풀 재사용, 피격 연출.
- 다른 작업자: YPH 총·폭발 피해, CHG 근접 공격의 공통 피해 연결.
- 씬·프리팹 동시 수정 여부: 아직 확인하지 않았습니다. 담당자가 확인 후 수정해 주세요. 이번 작업에서는 NGH 파일을 수정하지 않았습니다.

## 7. 확인 방법

총 한 발에 HP -1, 폭발에 적당 HP -3, 여러 자식 콜라이더여도 폭발 한 번에 한 번만 피해를 받는지 확인합니다. 죽은 적으로 증기를 회복하지 못해야 하며 마지막 타격은 회복해야 합니다. 풀 재사용 뒤에도 살아 있는 적으로 다시 맞아야 합니다.

## 8. 안 하면 생기는 문제 / 대안

- 안 하면: 실제 NGH 적과 전투를 연결할 수 없습니다.
- 대안: YPH 전투 시험 씬의 개발 표적을 사용합니다.
