## 1. 한 줄 요약

CHG·NGH·YPH의 API 연결 순서와 플레이어·적 충돌 레이어를 확정해 주세요.

## 2. 대상 파일

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `SteamAttack/ProjectSettings/TagManager.asset` | 설정 | Player·Enemy 레이어 정의 검토 |
| 공동 플레이어·적 프리팹과 통합 씬 | 프리팹·씬 | 담당 지정 후 레이어·컴포넌트 연결 |
| 각 담당 브랜치 | Git | 통합 순서·시점 합의 |

## 3. 왜 필요한가

카메라에서 쏘는 광선은 플레이어 몸을 지나 적이나 벽에서 멈춰야 합니다. 현재 전용 레이어가 없어 YPH는 여러 광선 결과 중 플레이어 루트 아래 콜라이더를 제외합니다. 총·수류탄의 실제 플레이어·적 연결에는 담당자 API 합의가 필요합니다.

## 4. 현재 상태 → 원하는 상태

- 현재: CHG·NGH 코드가 이미 이 작업 트리에 있으나 전투 API 연결은 별도입니다. `Enemy`·`Boss` 태그와 기본 `Player` 태그는 사용할 수 있지만 사용자 정의 Player·Enemy 레이어는 비어 있습니다. 이번 작업에서 ProjectSettings는 수정하지 않았습니다.
- 원하는 모습: 태그(피해 대상 구분)와 레이어(물리 검사 대상)를 구분해 정하고, 통합 씬을 한 명이 책임지고 저장합니다.

## 5. 구체적인 변경 방법

1. CHG 명중 이벤트·입력 연결과 NGH 피해 API 요청이 확정되는 순서를 정해 주세요. 관련 요청 문서 두 건이 같은 폴더에 있습니다.
2. 프로젝트 전체에서 충돌하지 않는 레이어 번호에 `Player`·`Enemy`를 정의할 담당자를 지정해 주세요. 기존 태그는 유지합니다.
3. 플레이어 몸 콜라이더를 Player 레이어, 적 콜라이더를 Enemy 레이어에 배치합니다. 총 검사에서 Player는 제외하되 지형·벽은 포함해야 합니다. 폭발 검사에는 Player와 Enemy를 모두 포함합니다.
4. 적용 후 YPH가 현재 16개 버퍼 광선 검사를 단일 `Physics.Raycast`로 바꾸는 후속 작업을 진행합니다. 이번 단계의 코드는 `_ignoreRoot`로 자기 몸을 제외합니다.
5. YPH 어댑터 → 실제 플레이어 백팩·총·수류탄 참조 연결 → 임시 입력 제거 → 통합 피해·회복 시험 순으로 진행합니다. Main 병합은 팀장이 수행합니다.

## 6. 영향 범위

- 참조: 모든 물리 레이어 마스크, 플레이어·적 콜라이더와 카메라 컬링 마스크.
- 다른 작업자: CHG 플레이어, NGH AI/투사체, YPH 광선/폭발.
- 씬·프리팹 동시 수정 여부: 아직 확인하지 않았습니다. 공동 씬 편집 담당과 편집 시간을 정해야 합니다.

## 7. 확인 방법

광선이 자기 몸을 통과하고 벽에서 멈추며, 적·보스를 맞히는지 확인합니다. 폭발은 플레이어도 피해를 받지만 적 명중만 증기를 회복해야 합니다. 레이어 변경 뒤 기존 근접·적 공격과 카메라 표시도 함께 확인합니다.

## 8. 안 하면 생기는 문제 / 대안

- 안 하면: 공동 씬 연결을 확정할 수 없고, 광선 위에 콜라이더가 16개 넘게 겹치면 가까운 대상을 놓칠 수 있습니다.
- 대안: 현재 `_ignoreRoot` 방식과 YPH 독립 시험 씬을 유지합니다.
