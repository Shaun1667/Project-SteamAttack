## 1. 한 줄 요약

지금은 우클릭으로 조준하거나 쏴도 캐릭터가 **이동 방향**을 봅니다. 총알은 **카메라가 보는 방향**으로 나갑니다. 조준 중(우클릭 유지)과 사격 순간에는 캐릭터 몸이 카메라 정면을 보게 해 주세요.

## 2. 대상 파일

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Assets/Scripts/NGH/Player/PlayerController.cs` | 스크립트 | 조준 중 바라볼 방향 추가 (변경) |
| `Assets/Scripts/NGH/Player/CombatBridge.cs` | 스크립트 | 조준 여부를 `PlayerController`에 전달 (변경, 한 줄) |

## 3. 왜 필요한가

**비유:** 지금은 옆을 보고 걸어가면서 총을 쏘면, 총알만 정면(카메라 쪽)으로 날아갑니다. 사람은 옆을 보는데 총알은 앞으로 나가니 어색하고, 어디를 쏘는지 몸으로 알 수 없습니다.

- `YPH.SteamGun`은 카메라 위치의 `_aimOrigin`에서 카메라 정면으로 광선을 쏴서 맞힙니다(히트스캔). 그래서 **맞는 방향은 이미 카메라 방향**입니다.
- 그런데 몸 방향은 `PlayerController`가 정합니다.
  - 이동: 대기 중 전방향·전투 중 W/A/D는 `face = moveDir`(이동 방향)
  - 사격 시작: `FaceAttackDirection(moveDir)` → 락온 대상이 없으면 이동 방향, 입력이 없으면 그대로
- 결과: 조준·사격하는 동안 몸, 화승총 모델, 총구 섬광이 총알 방향과 어긋납니다.

## 4. 현재 상태 → 원하는 상태

- **현재:** 조준(우클릭 유지)·사격 중에도 이동 방향을 봄
- **원하는 모습:**
  - 조준 중에는 **락온과 같은 방식**으로 움직임: 몸은 카메라 정면(수평)을 보고, A/D는 옆걸음, S는 뒷걸음, 입력이 없어도 카메라 쪽으로 돎
  - 사격 순간에는 즉시 카메라 정면을 봄(조준 없이 쏘는 경우 포함)
  - 달리기(Shift)는 조준이 풀린 상태에서만. 조준 중 달리기 입력은 무시하거나 조준 해제 중 어느 쪽이든 NGH 판단(지금 조준 이동 속도는 0.5배)

## 5. 구체적인 변경 방법

이미 있는 **락온 이동 코드를 재사용**합니다. "락온 대상 방향" 대신 "카메라 정면"을 쓰는 것만 다릅니다.

1. `PlayerController`에 공개 필드를 추가합니다. `MoveSpeedMultiplier`처럼 `CombatBridge`가 매 프레임 넣어 줍니다.

```csharp
public float MoveSpeedMultiplier = 1f;
public bool FaceCameraWhileAiming;   // 조준 중이면 CombatBridge가 true로 넣음
```

2. 바라볼 방향을 구하는 함수를 하나 둡니다.

```csharp
// 락온 대상이 있으면 그쪽, 조준 중이면 카메라 정면, 둘 다 아니면 영(0) 벡터
Vector3 FocusDirection()
{
    if (lockTarget) return Flat(lockTarget.transform.position - transform.position);
    if (FaceCameraWhileAiming && cameraTransform) return Flat(cameraTransform.forward);
    return Vector3.zero;
}
```

3. 이동 부분에서 `else if (lockTarget)` 두 곳(입력 있을 때 옆걸음 분기, 입력 없을 때 바라보기)을 `FocusDirection()`으로 바꿉니다.

```csharp
Vector3 focus = FocusDirection();
...
else if (focus.sqrMagnitude > 0.0001f)        // 기존: else if (lockTarget)
{
    face = focus;                              // 기존: Flat(lockTarget.transform.position - transform.position)
    // 아래 옆걸음·뒷걸음 계산은 그대로
}
...
else if (focus.sqrMagnitude > 0.0001f)        // 입력이 없을 때
{
    face = focus;
}
```

4. 사격 순간 방향: `FaceAttackDirection`에서 사격(`ActionState.Shot`)이고 카메라가 있으면 카메라 정면을 봅니다.

```csharp
void FaceAttackDirection(Vector3 moveDir, bool isShot)
{
    Vector3 focus = FocusDirection();
    if (isShot && cameraTransform) focus = Flat(cameraTransform.forward);   // 총알 방향과 맞춤
    Vector3 dir = focus.sqrMagnitude > 0.0001f ? focus
                : (moveDir.sqrMagnitude > 0.01f ? moveDir : Vector3.zero);
    if (dir.sqrMagnitude > 0.0001f) transform.rotation = Quaternion.LookRotation(dir);
}
```

5. `CombatBridge.LateUpdate`에 한 줄 추가합니다(이미 `MoveSpeedMultiplier`를 넣는 곳).

```csharp
if (player != null) player.FaceCameraWhileAiming = aim != null && aim.IsAiming;
```

> 회전 속도는 기존 `turnSpeed`(720도/초)를 그대로 씁니다. 조준을 시작할 때 너무 느리게 돌면 조준 중에만 더 빠르게 돌려도 됩니다.

## 6. 영향 범위

- 이 파일을 참조하는 곳: 락온(`lockTarget`) 이동, 근접 공격 방향(`FaceAttackDirection`), `CombatBridge`의 조준 연결
- 같이 영향받을 수 있는 다른 작업자·기능: YPH 화승총(`SteamGun`, `RifleMotion` 상체 레이어)·조준 연출(`AimController`). YPH 쪽 수정은 없음
- 씬·프리팹이면: 해당 없음(스크립트만)

## 7. 확인 방법

1. `Main` Play → TAB으로 화승총을 들고 우클릭 → 마우스를 좌우로 돌리면 캐릭터 몸이 카메라 정면을 따라 돎
2. 조준한 채 A/D → 옆걸음, S → 뒷걸음, 몸은 계속 카메라 정면
3. 이동 중 좌클릭 사격 → 쏘는 순간 몸·총구가 카메라 정면, 총구 섬광과 총알 방향이 일치
4. 우클릭을 떼면 기존처럼 이동 방향을 봄. 락온·환도 공격 방향은 기존과 같음

## 8. 안 하면 생기는 문제 / 대안

- **안 하면:** 시연에서 옆을 보고 걸으며 쏘면 총알이 엉뚱한 곳에서 나오는 것처럼 보입니다. 지붕 위 궁수를 쏘는 장면(시연 흐름 ①·③)이 어색합니다.
- **대안:** YPH 컴포넌트가 `LateUpdate`에서 플레이어 회전을 덮어쓰는 방법도 있습니다. 하지만 `PlayerController`의 `TurnTowards`와 매 프레임 싸우고, 이동 애니메이션(옆걸음)도 맞지 않아 추천하지 않습니다.
