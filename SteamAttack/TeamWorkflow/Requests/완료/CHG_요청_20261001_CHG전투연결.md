## 1. 한 줄 요약

근접 명중을 외부에서 받을 이벤트를 추가하고, 기존 무기 슬롯·입력에서 총과 수류탄을 호출하는 방법을 합의해 주세요.

## 2. 대상 파일

경로는 Unity 프로젝트의 `Assets/` 기준입니다.

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Scripts/CHG/chg_PlayerController.cs` | 스크립트 | 명중 이벤트 추가, 입력 연결 합의 |
| `Scripts/CHG/chg_WeaponHolder.cs` | 스크립트 | 슬롯에 원거리 장비를 올리는 방법 합의 |
| `Prefabs/CHG/chg_Player.prefab` | 프리팹 | 대상이 실제 사용하는 플레이어인지 확인 후 루트 태그 지정 |
| `Prefabs/CHG/chg_Dummy.prefab` 및 CHG 시험 씬의 사용 인스턴스 | 프리팹·씬 | 사용하는 표적의 태그 확인 |

## 3. 왜 필요한가

YPH는 적을 맞힐 때 증기를 회복합니다. 현재 `DoHit`은 `chg_Damageable.TakeDamage`를 직접 호출하므로 외부 회복 코드가 실제 명중을 알 수 없습니다. 총·수류탄은 입력을 모르고 공개 메서드로만 동작합니다.

## 4. 현재 상태 → 원하는 상태

- 현재: CHG 코드가 이 작업 트리에 있고, `chg_Damageable`의 `IsAlive`·`TakeDamage(float, Vector3)`도 있습니다. `DoHit`의 성공 명중 이벤트는 없습니다. `chg_WeaponHolder`는 `chg_Weapon` 최대 3개와 Tab 전환을 담당합니다.
- 원하는 모습: 이미 있는 생존·공격당 중복 검사 뒤의 실제 명중을 이벤트로 알리고, 선택 장비에 따라 좌클릭을 한 곳에서 분배합니다.

## 5. 구체적인 변경 방법

1. `chg_PlayerController`에 다음 이벤트를 추가해 주세요.

```csharp
/// <summary>살아 있던 대상을 실제로 맞힌 뒤 한 번 알립니다.</summary>
public event System.Action<chg_Damageable> OnHitLanded;
```

2. `DoHit`의 기존 `d.TakeDamage(dmg, transform.position);` 바로 다음에 `OnHitLanded?.Invoke(d);`를 추가해 주세요. 기존 `!d.IsAlive`와 `_hitThisSwing` 검사를 유지하고, 피해 후 생존 여부를 다시 검사하지 않습니다. 마지막 타격도 회복 대상입니다.
3. 일반 적의 피해 컴포넌트 오브젝트는 `Enemy`, 보스는 `Boss`, 플레이어 루트는 `Player` 태그인지 확인해 주세요. 태그는 이미 등록되어 있습니다.
4. 근접·총·수류탄을 기존 3슬롯에 배치할 방식과 `chg_Weapon` 연출 재사용 범위를 합의해 주세요. YPH는 이번 단계에서 CHG 타입을 직접 참조하지 않았습니다.
5. 통합 시 좌클릭은 장비에 따라 `YPH_SteamGun.TryFire()` 또는 `YPH_SteamGrenadeThrower.TryThrow()`로 보내고, R은 총 장착 중 `TryChargePouch()`, G는 장비와 무관하게 `TryCraft()`로 보냅니다. 우클릭 조준은 다음 단계입니다. 중복 입력을 막기 위해 `YPH_CombatTestInput`은 제거합니다.
6. `TakeHit(int, Vector3)`는 이미 공개되어 있으므로 새로 만들 필요가 없습니다. 수류탄 플레이어 피해 기본 1과 실제 HP·구르기 무적 처리, 피해 거부 시의 결과를 합의하면 YPH가 후속 어댑터를 만듭니다. 근접 명중 이벤트의 대상도 YPH 어댑터를 거쳐 `YPH_SteamHitRefill.NotifyHit`에 전달합니다.

## 6. 영향 범위

- 참조: CHG 근접 공격·무기 전환·플레이어 피해. YPH가 추후 이벤트를 구독하고 비활성화 시 해제합니다.
- 다른 작업자: YPH 전투 연결, NGH 적의 피해 컴포넌트.
- 씬·프리팹 동시 수정 여부: 아직 확인하지 않았습니다. CHG 담당자가 확인하고 수정해 주세요. 이 요청 작성 중 CHG 파일은 수정하지 않았습니다.

## 7. 확인 방법

살아 있는 적 한 명 명중 시 이벤트 한 번과 증기 +10, 허공·시체·같은 공격의 중복 콜라이더에는 추가 회복이 없어야 합니다. Tab 후 좌클릭이 선택 장비 하나만 작동하는지, R/G 충전·제작과 구르기 중 폭발 피해 규칙을 통합 씬에서 확인합니다.

## 8. 안 하면 생기는 문제 / 대안

- 안 하면: 근접 회복과 실제 플레이어 조작 연결을 완료할 수 없습니다.
- 대안: `Scenes/YPH/YPH_CombatTest.unity`의 독립 입력과 개발 표적으로 총·수류탄은 계속 시험할 수 있습니다.
