## 1. 한 줄 요약

총을 든 동안 우클릭 조준이 켜지도록 카메라 후처리를 허용하고, YPH가 계산한 감도·이동 속도 배율을 받을 창구를 추가해 주세요.

## 2. 대상 파일

경로는 Unity 프로젝트 `Assets/` 기준입니다. 이 요청을 작성하면서 대상 파일은 수정하지 않았습니다.

| 경로 | 종류 | 수정 방식 |
|---|---|---|
| `Prefabs/CHG/chg_PlayerCamera.prefab` | 프리팹 | 카메라 후처리 켜기 |
| `Scripts/CHG/chg_ThirdPersonCamera.cs` | 스크립트 | 감도 배율 필드와 곱셈 추가 |
| `Scripts/CHG/chg_PlayerController.cs` | 스크립트 | 일반 이동 배율 필드와 곱셈 추가 |

## 3. 왜 필요한가

조준은 시야각 확대, 화면 가장자리를 어둡게 하는 비네트, 방사형 줄무늬로 표시합니다. 비네트는 URP 카메라 후처리가 켜져 있어야 보입니다. YPH 시험 씬에는 적용했지만 CHG 카메라는 후처리가 꺼져 있습니다.

`YPH_AimController`는 전환 비율에 따라 감도 1→0.6, 이동 속도 1→0.5의 배율을 제공합니다. CHG 카메라와 플레이어가 실제 회전·이동을 수행하므로 이 값을 곱할 창구가 필요합니다. YPH 코드는 CHG 클래스를 직접 참조하지 않습니다.

## 4. 현재 상태 → 원하는 상태

- 현재: CHG 카메라 후처리 꺼짐. 마우스 변화량에는 `mouseSensitivity`만, 일반 이동에는 `speed`만 사용합니다.
- 원하는 모습: 후처리 켜짐. 두 배율의 기본값은 1로 두어 연결 전 동작을 유지합니다. 연결 후 조준 중에만 YPH가 배율을 낮추고 해제·장비 전환·비활성화 시 1로 복구합니다.

## 5. 구체적인 변경 방법

### 카메라

1. `chg_PlayerCamera`의 실제 Camera를 선택합니다.
2. `UniversalAdditionalCameraData`의 **Render Post Processing**을 켭니다.
3. Volume Layer Mask에 **Default**를 포함합니다. 기존 포함 레이어는 유지합니다.
4. 병합 후 YPH가 `Prefabs/YPH/YPH_AimEffects.prefab`을 카메라 자식으로 배치합니다. `YPH_AimController._gun`, `._camera`, `YPH_AimZoomView._camera` 세 참조를 연결합니다. 프리팹 내부 Volume·Quad·뷰 연결은 완료되어 있습니다.

### 마우스 감도

`chg_ThirdPersonCamera`에 값을 받을 필드를 추가합니다.

```csharp
[Tooltip("외부 조준 시스템의 감도 배율입니다. 1이면 기존 감도, 낮추면 마우스 회전이 느려집니다.")]
public float SensitivityMultiplier = 1f;
```

마우스 변화량을 읽는 줄을 바꿉니다. 작성 시점 약 70번째 줄입니다.

```csharp
Vector2 d = mouse.delta.ReadValue() * mouseSensitivity * SensitivityMultiplier;
```

### 일반 이동 속도

`chg_PlayerController`에 값을 받을 필드를 추가합니다.

```csharp
[Tooltip("일반 이동의 속도 배율입니다. 1이면 기존 속도, 0이면 제자리이며 구르기·공격 이동·중력에는 적용하지 않습니다.")]
public float MoveSpeedMultiplier = 1f;
```

걷기·달리기·옆걸음·뒷걸음의 속도를 결정한 뒤 일반 이동을 만드는 줄만 바꿉니다. 작성 시점 약 292번째 줄입니다.

```csharp
Vector3 velocity = moveDir * (speed * MoveSpeedMultiplier);
```

구르기의 `rollDistance`, 공격 이동의 `attackMoveRatio`, 중력 계산에는 곱하지 않습니다.

### 연결 담당과 합의

- 배율 값과 전환 시간은 YPH가 정합니다. 병합 후 YPH 어댑터가 `SensitivityMultiplier`, `MoveSpeedMultiplier` 읽기 전용 프로퍼티를 읽어 위 두 필드에 넣고, 연결 종료 시 1로 복구합니다. **CHG는 YPH 코드를 참조하지 않아도 됩니다.**
- 조준 중 FOV는 YPH가 소유하고 시작 직전 값을 저장해 종료 시 정확히 복구합니다. CHG에서 달리기 등으로 FOV를 쓰게 되면 적용 순서를 합의해 주세요.
- 총 장착 시 우클릭은 조준용으로 유지합니다. 기존 근접 무기 우클릭 강공격과 입력이 겹치지 않게 장비별로 나눕니다.
- CHG·기획 결정 필요: 조준 중 달리기를 막을지, 이동 속도에 맞춰 걷기 애니메이션 `playRate`도 줄일지. 이는 배율 적용과 별개의 규칙입니다. 구르기·공격 이동은 배율 영향에서 제외되는지도 함께 확인해 주세요.

## 6. 영향 범위

- 대상 카메라·플레이어를 쓰는 CHG 씬과 프리팹에 영향을 줍니다. 후처리를 켜면 기존 Volume의 다른 효과도 보일 수 있으므로 CHG 씬에서 확인해야 합니다.
- 조준 줄무늬는 오방색 적입니다. 과열·공격 예고와 헷갈리면 YPH의 줄무늬 색을 흑·백으로 조절할 수 있습니다.
- 씬·프리팹의 현재 편집 담당자 확인: 아니오. CHG가 편집 상태를 확인한 뒤 자신의 파일에서 처리합니다.
- 기존 명중·무기 슬롯, 적 피해 API, 병합·레이어 요청은 별도로 유효합니다.

## 7. 확인 방법

1. 연결 전 두 배율을 1로 두고 기존 이동·카메라 조작이 같은지 확인합니다.
2. 총 우클릭을 유지하면 FOV가 80%로 줄고 가장자리가 어두워지는지 봅니다. 방향 회전과 일반 이동은 각각 0.6배·0.5배가 되어야 합니다.
3. 우클릭 해제·수류탄 전환·비활성화 후 FOV와 두 배율이 복구되는지 확인합니다. 조준하지 않을 때 다른 FOV 변경을 덮어쓰면 안 됩니다.
4. 이동 배율 0에서 일반 이동은 멈추되 중력·구르기·공격 이동 규칙은 유지되는지 확인합니다.
5. 후처리만 끄면 비네트만 사라지고 줌·줄무늬는 남아야 합니다.
6. 달리기·옆걸음·뒷걸음과 애니메이션 발 미끄러짐을 CHG 씬에서 확인합니다.

## 8. 안 하면 생기는 문제 / 대안

- 안 하면: CHG 카메라에서 비네트가 보이지 않으며 조준 중 감도·이동 속도가 줄지 않습니다.
- 현재 가능한 확인: YPH 시험 씬에서 후처리와 방향키 감도를 확인합니다. 이 씬에는 이동이 없어 이동 배율은 값만 검사합니다. 실제 CHG 이동 검증은 요청 처리·병합 이후 진행합니다.
