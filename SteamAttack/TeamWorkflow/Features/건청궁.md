# 기능: 건청궁 (Main 맵 경복궁 북쪽 왕의 처소)

| 항목 | 내용 |
|---|---|
| 한 줄 설명 | Main 맵 건청궁. 장안당·곤녕합·관문각, 누마루 2곳(추수부용루·옥호루), 앞 행각·대문(현판 宮淸乾), 꽃담. 단청 없는 백골집 |
| 담당자 | NMJ |
| 사용한 AI | Claude Code (Blender 스크립트·Unity 에디터 명령), VARCO 3D (계자난간·굴뚝 3D, 분합문·백골 나무·회벽·꽃담 질감) |

| 브랜치 / 커밋 | `NMJ` / 이 문서와 같은 커밋 |

| 대상 플랫폼 | PC, 목표 60FPS |

## 1. 이 기능은 무엇인가

향원정 연못 취향교 북쪽의 건청궁입니다. 실제처럼 단청 없는 백골집(나무 결 그대로·흰 회벽)으로, 네모기둥·장대석 두 벌대 기단·머름과 교창이 있는 분합문을 넣었습니다. 앞은 꽃담 아랫벽 행각 두 채와 솟을대문, 양 끝 앞에 높은 돌기둥 위 누마루 두 곳이 있습니다. 자리와 크기는 기존 블록 배치와 같아서 다른 배치가 그대로 맞습니다.

## 2. 5분 안에 써 보기

1. **씬:** `Assets/Scenes/Common/Main.unity`를 엽니다. 프리팹 위치는 (0, 0, 137)입니다.
2. **준비:** 없음
3. **실행:** Play를 누르고 그 자리로 걸어갑니다.
4. **확인:** 취향교를 건너 대문 가운데로 들어가 마당에서 장안당·곤녕합·누마루를 보면 정상입니다.

## 4. 어떻게 만들어졌나 (구조)

### 4-1. 만들거나 고친 파일

| 경로 | 신규/수정 | 역할 (한 문장) |
|---|---|---|
| `Assets/Prefabs/NMJ/Geoncheonggung/NMJ_Geoncheonggung.prefab` | 신규 | 건청궁 전체 (FBX 자식 Y 180°, 대문 양옆 BoxCollider 2개) |
| `Assets/Arts/Models/NMJ/Geoncheonggung/` | 신규 | FBX·원본 blend·바르코 부품(Source~/parts)·`M_GCG_*` 재질·`GCG_*` 질감 |
| `Assets/Scenes/Common/Main.unity` | 수정 | 프리팹 놓음, 옛 `건청궁 (乾淸宮)` 끔 |

### 4-2. 클래스 관계

코드 없음. 모델·재질·충돌체뿐입니다.

### 4-3. 동작 흐름

벽·기단·기둥은 MeshCollider로 막고, 지붕은 충돌체가 없습니다.

### 4-4. 프리팹·씬 구성

- 프리팹 루트 안에 FBX 자식 하나(로컬 회전 Y 180°). 재질은 물체마다 1개
- 옛 블록 물체는 지우지 않고 끔

## 5. 왜 이렇게 만들었나 (설계 이유)

| 결정 | 이유 | 버린 대안과 그 이유 |
|---|---|---|
| 큰 형태는 스크립트, 조각 많은 부분·그림은 바르코3D | 지붕·기와는 스크립트가 깔끔하고, 장식·그림은 AI가 사실적 | 통째로 바르코: 면이 뭉개짐 |
| 기존 블록과 같은 자리·크기 | 다른 배치가 그대로 맞음 | 실제 치수로 새로: 맵 배치를 다시 해야 함 |
