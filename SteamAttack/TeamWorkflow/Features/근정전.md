# 기능: 근정전 (Main 맵 경복궁 정전)

| 항목 | 내용 |
|---|---|
| 한 줄 설명 | Main 맵 근정전 건물·월대(두 단 기단)·실내·어좌. 걸어 오를 수 있는 계단 8곳, 여닫이 문, 입체감 셰이더 |
| 담당자 | NMJ |
| 사용한 AI | Claude Code (Blender 스크립트·Unity 에디터 명령), VARCO 3D (일부 파츠) |
| 완료일 | 2026-10-29 (외형·검수), 성능 측정은 11번 |
| 브랜치 / 커밋 | `NMJ` / `2acbe3d` |
| 관련 기획서 | [맵 구상](../Design/월드/맵구상.md) · 기준 결정: D-105 |

| 대상 플랫폼 | PC, 목표 60FPS |

## 1. 이 기능은 무엇인가

시작 지점 바로 뒤에 서 있는 근정전입니다. 두 단 월대 위에 2층 지붕(팔작) 건물이 있고, 앞·양옆·뒤 계단으로 월대에 오를 수 있습니다. 앞문과 뒷문은 다가가면 열리고, 안에는 어좌(임금 자리)와 닫집, 일월오봉도 병풍이 있습니다. 기와·주춧돌·전돌 바닥은 한 장씩 만들었고, 처마 밑 그늘과 틈새 그늘을 넣은 전용 셰이더로 입체감을 냈습니다.

## 2. 5분 안에 써 보기

1. **씬:** `Assets/Scenes/Common/Main.unity`를 엽니다. 근정전 프리팹이 (0, 0, 55)에 놓여 있습니다.
2. **준비:** 없음
3. **실행:** Play를 누르고 개발자 창(` 키)에서 `2 근정전 마당`으로 이동합니다.
4. **확인:** 월대 앞 계단 → 위 단 → 앞문으로 들어가 어좌 계단을 올라가 봅니다. 옆면 앞쪽·뒤쪽 계단으로도 오르내릴 수 있으면 정상입니다.

## 3. 테스트 조작법

### 3-1. 게임 조작 키

이 기능 전용 키는 없습니다. 기존 플레이어 이동(NGH)으로 걷고 오릅니다. 문은 가까이 가면 자동으로 열립니다(`NMJ.NmjHingedDoor`).

### 3-2. 테스트 전용 키 (디버그)

| 키 | 하는 일 | 쓰는 때 | 어느 스크립트가 처리하나 |
|---|---|---|---|
| ` → 개발자 창 `2` | 근정전 마당으로 이동 | 근정전 확인 | `NMJ.NmjDevWindow` ([디버깅 메뉴](../Design/UI/디버깅메뉴.md)) |

### 3-3. 테스트 시나리오

| # | 하는 일 (순서대로) | 정상이라면 보이는 것 |
|---|---|---|

| 2 | 위 단 동·서쪽 끝(앞쪽)의 측면 계단, 뒤쪽 가운데 계단으로 내려갔다 오르기 | 두 단 계단 모두 걸어서 오르내림 |

### 4-1. 만들거나 고친 파일

### 4-2. 클래스 관계

코드는 문(`NmjHingedDoor`) 하나뿐이고 나머지는 모델·재질·충돌체입니다.

### 4-3. 동작 흐름

1. 플레이어가 계단 위를 걸으면 프리팹의 경사판 BoxCollider(보이지 않음)를 밟고 오릅니다. 계단 모양 메시는 보이기만 합니다.
2. 벽·난간·기둥은 MeshCollider로 막습니다.
3. 문 앞에 가면 `NmjHingedDoor`가 문짝을 경첩 축으로 돌립니다.

### 4-4. 프리팹·씬 구성

- `NMJ_Geunjeongjeon_VARCO` (루트)
  - `NMJ_Geunjeongjeon` (FBX): 지붕·기와·벽·문·월대·어좌 등 물체 186개. 재질은 물체마다 1개
  - 걷기 경사판(Ignore Raycast 레이어, BoxCollider): `계단_경사판`(앞), `측면계단_경사판_동/서_아래/위`, `뒤계단_경사판_아래/위`, `어좌_계단경사`, 문지방 `윗면_*`·`안쪽_*`·`바깥_*`
  - `실내_눈막이`(눈 효과가 실내에 안 들어오게), 실내 조명
- 씬 Main의 인스턴스는 위치·일부 값을 덮어씀(덮어쓴 값 47개). 프리팹을 고치면 씬에 바로 반영됩니다.

## 5. 왜 이렇게 만들었나 (설계 이유)

| 결정 | 이유 | 버린 대안과 그 이유 |
|---|---|---|
| 계단은 보이는 메시 + 보이지 않는 경사판 | 계단 턱마다 걸리지 않고 매끄럽게 오름 | 계단 MeshCollider: 턱에 걸리고 비용이 큼 |
| 지붕·기와를 식으로 만든 매끈한 면 위에 다시 깖 | 바르코 지붕 높이를 따라 깔면 물결·톱니 처마가 생김 | 바르코 지붕 그대로: 들쭉날쭉해 보임 |
| 전용 셰이더 `NMJ/GJJ_Lit` | URP Lit은 모델에 구운 틈새 그늘을 못 씀. 처마 밑을 눈 반사광으로 밝히는 것도 장면 전체 조명을 바꾸지 않고 이 건물에만 적용 | 장면 환경광 변경: 다른 팀원 화면까지 바뀜 |

- 일부러 단순하게 둔 곳: 먼 거리용 단순 모델(LOD)이 없음 (13번)

## 6. 인스펙터 값 설명

`NMJ/GJJ_Lit` 셰이더는 URP Lit을 바탕으로 했고, 추가 값은 **URP Lit이 안 쓰는 칸을 빌려** 씁니다(SRP Batcher 유지). 인스펙터에는 한글 이름으로 보입니다.

| 컴포넌트 | 값 (속성 이름) | 기본값 | 올리면 / 내리면 | 권장 범위·주의 |
|---|---|---|---|---|
| `NMJ/GJJ_Lit` | 큰 틈새 그늘 세기 (`_OcclusionStrength`) | 0.7 | 처마 밑·구석이 더 어두움 / 납작해짐 | 0.5~0.8. 창호지는 0.15 |
| `NMJ/GJJ_Lit` | 좁은 틈 그늘 세기 (`_DetailAlbedoMapScale`) | 0.6 | 기와 골·서까래 사이가 진해짐 | 0.4~0.7 |
| `NMJ/GJJ_Lit` | 햇빛 받는 면에도 그늘 섞기 (`_ClearCoatMask`) | 0.25 | 해 받는 면도 틈이 진해짐 | 0~0.3 |
| `NMJ/GJJ_Lit` | 위아래 밝기 차 (`_ClearCoatSmoothness`) | 0.25 | 위를 보는 면이 더 밝음 | 0~0.4 |
| `NMJ/GJJ_Lit` | 눈 반사광 (`_EmissionColor`) | (0.66, 0.62, 0.56) | 처마 밑·벽이 밝고 따뜻해짐 | 밤 장면이면 어둡게 |
| `NMJ/GJJ_Lit` | 하늘 테두리 빛 색·세기 (`_SpecColor`·`_Parallax`) | 하늘색 · 0.12 | 윤곽이 하늘과 갈라짐 | 0.2 넘으면 번쩍임 |

- **주의:** 위 이름은 URP Lit과 같지만 뜻이 다릅니다. 이 재질을 URP Lit으로 바꾸면 값이 엉뚱하게 쓰입니다.
- **투명 재질은 이 셰이더로 바꾸지 않습니다** (불투명 전용). 지금 `M_GJJ_벽밑때`만 URP Lit 투명입니다.
