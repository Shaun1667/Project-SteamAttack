# 기능: 광화문 (Main 맵 경복궁 정문)

| 항목 | 내용 |
|---|---|
| 한 줄 설명 | Main 맵 광화문. 석축·홍예 3곳(지나갈 수 있음) + 2층 문루, 바르코3D 부품(공포·취두·문짝)과 실사 질감, 가운데 홍예 천장 주작 그림 |
| 담당자 | NMJ |
| 사용한 AI | Claude Code (Blender 스크립트·Unity 에디터 명령), VARCO 3D (부품 4종·질감 그림 7장) |
| 완료일 | 2026-10-29 (외형), 성능 측정은 11번 |
| 브랜치 / 커밋 | `NMJ` / `984e69c` |
| 관련 기획서 | [맵 구상](../Design/월드/맵구상.md) · 기준 결정: D-105 |
| 상태 | 일부 완료: 성능 측정·큰 파일 정리는 13번 |
| 대상 플랫폼 | PC, 목표 60FPS |

## 1. 이 기능은 무엇인가

시작 마당 남쪽의 광화문입니다. 화강암 석축에 아치 문(홍예) 3개가 나 있고, 위에 정면 3칸·측면 2칸 2층 문루가 있습니다. 1900년대 사진 비율(지붕 폭 ≈ 석축 폭)에 맞췄고, 처마 밑 다포 공포·용마루 끝 취두·홍예 문짝은 바르코3D로 뽑은 부품입니다. 가운데 홍예 천장에는 주작 그림이 있습니다. 예전 블록 광화문과 같은 자리·같은 석축 크기라 기존 배치(해태·얼음문·적)가 그대로 맞습니다.

## 2. 5분 안에 써 보기

1. **씬:** `Assets/Scenes/Common/Main.unity`를 엽니다. 광화문 프리팹이 (0, 0, -40)에 놓여 있습니다.
2. **준비:** 없음
3. **실행:** Play를 누르고 광화문 앞(남쪽)으로 걸어갑니다.
4. **확인:** 세 홍예를 지나 북쪽(근정전 쪽)으로 나갈 수 있고, 가운데 홍예에서 올려다보면 주작 천장이 보이면 정상입니다.

## 4. 어떻게 만들어졌나 (구조)

### 4-1. 만들거나 고친 파일

| 경로 | 신규/수정 | 역할 (한 문장) |
|---|---|---|
| `Assets/Prefabs/NMJ/Gwanghwamun/NMJ_Gwanghwamun.prefab` | 신규 | 광화문 전체. 안쪽 FBX 자식을 Y 180° 돌려 현판이 남쪽을 봄 |
| `Assets/Arts/Models/NMJ/Gwanghwamun/NMJ_Gwanghwamun.fbx` | 신규 | 모델(물체 34개). 꼭짓점 색에 틈새 그늘이 구워져 있음 |
| `Assets/Arts/Models/NMJ/Gwanghwamun/Source~/NMJ_Gwanghwamun.blend` | 신규 | FBX 원본(블렌더). `~` 폴더라 유니티가 읽지 않음 |
| `Assets/Arts/Models/NMJ/Gwanghwamun/Source~/parts/` | 신규 | 바르코3D 부품 원본 FBX (공포·귀공포·취두·문짝) |
| `Assets/Arts/Models/NMJ/Gwanghwamun/Materials/` · `Textures/` | 신규 | `M_GWM_*` 재질, `GWM_*` 질감(색 + 요철) |
| `Assets/Scenes/Common/Main.unity` | 수정 | 광화문 프리팹 놓음, 예전 `02_광화문/광화문 (光化門)` 끔(지우지 않음) |

### 4-2. 클래스 관계

코드 없음. 모델·재질·충돌체뿐입니다.

### 4-3. 동작 흐름

1. 석축(`광화문_석축`, `광화문_마름돌`)의 MeshCollider가 벽을 막고, 홍예 통로는 비어 있어 지나갈 수 있습니다.
2. 문루·지붕은 충돌체가 없습니다 (석축 위로 올라갈 길이 없음).

### 4-4. 프리팹·씬 구성

- `NMJ_Gwanghwamun` (루트, 씬 (0, 0, -40))
  - `NMJ_Gwanghwamun` (FBX, 로컬 회전 Y 180°): 석축·마름돌·여장·문루·공포·지붕·현판·홍예 천장 등 물체 34개. 재질은 물체마다 1개
- 해태·`NMJ_광화문_얼음문`·적 배치는 프리팹 밖(기존 씬 물체)이고 건드리지 않았습니다.

## 5. 왜 이렇게 만들었나 (설계 이유)

| 결정 | 이유 | 버린 대안과 그 이유 |
|---|---|---|
| 석축 바깥 크기(34.4 × 12.4m)·홍예 자리를 예전 블록 광화문과 같게 | 얼음문·적 배치·담장이 그대로 맞음 | 실제 치수로 새로: 맵 배치를 다시 해야 함 |
| 공포·취두·문짝만 바르코3D 부품, 나머지는 스크립트 | 조각이 많은 부분은 AI 부품이 사실적이고, 큰 면·지붕은 스크립트가 깔끔함 | 건물 통째로 바르코: 면이 뭉개지고 고치기 어려움 |
| 광화문 전용 재질 `M_GWM_*` | 실사 질감을 넣어도 근정전 모습이 안 바뀜 | 근정전 재질 공유: 근정전까지 바뀜 |
| 근정전과 같은 셰이더 `NMJ/GJJ_Lit` | 틈새 그늘·처마 밑 반사광을 씬 조명을 안 바꾸고 이 건물에만 | 씬 조명 변경: 다른 팀원 화면까지 바뀜 |

- 일부러 단순하게 둔 곳: 홍예 문짝은 안쪽으로 연 채 고정(게임에서 지나다녀야 함), 먼 거리용 단순 모델(LOD) 없음

## 6. 인스펙터 값 설명

셰이더 값은 [근정전](근정전.md) 6번과 같습니다. 광화문 재질만의 값:

| 컴포넌트 | 값 (속성 이름) | 기본값 | 올리면 / 내리면 | 권장 범위·주의 |
|---|---|---|---|---|
| `M_GWM_*` 재질 | 요철 세기 (`_BumpScale`) | 0.4~1.0 | 결이 깊어 보임 / 납작 | 1.2 넘으면 지저분함 |
| `M_GWM_판벽` | 색 (`_BaseColor`) | (0.78, 0.72, 0.70) | 판벽이 밝아짐 | 붉은칠 질감을 어둡게 써서 기둥과 구분 |

- **주의:** `M_GWM_창방단청`·`M_GWM_천장주작` 질감은 Clamp(반복 안 함)여야 머리초·그림 끝이 번지지 않습니다.
