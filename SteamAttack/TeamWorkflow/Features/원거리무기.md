# 총·수류탄 사용 가이드

작성: YPH · 2026-10-02 갱신 · Unity 6000.6 / URP 17.6 / 새 Input System

> 관련 기획서: [원거리 무기](../Design/전투/원거리무기.md) · 기준 결정: 없음 (기획서 재구성 전에 작성)

이 문서는 총·수류탄을 직접 시험하거나 다른 씬에 연결하는 팀원을 위한 안내입니다. 코드 작성자가 아니어도 조작 방법, 증기를 쓰는 시점, 수치 조절 위치를 확인할 수 있도록 정리했습니다.

문서의 `Assets/` 경로는 `C:/Project/SteamAttack/SteamAttack/Assets/`를 기준으로 합니다. 아래 수치는 현재 코드와 시험 씬의 기본값입니다.

## 1. 바로 실행하기

1. Unity Project 창에서 `Assets/Scenes/YPH/YPH_CombatTest.unity`를 엽니다.
2. Play를 누르고 **Game 창을 클릭해 입력 포커스**를 줍니다.
3. 초록색 총, 가득 찬 백팩 게이지, 앞쪽 캡슐 표적이 보이는지 확인합니다. 시작 상태는 약실 1발, 주머니 10발, 증기 100, 수류탄 0개입니다.
4. 방향키로 화면 중앙에 표적을 맞춘 뒤 좌클릭합니다. 별도 조준점 UI는 없습니다.
5. G로 수류탄을 제작하고 1초 기다린 뒤, Tab으로 수류탄을 들고 좌클릭해 던집니다.

| 입력 | 동작 | 조건·주의점 |
|---|---|---|
| 좌클릭 | 총 한 발 발사 / 수류탄 한 개 투척 | 현재 장착한 장비만 작동합니다. 누르고 있는 동안 연속 발사하는 방식은 아닙니다. |
| R | 총의 탄환 주머니 충전 | 총을 든 상태이며 `Ready` 또는 `Empty`일 때만 됩니다. |
| G | 수류탄 한 개 제작 | 장비와 무관하게 됩니다. 제작 중이거나 소지가 가득 차면 거절합니다. |
| Tab | 총 ↔ 수류탄 전환 | 총을 넣으면 총의 진행만 멈추고, 다시 꺼내면 이어집니다. |
| ← / → | 좌우 조준 회전 | 플레이어와 카메라가 함께 회전합니다. |
| ↑ / ↓ | 상하 조준 회전 | 기본 상하 제한은 ±60도입니다. |
| 우클릭 유지 | 총 조준 | 누르는 동안 줌·비네트·방사형 줄무늬가 켜집니다. 떼거나 수류탄으로 전환하면 해제합니다. |

이 씬에는 이동 입력이 없습니다. Console 창에서는 발사 결과, 충전·제작 여부, 소지 수와 표적의 남은 HP를 확인할 수 있습니다. 로그는 Editor에서만 출력합니다.

조준 중에도 사격과 R 충전이 됩니다. 켜질 때 0.12초, 풀릴 때 0.08초에 걸쳐 전환합니다. Tab은 조준 목표를 즉시 해제한 뒤 같은 시간으로 복구합니다. 수류탄은 우클릭을 무시하며, 계속 누른 채 총으로 돌아오면 다시 조준합니다. 방향키 회전은 90→54도/초로 느려집니다. 이동 배율 1→0.5는 전환 완료 로그로 확인하며 실제 CHG 이동에는 아직 연결되지 않았습니다.

## 2. 총: 언제 탄과 증기가 줄어드나요?

**약실**은 바로 발사할 한 발이 들어 있는 자리이고, **탄환 주머니**는 약실로 옮길 예비 탄을 보관하는 곳입니다. 약실 크기는 항상 1발입니다.

### 한 발 쏘는 순서

```text
Ready (약실 1발)
  → 좌클릭: 약실 한 발 사용, 즉시 명중 판정
Firing (0.25초)
  → 주머니에 탄이 있으면 한 발을 꺼냄
Chambering (0.5초)
  → 약실에 한 발 넣기 완료
Ready
```

이 과정에는 증기가 들지 않습니다. 기본 설정에서는 다음 발을 쏘기까지 약 0.75초가 필요합니다. 준비되기 전에 누른 입력은 예약되지 않으므로, 준비된 뒤 다시 클릭해야 합니다.

주머니까지 비었으면 `Firing`이 끝난 뒤 `Empty`가 됩니다. 시작할 때 약실 1발과 주머니 10발이 있으므로 충전 없이 총 11발을 쏠 수 있습니다. 빗맞혀도 탄은 사용합니다.

### R로 주머니 충전하기

증기는 **R로 주머니를 채우기 시작할 때** 소비합니다. 기본 비용은 한 발당 증기 1입니다.

| 상황 | 충전 시작 | 충전 완료 뒤 |
|---|---|---|
| 약실·주머니가 모두 비고 증기 100 | 증기 10을 즉시 사용, `Charging` 시작 | 1초 뒤 주머니 10발 지급 → 자동 약실 이동 0.5초 → 약실 1발 + 주머니 9발 |
| 약실·주머니가 모두 비고 증기 4 | 살 수 있는 4발 비용만 사용, 증기 0 | 충전과 약실 이동 후 약실 1발 + 주머니 3발 |
| 약실 1발 + 주머니 7발 | 빈 3칸 비용만 사용 | 1초 뒤 약실 1발 + 주머니 10발. 약실 이동은 생략 |
| 주머니가 가득 참 | 시작하지 않음 | 탄·증기 변화 없음 |
| 한 발 비용도 없음 | 시작하지 않음 | 현재 상태·탄·증기 유지 |

`Firing`, `Chambering`, `Charging` 중에는 발사와 추가 충전이 막힙니다. 충전 중 Tab으로 총을 넣으면 이미 낸 증기는 유지되고 진행 시간만 멈춥니다. 다시 꺼내면 남은 과정을 이어갑니다.

### 확인용 총 색과 사격선 읽기 (기본 꺼짐)

기본 표시는 총구 불꽃·증기, 백색 총알 궤적, 명중 불꽃입니다. 아래 상태 색과 직선은 확인용입니다. 총 루트의 `GunStateView`, 자식 `Tracer`의 `GunTracerView` 체크박스를 켜면 다시 동작합니다. **기본 초록색 몸체만 보고 발사 가능 여부를 판단하지 마세요.**

| 몸체 색 | 상태 | 의미 |
|---|---|---|
| 초록 | `Ready` | 발사 가능 |
| 빨강 | `Firing` | 발사 직후 간격 대기 |
| 파랑 | `Chambering` | 주머니에서 약실로 한 발 이동 중 |
| 회색 | `Empty` | 발사할 탄 없음 |
| 노랑 | `Charging` | 증기를 내고 주머니 탄 지급을 기다리는 중 |

사격선은 기본 0.1초 동안 보입니다. 살아 있는 적에게 피해를 주면 초록, 허공·벽·태그 없는 대상이면 노랑입니다. 피해 대상이 아닌 벽도 광선을 막습니다.

명중 판정은 **카메라 위치에서 앞 방향으로** 즉시 검사합니다. 새 궤적은 총구에서 판정 끝점까지 기본 250m/s로 이동하는 표시이고, 확인용 선은 끝까지 즉시 그립니다. 두 표시 모두 피해를 판정하는 실제 탄환은 아닙니다.

## 3. 수류탄: 제작·투척·폭발

### 제작과 소지

G를 누르면 증기 40을 즉시 소비하고 1초 뒤 소지가 한 개 늘어납니다. 증기가 부족하면 일부를 쓰지 않고 제작 전체를 거절합니다. 기본 소지 상한은 3개이며 시작 소지는 0개입니다.

제작 중에는 추가 제작과 수류탄 투척만 막힙니다. 총의 발사·충전은 사용할 수 있고, Tab으로 장비를 바꿔도 제작은 계속됩니다.

**수류탄 장착 중이고 소지가 1개 이상일 때만 손의 작은 구가 보입니다.** 소지가 0이면 수류탄을 장착해도 손이 비어 있고, 좌클릭해도 던지지 않습니다.

### 던지기

좌클릭하면 손 위치에 실제 수류탄을 만들고 소지를 한 개 줄입니다. 이때 증기를 추가로 쓰지는 않습니다. 기본 초기 속도는 카메라 앞 방향 12m/s에 위 방향 2m/s를 더한 값이며, 이후에는 중력과 충돌 물리에 따라 움직입니다.

다음 투척은 기본 0.5초 뒤부터 가능합니다. 던지는 동안 자기 몸과의 직접 충돌은 무시하지만, 폭발 범위에 서 있으면 자기 수류탄에도 피해를 받습니다.

### 기폭 방식

Project 창에서 `Assets/Prefabs/YPH/YPH_SteamGrenade.prefab`을 선택하고 `Grenade`의 `Detonation Mode`를 바꿉니다.

| 설정 | 터지는 시점 | 바닥·벽에 닿으면 |
|---|---|---|
| `AfterThrow` | 던진 뒤 `Fuse Time` 경과, 기본 2초 | 바로 터지지 않고 물리 재질에 따라 튀거나 구름 |
| `OnImpact` | 자기 몸 외 물체와 첫 충돌 | 닿은 지점에서 즉시 폭발 |

아무것에도 닿지 않을 때를 위해 최대 생존시간이 있습니다. 실제 안전장치 시간은 `Max Lifetime`과 `Fuse Time` 중 더 큰 값입니다. 이 규칙은 `OnImpact`에도 적용됩니다.

수류탄 뒤에는 백색 꼬리가 남습니다. 폭발하면 황·백 섬광, 불똥 24개, 증기 연기 14개가 나타나고 스스로 삭제됩니다. 연기는 1.5초 동안 사라집니다. 피해 반경은 기본 4m이며 반경에 비례해 표시 크기도 바뀝니다. 이펙트에는 Collider가 없고 피해는 한 번만 처리합니다. 파티클 외곽은 정확한 피해 경계가 아닙니다.

반경 확인용 구는 기본으로 꺼져 있습니다. 수류탄의 `_explosionFlashPrefab`에 `Prefabs/YPH/YPH_ExplosionFlash.prefab`을 연결하면 다시 표시됩니다. 반경 4m일 때 지름 8m, 표시 시간 0.2초입니다. Project 창의 프리팹을 변경하면 저장되므로 시험 후 슬롯을 다시 비우세요.

## 4. 누가 피해를 받고 증기를 회복시키나요?

태그는 `IDamageable`을 구현한 **피해 컴포넌트가 붙은 오브젝트**에서 읽습니다. 자식 콜라이더의 태그만 바꿔서는 대상의 편이 바뀌지 않습니다.

| 대상 태그 | 총 기본 피해 | 수류탄 기본 피해 | 유효한 명중 한 번의 증기 회복 |
|---|---|---|---|
| `Enemy` | 1 | 3 | +10 |
| `Boss` | 1 | 3 | +10 |
| `Player` | 없음 | 1 | 없음 |
| `Untagged` 등 그 밖의 태그 | 없음 | 없음 | 없음 |

- 총은 `_ignoreRoot` 아래의 자기 몸 콜라이더를 통과합니다. 다른 플레이어가 경로를 막으면 피해 없이 광선을 막을 수 있습니다.
- 한 적에 콜라이더가 여러 개 있어도 같은 폭발에서 피해·회복은 한 번입니다. 적 두 명을 맞히면 증기 +20입니다.
- 공격 직전에 살아 있어야 피해를 줍니다. 적을 쓰러뜨린 마지막 타격도 회복하지만, 이미 죽은 대상을 때려서는 회복하지 않습니다.
- 피해량이 0인 공격은 해당 대상의 피해·명중 회복을 처리하지 않습니다.
- 회복은 탱크 최대량을 넘지 않으며 회복할 때 배출구가 분출하지 않습니다.
- 증기가 0 이하이면 배출구 파티클을 멈추고 남은 입자도 지웁니다. 잔량이 양수지만 비용보다 부족할 때만 작은 실패 분출이 가능합니다.

개발 표적은 기본 HP 5이며 피해를 받으면 하얗게 깜빡입니다. HP가 0이 되면 몸체·콜라이더를 숨겼다가 3초 뒤 HP를 채워 부활합니다.

## 5. Inspector에서 수치 조절하기

필드 이름에 마우스를 올리면 한국어 설명을 볼 수 있습니다. 아래 표에는 코드 필드명도 함께 적었습니다. 예를 들어 `_fireInterval`은 Inspector에서 `Fire Interval`로 표시됩니다.

**씬 오브젝트와 Project 창의 프리팹 에셋을 구분하세요.** 잠깐 시험하려면 Play 중 Hierarchy의 실행 인스턴스를 바꾸고, 기본값으로 남기려면 Play를 끝낸 뒤 씬이나 프리팹에서 변경·저장합니다. Play 중이라도 Project 창의 에셋을 수정하면 변경이 남을 수 있습니다. 이미 던져진 수류탄의 값을 바꾸려면 해당 실행 인스턴스를 선택합니다.

### 총: `YPH_SteamGunProxy` → `SteamGun`

| 필드 | 기본값 | 바꾸면 달라지는 것 |
|---|---|---|
| `_pouchCapacity` | 10 | 충전 가능한 주머니 상한. 실행 중 낮춰도 기존 탄·이미 지불한 충전분은 버리지 않음 |
| `_startPouchRounds` | 10 | 시작 주머니 탄 수. **시작할 때만** 읽고 용량 이하로 제한. 약실 1발은 별도 |
| `_steamCostPerRound` | 1 | 충전 한 발당 증기. 높일수록 같은 증기로 살 수 있는 탄이 줄어듦 |
| `_fireInterval` | 0.25초 | 발사 후 약실 이동을 시작하기까지 대기. 0이면 즉시 다음 단계 |
| `_chamberTime` | 0.5초 | 주머니에서 약실로 옮기는 시간. 0이면 즉시 완료 |
| `_pouchChargeTime` | 1초 | 비용 지불부터 탄 지급까지 시간. 0이면 즉시 완료 |
| `_damage` | 1 | 적 한 명에게 주는 총 피해. 0이면 피해·회복 없음 |
| `_range` | 50m | 카메라에서 검사하는 최대 거리 |
| `_hitMask` | Everything | 광선이 검사할 레이어. 벽을 제외하면 벽을 통과할 수 있음 |

진행 중 시간 설정을 바꾸면 현재 단계의 경과시간과 새 값을 비교합니다. 이미 지난 시간보다 작게 줄이면 다음 갱신에서 단계가 끝날 수 있습니다.

### 제작·투척: `YPH_GrenadeHand` → `SteamGrenadeThrower`

| 필드 | 기본값 | 바꾸면 달라지는 것 |
|---|---|---|
| `_craftSteamCost` | 40 | 한 개 제작 비용. 0이면 무료 제작 |
| `_craftTime` | 1초 | 제작 완료까지 시간. 0이면 즉시 소지 증가, 진행 중 변경도 반영 |
| `_maxHeldGrenades` | 3 | 소지 상한. 1이면 한 개씩 제작·투척하는 방식 |
| `_throwInterval` | 0.5초 | 투척 사이 대기. 0이면 클릭할 때마다 투척 가능 |
| `_throwSpeed` | 12m/s | 앞 방향 초기 속도. 높이면 일반적으로 더 멀리 날아감 |
| `_upwardBoost` | 2m/s | 위 방향 추가 속도. 높이면 더 높이 뜨고 음수이면 아래로 던짐 |

소지 상한을 낮춰도 이미 가진 수류탄과 비용을 낸 제작분은 버리지 않습니다. 소지가 상한 아래로 줄어들 때까지 추가 제작을 막습니다.

### 비행·폭발: `YPH_SteamGrenade` 프리팹 → `Grenade`

| 필드 | 기본값 | 바꾸면 달라지는 것 |
|---|---|---|
| `_detonationMode` | `AfterThrow` | 지연 폭발 / 첫 충돌 폭발 선택 |
| `_fuseTime` | 2초 | 지연 폭발 시간. `AfterThrow`에서 0이면 투척 즉시 폭발 |

## 6. 다른 씬에 연결하기

기존 시험 씬의 연결을 참고하면 됩니다. 아래 참조는 **Play 전에** 연결합니다. 필수 참조가 비어 있으면 해당 컴포넌트는 오류를 남기고 스스로 비활성화됩니다.

### 백팩과 회복 입구

1. `Assets/Prefabs/YPH/YPH_SteamBackpack.prefab`을 플레이어의 등 위치에 배치합니다.
2. 빈 오브젝트에 `SteamHitRefill`을 붙입니다.
3. 회복 입구의 `_tank`에 백팩 루트의 `SteamTank`를 연결합니다. 총과 수류탄도 같은 탱크를 사용해야 합니다.

### 총: 씬 참조 네 개 연결

`Assets/Prefabs/YPH/YPH_SteamGunProxy.prefab`을 배치합니다. 현재 시험 씬에서는 `AimCamera` 자식으로 두어 화면 오른쪽 아래에 표시합니다.

| `SteamGun` 필드 | 연결할 대상 |
|---|---|
| `_tank` | 백팩 루트의 `SteamTank` |
| `_hitRefill` | 앞에서 만든 `SteamHitRefill` |
| `_aimOrigin` | 조준 카메라 Transform |
| `_ignoreRoot` | 자기 몸 콜라이더를 포함하는 플레이어 루트 Transform |

`_muzzle`과 상태·사격선 표시의 내부 참조는 프리팹에 이미 연결되어 있습니다. 프리팹 에셋의 외부 참조 네 칸이 비어 있는 것은 정상이며, 씬에 놓은 인스턴스에 연결합니다.

### 조준 연출: 씬 참조 세 개 연결

1. `Prefabs/YPH/YPH_AimEffects.prefab`을 **카메라 자식**으로 둡니다. 비활성화되는 총 아래에는 두지 않습니다.
2. AimController의 `_gun`에 총, `_camera`에 그 카메라를 연결합니다.
3. AimZoomView의 `_camera`에도 같은 카메라를 연결합니다. 내부 Volume·Quad·뷰의 참조는 연결되어 있습니다.
4. Camera의 **Render Post Processing**을 켜고 Volume Layer Mask에 **Default**를 포함합니다. 후처리를 끄면 비네트만 사라집니다.
5. 개발용 입력의 `_aim`에 AimController를 연결합니다. 실제 입력 어댑터는 총 장착 여부와 우클릭 유지 여부를 합쳐 `SetAiming`을 호출하며 장비 해제·입력 중단 시 `false`를 전달해야 합니다.

Volume의 공유 프로파일은 런타임에 복사하므로 Play 중 수치가 원본에 저장되지 않습니다. 조준 종료 시 이 볼륨의 오버라이드를 해제하여 다른 볼륨을 막지 않습니다.

### 수류탄 제작기와 손 표시

카메라나 손 아래에 `YPH_GrenadeHand` 오브젝트를 만들고 `SteamGrenadeThrower`와 `GrenadeHandView`를 붙입니다. 그 자식으로 작은 `HandSphere`를 만들고 **Collider를 제거**합니다.

| 컴포넌트·필드 | 연결할 대상 |
|---|---|
| Thrower → `_tank`, `_hitRefill` | 총과 같은 탱크·회복 입구 |
| Thrower → `_grenadePrefab` | `Assets/Prefabs/YPH/YPH_SteamGrenade.prefab` |
| Thrower → `_handPoint` | `HandSphere`의 Transform |
| Thrower → `_aimOrigin` | 조준 카메라 Transform |
| Thrower → `_ignoreRoot` | 플레이어 루트 Transform |
| HandView → `_thrower` | 같은 오브젝트의 `SteamGrenadeThrower` |
| HandView → `_handSphere` | 자식 `HandSphere` 오브젝트 |

손 표시 구와 실제 날아가는 수류탄은 별도 오브젝트입니다. 표시 구에는 Collider가 없고, 실제 수류탄 프리팹에는 Rigidbody와 SphereCollider가 있습니다. 제작기는 총 오브젝트 밖에 두어야 총을 넣어도 제작이 계속됩니다.

### 개발용 입력과 표적

`CombatTestInput`에 총, 제작기, 손 표시, 좌우 회전 루트(`_aimRig`), 상하 회전 카메라(`_aimCamera`), 조준 컨트롤러(`_aim`)를 연결합니다. 총·손은 카메라 아래에, 카메라·플레이어는 회전 루트 아래에 둡니다. 실제 CHG 입력과 연결할 때는 이 개발용 입력을 제거해 중복 실행을 막습니다.

표적은 `Assets/Prefabs/YPH/YPH_TargetDummy.prefab`으로 배치할 수 있습니다. 플레이어 대용 표적에는 `Player` 태그를 지정하고 `_visualRoot`에 Body만 연결합니다. 이렇게 해야 쓰러질 때 백팩까지 같이 사라지지 않습니다.

## 7. 코드에서 연결할 때 알아둘 흐름

```text
입력 담당 → 총 / 제작기 메서드 호출
          → 증기 비용은 SteamTank에 요청
총 / 폭발 → 살아 있는 피해 대상에게 TakeDamage
          → SteamHitRefill에 명중 알림 → 적이면 탱크 회복
총 / 제작기 이벤트 → 총구 · 궤적 · 명중 불꽃 · 손 구 갱신 (확인용 색·선은 선택)
입력 → AimController → 줌 · 비네트 · 줄무늬, 감도·이동 배율 제공
탱크 이벤트 → 게이지 · 바늘 · 배출구 갱신
```

| 호출할 메서드 | 성공의 의미 |
|---|---|
| `SteamGun.TryFire()` | 한 발을 발사함. **빗맞아도 true**이며 명중 여부는 `OnFired`의 마지막 인자로 구분 |
| `SteamGun.TryGetAimPoint(out Vector3)` | 활성 총의 조준점 조회. 허공이면 최대 사거리 끝점. 탄·상태·증기·이벤트는 바꾸지 않음 |
| `AimController.SetAiming(bool)` | 조준 목표 설정. 실제 전환은 `AimBlend`에 따라 진행 |
| `SteamGun.TryChargePouch()` | 비용을 내고 충전을 시작함. 즉시 탄 지급을 뜻하지 않음 |
| `SteamGrenadeThrower.TryCraft()` | 비용을 내고 제작을 시작함. 즉시 소지 증가를 뜻하지 않음 |
| `SteamGrenadeThrower.TryThrow()` | 가진 수류탄 한 개를 던짐 |
| `GrenadeHandView.SetEquipped(bool)` | 수류탄 장착 여부에 맞춰 손 표시 갱신 |
| `SteamHitRefill.NotifyHit(IDamageable)` | 공격 직전에 살아 있던 대상에 실제 피해를 준 후 회복 요청 |

총·제작기의 `Try*`가 false이면 해당 요청은 실행되지 않은 것입니다. 입력이나 다른 장비 코드에서 탄·증기를 별도로 차감하지 마세요. 이미 각 컴포넌트가 처리합니다.

피해 대상은 `IDamageable`의 `IsAlive`, `TakeDamage(float, Vector3)`, `CompareTag(string)`를 제공해야 합니다. `hitFrom`에는 총의 조준 원점 또는 폭발 위치가 전달됩니다. `MonoBehaviour`의 기존 `CompareTag`가 인터페이스의 태그 조회를 충족합니다.

`NotifyHit` 자체는 생존 여부를 검사하지 않습니다. 호출자가 **피해를 주기 전에** 생존을 확인해야 마지막 타격의 회복을 누락하지 않고 시체 회복도 막을 수 있습니다. 기존 총·수류탄은 이 순서를 지킵니다.

총은 피해 처리 뒤 `OnFired(muzzle, end, hitEnemy)`를 알리고, 실제 충돌이 있으면 이어서 `OnImpact(point, normal, hitEnemy)`를 알립니다. 피해를 준 살아 있는 적·보스에만 `hitEnemy=true`입니다. 뷰는 표시만 담당합니다. `OnStateChanged`, 제작기의 `OnHeldCountChanged`, 조준의 `OnAimChanged(blend, focus)`도 구독은 `OnEnable`, 해제는 `OnDisable`에서 합니다.

현재 CHG·NGH 클래스와의 직접 연결은 없습니다. 기존 요청 세 건과 `Requests/YPH_요청_20261002_조준카메라와배율창구.md`를 참고하세요. 실제 CHG 감도·이동 적용, 달리기 허용·걷기 애니메이션·FOV 소유 합의는 병합 후 연결에서 처리합니다.

| 조준 전환 | 우클릭 유지·해제, 조준 중 Tab | 50°→40°→50°, 효과 복구. 수류탄은 우클릭 무시 |
| 조준 중 행동 | 우클릭 유지한 채 좌클릭, 준비된 뒤 R | 사격·충전 가능, 방향키 회전은 0.6배 |
| 중심 이동 | 총의 `_aimOrigin`을 기울인 빈 Transform으로 임시 변경 | 비네트·줄 중심이 같은 방향으로 이동 |
| 후처리 분리 | Camera의 Render Post Processing 끄기 | 비네트만 사라지고 줌·줄은 유지 |
| 폭발 크기·정리 | 반경을 바꾸어 투척하고 폭발 후 3초 대기 | 표시 크기 비례, 폭발 오브젝트 삭제 |
| 11발 소진 | 새 Play에서 허공을 조준하고 준비될 때마다 11번 클릭 | 총 회색, 약실·주머니 0. 증기는 그대로 100 |
| 빈 총 충전 | 위 상태에서 R | 증기 90, 노랑 → 파랑 → 초록. 약실 1 + 주머니 9 |
| 부분 충전 | Play 전에 탱크 시작 증기를 4로 바꾸고, 시작 탄 11발을 허공에 소진한 뒤 R | 증기 0, 충전 완료 뒤 약실 1 + 주머니 3, 배출구 정지 |
| 명중 회복 | G로 제작해 증기를 60으로 줄인 뒤 총으로 살아 있는 적 한 번 명중 | 증기 70, 적 HP -1 |
| 장비 전환 중 충전 | R로 충전을 시작하고 Tab, 1초 이상 기다렸다 다시 Tab | 넣어 둔 동안 총 진행 정지, 다시 꺼내면 이어짐 |
| 한 개 소지 방식 | `_maxHeldGrenades`를 1로 설정하고 G로 한 개 제작 완료 후 다시 G | 추가 제작·증기 소비 없음. 던진 뒤에는 다시 제작 가능 |
| 충돌 기폭 | Play 전에 수류탄 프리팹의 모드를 `OnImpact`로 설정하고 G → 대기 → Tab → 좌클릭 | 자기 몸을 제외한 첫 충돌 지점에서 폭발 |
| 플레이어 피해 | 폭발 범위 안에서 수류탄 폭발 | 플레이어 HP -1. 플레이어만 맞으면 증기 회복 없음 |

색으로 상태를 읽는 시험은 먼저 확인용 `GunStateView`를 켭니다. 시험용으로 바꾼 에셋·편집 모드 값은 시험 후 원하는 기본값으로 되돌려 저장하세요.

## 9. 문제가 생겼을 때

| 증상 | 먼저 확인할 것 |
|---|---|
| 키·클릭이 반응하지 않음 | Play 상태, Game 창 포커스, Input System 키보드·마우스 연결, `CombatTestInput` 활성화와 참조 |
| 총이 안 쏴짐 | `Ready`인지, 약실이 있는지. 기본 몸체 색은 상태 표시가 아니므로 Console 또는 확인용 뷰로 검사 |
| R을 눌러도 반응 없음 | 총 장착 여부, 주머니가 가득 찼는지, 충전 가능한 상태인지, 한 발 비용이 남았는지 |
| 제작했는데 바로 손 구가 안 보임 | 제작 완료까지 기다렸는지, 수류탄을 장착했는지, 소지가 남았는지 |
| 증기가 있는데 G가 안 됨 | 제작 중인지, 소지 상한인지, 한 개 비용 전액이 있는지 |
| 적을 맞혀도 피해·회복이 없음 | 피해 컴포넌트의 태그·생존 상태, `IDamageable` 구현, 양수 피해량, `_hitMask`, 회복 입구의 탱크 연결 |
| 자기 몸에 광선이나 수류탄이 걸림 | `_ignoreRoot` 아래에 실제 몸 콜라이더가 모두 포함되는지 |
| 폭발 표시는 없는데 피해는 들어감 | `_explosionEffectPrefab` 연결. 반경 구는 별도 `_explosionFlashPrefab` 연결 |
| 조준 중 어두워지지 않음 | Camera 후처리, Default 볼륨 마스크, Volume의 프로파일·Weight 확인 |
| 조준 전체가 안 나옴 | 입력의 `_aim`, AimController의 총·카메라, 총 장착 여부 확인 |
| 수류탄이 플레이어를 해침 | 범위 안에서는 기본 동작. 피해를 끄려면 `_playerDamage = 0` |
| 시작 값 수정이 반영되지 않음 | 시작 탄·시작 증기는 Play 전에 설정. 최대 HP는 다음 부활부터 반영 |
| 참조를 연결했는데 컴포넌트가 계속 꺼져 있음 | 참조 누락으로 Awake에서 비활성화되었을 수 있음. Play를 멈추고 참조를 연결한 뒤 다시 실행 |

| 저장된 씬·셰이더·공유 재질·프로파일·팔레트 | 25개 통과, Missing Script 0 |

총구·폭발의 짧은 섬광은 파티클 시뮬레이션을 특정 시점에 정지한 화면으로 모양을 확인했습니다. 재생·반복·수명·자동 삭제는 별도의 실시간 검사로 확인했습니다. 정상 실행 콘솔은 오류·경고 0건입니다. 누락 참조 시험의 의도된 오류 5건은 별도 기록 후 콘솔을 비웠습니다.

빌드 실행, Profiler의 GC 할당 측정, 사람이 직접 조작하는 시험과 실제 CHG 이동 연결은 미실행입니다. 조준 루프의 객체·문자열 할당 여부는 소스 검토로 확인했습니다. 효과의 강도와 최종 색은 사용자가 직접 조작하며 조절할 수 있습니다.

현재 구현의 범위는 다음과 같습니다.

- 우클릭 조준과 파티클 이펙트는 구현했습니다. 개발용 플레이어·표적·총 도형을 사용하며 실제 CHG·NGH 연결, 모델 교체·소리·시간 역행은 후속입니다.
- 텍스처 없는 원형 파티클을 사용합니다. 깊이 기반 소프트 파티클 처리가 없어 지면과 겹친 경계가 드러날 수 있습니다.
- 총 광선은 콜라이더 16개, 폭발 범위는 콜라이더 32개 버퍼를 사용합니다. 이를 넘는 밀집 상황에서는 대상이 누락될 수 있습니다.
- 폭발은 범위 겹침으로 판정하며 벽에 가려졌는지는 검사하지 않습니다. 범위 안이면 벽 너머의 대상도 피해를 받을 수 있습니다.
- 수류탄과 폭발 표시는 매번 생성·삭제합니다. 대량 동시 투척을 위한 풀링은 구현하지 않았습니다.
