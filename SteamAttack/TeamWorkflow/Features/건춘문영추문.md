# 기능: 건춘문(동문)·영추문(서문) (Main 맵 궁성 문)

| 항목 | 내용 |
|---|---|
| 한 줄 설명 | 궁성 동·서 문. 석축·홍예 1개(닫힌 판문)·전돌 여장·단층 문루(다포·우진각·잡상), 홍예 천장 청룡/백호, 현판 門春建·門秋迎 |
| 담당자 | NMJ |
| 사용한 AI | Claude Code (Blender 스크립트·Unity 에디터 명령), VARCO 3D (청룡·백호 천장 그림, 전돌 여장 질감, 닫힌 홍예 문짝 3D, 광화문 공포·취두 재사용) |
| 완료일 | 2026-10-29 (외형), 성능 측정은 11번 |
| 브랜치 / 커밋 | `NMJ` / 이 문서와 같은 커밋 |
| 관련 기획서 | [맵 구상](../Design/월드/맵구상.md) · 기준 결정: D-105 |
| 상태 | 일부 완료: 성능 측정은 13번 |
| 대상 플랫폼 | PC, 목표 60FPS |

## 1. 이 기능은 무엇인가

경복궁 동문 건춘문과 서문 영추문입니다. 실제 사진대로 넓은 화강암 석축 가운데 홍예 하나, 위에 전돌 여장과 작은 단층 문루를 얹었습니다. 홍예 천장은 사신에 맞춰 건춘문 청룡, 영추문 백호입니다. 문은 닫혀 있습니다(기존 투명 길막이 그대로). 자리와 크기는 기존 블록 배치와 같아서 다른 배치가 그대로 맞습니다.

## 2. 5분 안에 써 보기

1. **씬:** `Assets/Scenes/Common/Main.unity`를 엽니다. 프리팹 위치는 (0, 0, 0) (두 문이 한 프리팹, 건춘문 (70, 60) · 영추문 (-70, 60))입니다.
2. **준비:** 없음
3. **실행:** Play를 누르고 그 자리로 걸어갑니다.
4. **확인:** 궁성 동·서 담을 따라 가서 문을 보면 정상입니다. 문은 닫혀 있어 지나갈 수 없습니다(원래 설계).

## 4. 어떻게 만들어졌나 (구조)

### 4-1. 만들거나 고친 파일

| 경로 | 신규/수정 | 역할 (한 문장) |
|---|---|---|
| `Assets/Prefabs/NMJ/Gyeongbokgung/NMJ_GJJ_Gates.prefab` | 신규 | 두 문 |
| `Assets/Arts/Models/NMJ/Gyeongbokgung/NMJ_GJJ_Gates.fbx` · `Source~/NMJ_GJJ_Gates.blend` · `Source~/parts/gatedoor.fbx` | 신규 | 모델·원본·바르코 문짝 |
| `Assets/Scenes/Common/Main.unity` | 수정 | 프리팹 놓음, 옛 건춘문·영추문·석축 끔 |

### 4-2. 클래스 관계

코드 없음. 모델·재질·충돌체뿐입니다.

### 4-3. 동작 흐름

벽·기단·기둥은 MeshCollider로 막고, 지붕은 충돌체가 없습니다.

### 4-4. 프리팹·씬 구성

- 프리팹 루트 안에 FBX 자식 하나(로컬 회전 Y 180°). 재질은 물체마다 1개
- 옛 블록 물체는 지우지 않고 끔

## 5. 왜 이렇게 만들었나 (설계 이유)

| 결정 | 이유 | 버린 대안과 그 이유 |
|---|---|---|
| 큰 형태는 스크립트, 조각 많은 부분·그림은 바르코3D | 지붕·기와는 스크립트가 깔끔하고, 장식·그림은 AI가 사실적 | 통째로 바르코: 면이 뭉개짐 |
| 기존 블록과 같은 자리·크기 | 다른 배치가 그대로 맞음 | 실제 치수로 새로: 맵 배치를 다시 해야 함 |
