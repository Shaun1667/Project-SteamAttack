# 회의록 템플릿

- 저장: `Meetings/YYYY-MM-DD_제목.md`
- 아래 `---` 부터 복사해서 씁니다. 해당 없는 칸은 `없음`으로 씁니다.
- 회의가 끝나면: 결정을 [결정 로그](../Meetings/README.md)에 추가 → 해당 기획서 수정 → 회의록 목록에 한 줄 추가.

## 작성 규칙 (말투)

- **사실만 짧게 씁니다.** 미사여구, 감탄, 인사, 수식어("매우", "효과적으로", "성공적으로")는 쓰지 않습니다.
- 항목은 **명사형이나 짧은 평서문으로 끝냅니다.** 예: `인벤토리 제외`, `5분 정도 보여줄 수 있게 짧고 굵게`, `내일 다시 논의`.
- "~했습니다", "~할 예정입니다" 같은 높임 서술은 쓰지 않습니다. 이유를 적을 때만 `~하고 싶었다.`, `~해야 한다.` 같은 평서문을 씁니다.
- 논의 항목은 `**주제:** 내용` 형식으로 씁니다. 한 줄에 하나만 씁니다.
- 담당자는 이니셜로 씁니다. 처음 나올 때만 이름을 같이 적습니다. 예: `YPH (윤평화)`.
- 날짜는 `2026년 10월 14일`처럼 연·월·일을 모두 씁니다. "내일", "다음 주"만 쓰지 않고, 괄호 안에 실제 날짜를 넣습니다.
- 확정되지 않은 것은 결정에 넣지 않습니다. `보류`라고 적고 `7. 확인·후속`에 옮깁니다.
- 받아쓰기(STT)에서 알아듣지 못한 내용은 추측하지 않습니다. 그 내용은 빼거나 `(확인 필요)`라고 표시합니다.
