# 개발자 요청 문서 템플릿

내 작업 범위(내 이니셜 폴더) 밖의 수정이 필요할 때, 담당자가 **이 문서만 읽고 바로 처리**할 수 있게 씁니다.

- 저장 위치: `TeamWorkflow/Requests/진행/` (D-057). 처리가 끝나면 받는 사람이 `Requests/완료/`로 옮깁니다. 만든 뒤 커밋하고 받는 사람에게 알립니다.
- 파일명: `<받는 사람>_요청_날짜_짧은제목.md` (예: `NGH_요청_20261001_플레이어프리팹수정.md`). 받는 사람을 맨 앞에 쓰고, 요청자는 머리 표에만 씁니다(D-089)
- 아래 `---` 부터 복사해서 씁니다.
- 한 문서에는 **요청 하나**만 담습니다. (처리 상태를 따로 추적하기 위해서입니다.)
