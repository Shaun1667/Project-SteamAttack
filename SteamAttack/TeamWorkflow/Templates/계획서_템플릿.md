# 구현 계획서 템플릿 (선택)

기획서(`Design/`)를 실제 작업 단위로 쪼갤 때 씁니다. 사람이 구현하든 AI에게 맡기든 **이 문서만 보고 바로 구현할 수 있게** 씁니다. 필수 문서는 아닙니다.

- 저장 위치: 각자 정합니다. 팀 저장소에 올리지 않는 개인 작업 문서입니다.
- 파일명: `<이니셜>_계획_날짜_짧은제목.md` (예: `YPH_계획_20261001_플레이어이동.md`)
- 무엇을 만들지는 기획서가 원본입니다. 계획서에는 기획 내용을 옮겨 쓰지 않고 링크만 겁니다.
- 아래 `---` 부터 복사해서 씁니다. 해당 없는 칸은 지우지 말고 "없음"이라고 적습니다.
- 사용자가 "확정"하기 전에는 상태를 `초안`으로 두고, 미결정 칸에 질문을 남깁니다.
