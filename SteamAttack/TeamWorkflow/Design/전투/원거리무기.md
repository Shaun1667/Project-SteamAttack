# 원거리 무기 (증기 격발 화승총)

<aside>
📌

**기획자:** CHG, NMJ (v3)

**구현 담당:** YPH

**상태:** 초안

**관련 결정:** D-017, D-022, D-028, D-040

**한 줄 요약:** 증기로 격발하는 화승총. 조준 사격과 받아치기를 겸하고, 탄약 없이 증기 10을 씀.

</aside>

## 1. 목표

- 지붕 위 궁수, 높이 있는 뱀 머리처럼 칼이 닿지 않는 적을 맞힘
- 받아치기와 같은 총을 써서 무기 하나로 두 역할을 보여줌

## 2. 규칙

- 원거리 무기는 증기 격발 화승총 1개 (D-040). 수류탄 제외 ([보관](../_제외/수류탄.md))
- TAB으로 화승총을 들고 우클릭 홀드로 조준, 조준 중 좌클릭으로 발사
- 히트스캔 판정
- 탄약 없음. 한 발마다 증기 10
- 증기가 10 미만이면 사격·받아치기 모두 불가
- 조준 중 조준 영역만 밝게 두고 바깥을 반투명 검정으로 덮어 조준 영역을 강조함(딤드, D-017). HUD는 어두워지지 않음
- 조준점(크로스헤어)은 없음. 딤드가 어색하면 일반 조준점으로 바꿈
- 받아치기는 들고 있는 무기와 관계없이 CTRL로 이 총을 씀. [받아치기](패링.md)

## 3. 수치

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 사거리 | 25m | |
| 피해 | 강공격과 같음 (약공격 ×2) | |
| 증기 소모 | 10 | [증기 시스템](증기시스템.md) |
| 경직 | 일반 경직 | |
| 딤드 모양 | 원형 | |
| 딤드 크기 | 화면 세로 기준 지름 45% | |
| 딤드 경계 | 반경의 25~30% 그라데이션 | |
| 딤드 페이드 인 / 아웃 | 0.12~0.15초 / 0.08~0.1초 | |
| 딤드 알파 | 0.5 | 초기값, 플레이테스트 후 확정 |

## 4. 근거

- 보통 화승총은 멈춘 도성에서 쏠 수 없고 증기 격발식만 쏠 수 있음. 세계관 [법칙 7](../세계관/세계관.md)
- 조준 중에도 적의 공격 예고가 보여야 받아치기를 판단할 수 있으므로 딤드 알파를 낮게 둠
- 조준경 없는 총이라 원형 딤드. 레퍼런스: 워프레임 메사. 어색하면 일반 조준선으로 바꿈
