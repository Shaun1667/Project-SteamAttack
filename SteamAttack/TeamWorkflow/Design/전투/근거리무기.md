# 근거리 무기 (환도·증기발도)

<aside>
📌

**기획자:** CHG, NMJ (v3)

**구현 담당:** NGH (근접 모션)

**상태:** 초안

**관련 결정:** D-022, D-043

**한 줄 요약:** 환도로 약공격·강공격을 하고, 증기 100을 모으면 증기발도로 현무의 가갑을 깸.

</aside>

## 1. 목표

- 근접 액션으로 증기를 모음
- 증기발도로 현무 가갑을 깨는 장면이 시연의 클라이맥스

## 2. 규칙

- 근거리 무기는 환도 1개 (D-022)
- 좌클릭 약공격, 우클릭 강공격
- 강공격 피해는 약공격의 2배
- 적중하면 증기 획득. [증기 시스템](증기시스템.md)

**증기발도 (D-043)**

- Z로 사용. 증기가 100일 때만 사용 가능
- 사용하면 증기 100 전부 소모
- 전방 부채꼴 범위 공격
- 현무의 흑철 가갑을 부수는 유일한 수단

## 3. 수치

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 약공격 피해 | 공격력 10 | [스탯 수치](../성장/스탯수치.md) |
| 강공격 피해 | 약공격 ×2 | |
| 증기발도 증기 | 100 (전량) | |
| 증기발도 범위 | 전방 4.5m, 180° | |
| 증기발도 피해 | 약공격 ×6 | |

## 4. 근거

- 흑철은 한 점에 몰린 고열에만 금이 감. 세계관 [법칙 6](../세계관/세계관.md)
- 증기를 칼(증기발도)과 시간(시간 역행) 중 어디에 쓸지 고르게 함. 세계관 [법칙 5](../세계관/세계관.md)

![근거리 무기 예시](../images/근거리무기_1.png)

## 5. 연출·피드백

| 시점 | 화면(VFX·UI) | 소리(SFX) | 애니메이션 |
| --- | --- | --- | --- |
| 약공격·강공격 적중 | 타격 이펙트 | 타격음 | 약공격·강공격 |
| 증기 100 | 증기통 붉은 증기 | 미정 | 없음 |
| 증기발도 | 전방 부채꼴 증기 폭발 | 미정 | 발도 |
| 가갑 파괴 | 가갑 파편 | 미정 | 현무 피격 |

## 6. 연관 기능

- [증기 시스템](증기시스템.md): 적중 시 획득, 증기발도 −100
- [현무](../적/현무.md): 가갑 파괴
- [피격·경직](피격경직.md): 약공격 일반 경직, 강공격 HEAVY 경직
- [받아치기](패링.md): 받아치기로 증기를 빨리 채움
