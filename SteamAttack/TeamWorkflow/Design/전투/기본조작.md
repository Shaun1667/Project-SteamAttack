# 기본 조작

<aside>
📌

**기획자:** NMJ (v3 조작표)

**구현 담당:** NGH (이동·구르기)

**상태:** 구현 중

**관련 결정:** D-028, D-039(대체됨), D-042, D-043(대체됨), D-067, D-071, D-082, D-090

**한 줄 요약:** 키보드·마우스 키 배치와 이동, 발도·납도, 구르기, 락온 규칙.

</aside>

## 1. 목표

- 왼손으로 이동·구르기·받아치기·시간 역행을 모두 조작
- 시연 중 안내 자막 몇 개만으로 조작을 익힘

## 2. 규칙

**입력**

- 조준·공격·락온을 제외한 전투 기능은 왼손 키에 배치
- 기능마다 누르기 또는 홀드 중 하나로만 입력
- 스태미나 없음
- 시연자 키와 디버그 키는 [디버깅 메뉴](../UI/디버깅메뉴.md)에서 관리

**이동**

- WASD 8방향 이동. 대각선도 직선과 같은 속도
- SHIFT 홀드 중 전력질주. 방향과 관계없이 같은 달리기 모션
- 이동 방식은 발도·납도 상태와 락온 여부로 바뀜

| 상태 | 이동 방식 |
| --- | --- |
| 납도 | 자유 8방향 이동 |
| 발도 | 8방향 이동. 뒤로 입력하면 뒷걸음질 |
| 락온 | 자동 발도. 대상을 바라본 채 전후좌우 이동 |
| 전력질주 | 상태와 관계없이 같은 달리기 모션 |

**발도·납도**

- C로 발도·납도 전환
- 납도 상태에서 공격을 입력하면 발도 후 공격
- 락온하면 자동 발도. 납도하면 락온 해제
- 자동 납도 없음

**구르기**

- 구르기가 끝나기 전에는 다시 구를 수 없음
- 구르기 중 일부 구간 무적

**무기 변경**

- TAB으로 환도 ↔ 화승총 전환. 사격용 장착 전환
- 납도 상태에서 바꾸면 선택만 바뀌고 발도하지 않음
- 받아치기(Ctrl)는 들고 있는 무기로 함. 환도면 칼 패링, 화승총이면 총 패링 모션 (D-082)

**락온**

- 락온 중에는 대상을 바라본 채 이동. 좌우·대각선은 대상 중심 횡이동, 뒤로는 대상을 보며 후퇴
- 대상 전환 기능 없음
- 대상이 죽으면 락온 해제. 범위 안에 다른 적이 있으면 자동으로 옮겨 감

**상호작용**

- F로 상호작용, 신핵 QTE 시작
- 대상에 다가가면 입력 안내 UI 표시

## 4. 근거

- 오른손은 마우스(조준·공격)를 쥐므로 나머지 전투 기능을 왼손에 모음
- 대상 전환을 빼서 락온 조작을 단순하게 함

## 7. 확인 필요

- 담당: 이동·구르기 NGH (D-036)
- 강공격 입력: 기획은 우클릭, 현재 구현은 좌+우 동시 클릭
- 발도·납도 키: 기획은 C, 현재 구현은 F (F는 기획상 상호작용·신핵 QTE)
- 조작키 안내·키 재지정 채택 여부 (2026-10-15 회의 추가 기능 후보)
