# 받아치기 (패링)

<aside>
📌

**기획자:** NMJ (v3), 2026-10-15 회의

**구현 담당:** YPH (판정·규칙·동심원, 총 패링 모션), NGH (칼 패링 모션)

**상태:** 구현 중

**관련 결정:** D-009(대체됨), D-032(대체됨), D-039(대체됨), D-061(대체됨), D-065, D-066, D-067, D-068, D-069, D-082, D-084, D-090, D-094

**한 줄 요약:** 적의 받아칠 수 있는 공격에 맞춰 Ctrl을 눌러 공격을 끊는 기술. 성공하면 적이 경직되고 그 사이 강공격을 넣을 수 있음.

</aside>

## 1. 목표

- 받아치기 → 적 경직 → 강공격으로 이어지는 전투 흐름을 보여줌
- 육조거리에서 반드시 한 번 보여줌

## 2. 규칙

**입력·판정**

- Ctrl로 사용 (D-067)
- 들고 있는 무기로 받아침. 환도를 들었으면 칼 패링 모션, 화승총을 들었으면 총 패링 모션 (D-082)
- 판정·규칙·동심원은 무기와 관계없이 하나 (`YPH.ParryController`, D-066, D-082)
- 받아칠 수 있는 공격 직전에 공격 지점에 흰 동심원 표시. 바깥 원이 안쪽으로 조여듦
- 두 원이 겹치는 시점 전후 허용 폭 안에 누르면 성공 (D-067, D-084)
- 받아칠 수 있는 공격: 일반 적 강공격, 보스 일부 패턴 (D-067)
- 궁수의 화살 받아치기는 제외. 화살 반사·튕김 연출도 이번 범위에 넣지 않음 (D-094)
- 면으로 오는 공격(돌진, 브레스 등)은 받아칠 수 없음. 구르기로 피함

**성공**

- 적 공격 무효, 적 경직 (D-067)
- 경직 동안 플레이어가 강공격을 넣을 기회 (D-067)
- 약점 노출·다음 공격 피해 증가 없음 (D-068)
- 증기 변화 없음 (D-067)
- 시각 이펙트·효과음으로 성공을 알림

**실패**

- 타이밍이 안 맞으면 적의 공격이 정상 피해로 들어옴
- 빠름·늦음 구분 없음
- 실패 시 증기 차감은 기능만 두고 플레이에는 적용하지 않음 (D-069)

**구현 원칙 (D-066)**

- 근거리·원거리 받아치기는 하나의 시스템, 공통 규칙
- 기획과 맞지 않는 옛 받아치기 코드(`NGH.PlayerParry` 등)는 다시 구현
- 쓸 수 있는 기존 애니메이션 재사용
- 적 AI의 기존 호출 방식 유지
- 바꿔야 할 남의 코드는 요청 문서로

**담당 (D-065, D-082)**

| 부분 | 담당 |
| --- | --- |
| 판정·규칙·동심원, 적 공통 인터페이스(`YPH.IParryTarget`), 플레이어 프리팹 연결 | YPH |
| 화승총 패링 모션(임시 Rifle Block + 총구 섬광), 애니메이터까지 | YPH |
| 환도 패링 모션 | NGH |
| 현무의 받아칠 수 있는 패턴에 공통 인터페이스 구현 | BHS |

## 4. 근거

- 보상을 경직 후 강공격 기회 하나로 줄여 규칙을 단순하게 함 (2026-10-15 회의)
- 들고 있는 무기로 받아쳐야 무기 전환 없이 자연스러운 모션이 나옴 (D-082)
- 총알 한 발은 한 점만 끊음. 세계관 [법칙 7](../세계관/세계관.md)

## 6. 연관 기능

## 7. 확인 필요

- 화승총을 들고 받아칠 때 화승총 발사 비용을 내는지. 10.15 회의는 "화승총 발사 비용은 따로", 이후 받아치기는 들고 있는 무기로 바뀜(D-082)
- 적 경직 시간
- 쿨타임 2초 유지 여부 (압축기획안 v3 값, 10.15 회의에서 언급 없음)
