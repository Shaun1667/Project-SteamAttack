# 아웃게임

<aside>
📌

**기획자:** CHG

**구현 담당:** NMJ (디자인)

**상태:** 초안

**관련 결정:** D-028

**한 줄 요약:** 타이틀, 설정, 일시정지, 클리어 화면과 화면 전환.

</aside>

## 1. 목표

- 시연 시작과 끝을 정리된 화면으로 보여줌
- 화면 전환에 수묵 느낌을 줌

## 2. 규칙

| 화면 | 내용 |
| --- | --- |
| 게임 실행 | 팀 이미지 |
| 메인 화면 | 게임 시작, 환경 설정, 게임 종료 |
| 환경 설정 | 마스터 음량, SFX, BGM, 감도, 해상도, 전체화면 |
| ESC 메뉴 | 계속하기, 조작법, 설정, 타이틀로, 게임 종료 |
| 클리어 화면 | 세계관 한 줄 문구, 플레이 시간, 사망 횟수, 타이틀로 버튼 |

- 타이틀로·게임 종료는 한 번 더 확인을 받음
- 화면 전환은 먹물이 번지며 덮었다가 다음 화면으로 넘어감
- UI 전체는 동양화, 먹물 느낌으로 통일

## 7. 확인 필요

- 불러오기·저장: 체크포인트 제외(D-028)로 저장 지점이 없음. 원본의 "불러오기", "진행 상황 저장" 문구를 뺐음. 저장이 필요한지 확인
- 사망 후 재시작은 [시연 흐름](../월드/시연흐름.md)의 사망 처리를 따름. 사망 화면 팁 없음
- 엔딩 크레딧 여부. v3 엔딩은 해빙 후 로고
- 담당: UI 디자인 NMJ (D-036)
