# 디버깅 메뉴·시연자 도구

<aside>
📌

**기획자:** NMJ (v3 시연자 도구)

**구현 담당:** 미정 (개발자 창은 NMJ)

**상태:** 초안

**관련 결정:** D-051, D-056, D-064, D-088, D-090, D-091, D-095, D-098

**한 줄 요약:** 회복·무적·무한 증기·부위별 한 방 처치·구간 이동·리젠을 제공하는 개발자 창. 기존 시연자 키와의 통합은 확인 필요.

</aside>

## 1. 목표

- 테스트 중 수치와 모션을 바로 확인
- 시연 중 구간 건너뛰기·재시작으로 흐름을 지킴

## 2. 규칙

**개발자 도구 (D-064, D-098)**

- NMJ가 개발. 증기 기능을 제외한 부분부터 작업하고, YPH의 증기 가방 정리를 병합한 뒤 증기 기능 연결
- 버튼 하나로 창을 열고 창 안에서 기능 선택. 호출 키는 미정

| 기능 | 동작 |
| --- | --- |
| 체력 회복 | 플레이어 체력 회복 |
| 증기 회복 | 플레이어 증기 회복 |
| 무적 | 체력만 줄지 않음. 피격 판정·피격 및 경직 모션 유지 |
| 무한 증기 | 켜 둔 동안 증기를 최대치로 고정. 피격·체력 감소 등 다른 기능은 평소대로 유지하며, 무적은 별도 선택 |
| 검 이펙트 (시안 비교, 임시) | 강공격 이펙트 시안을 바꿔 가며 봄: 기존 → C2 붉은 칼금 → C3 붉은 김 → 자동(증기 가득이면 C3). 일반 공격은 그대로. [요청서](../../Requests/진행/NGH_요청_20261023_강공격붉은칼금.md) |
| 원펀맨 모드 | 일반 적은 한 번에 처치. 보스는 맞힌 부위 하나만 한 번에 파괴하며, 다른 다리까지 동시에 파괴하지 않음 |
| 이동 | 시작 지점, 육조거리, 보스방 앞의 3개 지점. 보스방 이동 목표는 방 내부가 아님 |
| 리젠 | 현재 구역의 적을 모두 제거하고 다시 생성. 육조거리에서는 일반 적, 보스방에서는 보스 재생성 |

- 리젠 버튼으로 보스를 제거할 때는 처치·엔딩 연출을 재생하지 않음. 플레이어가 전투로 처치하면 정상 엔딩
- 무한 증기를 끄면 일반 증기 규칙을 사용. 회복 과정을 보여줄 때는 무한 증기를 끔
- 일정은 [프로젝트](../00_프로젝트.md)의 D-091 기준
- 코어 노출·무한 증기의 세부 의미는 2026년 10월 19일 YPH가 추가 확인. 무한 증기는 다른 피격 기능을 끄는 모드가 아님

**공통**

- 디버그 키는 최종 빌드에서 제외
- 화면에 찍히는 디버그 글자는 기본 꺼짐, 키로 켬. 시연·녹화 화면에 나오지 않게 (D-088)
- 시연자 키는 최종 빌드에서 시연 모드일 때만 켬
- 디버깅 메뉴에서 상세 스탯 수치 확인 가능
