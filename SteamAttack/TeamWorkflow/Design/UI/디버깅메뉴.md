# 디버깅 메뉴·시연자 도구

<aside>
📌

**기획자:** NMJ (v3 시연자 도구)

**구현 담당:** 미정

**상태:** 초안

**관련 결정:** D-051, D-056, D-064, D-088, D-090

**한 줄 요약:** 개발용 디버그 키와, 5분 시연을 매번 같게 보여주기 위한 시연자 숨김 키.

</aside>

## 1. 목표

- 테스트 중 수치와 모션을 바로 확인
- 시연 중 구간 건너뛰기·재시작으로 흐름을 지킴

## 2. 규칙

**개발자 도구(개발자 루트) (D-064)**

- 기능 구현(2026-10-18) 후 QA·버그 수정 단계에 추가
- 버튼 하나로 개발자 창을 엶
- 창 안에서 클릭으로 기능을 조절
- 보스전 등 지정 구간으로 바로 이동

**공통**

- 디버그 키는 최종 빌드에서 제외
- 화면에 찍히는 디버그 글자는 기본 꺼짐, 키로 켬. 시연·녹화 화면에 나오지 않게 (D-088)
- 시연자 키는 최종 빌드에서 시연 모드일 때만 켬
- 디버깅 메뉴에서 상세 스탯 수치 확인 가능

## 3. 수치

**시연자 키 (D-051)**

| 키 | 기능 |
| --- | --- |
| F9 | 다음 구간으로 건너뛰기 (육조거리 → 광화문 → 현무 → 엔딩) |
| F10 | 무적 켜기·끄기 |
| F11 | UI 숨기기 (녹화용) |

**디버그 키**

| 키 | 기능 |
| --- | --- |
| 0 | 디버깅 메뉴 열기 |
| ALT+1, ALT+2 | 피격 모션 재생 |
| ALT+3 | 체력바 수치 표시 |

**테스트·디버그 키 예약표 (D-056)**

새 테스트·디버그 키는 쓰기 전에 여기에 한 줄 추가합니다. 아래는 2026-10-14 코드 조사 결과입니다(YPH 브랜치 기준).

| 키 | 하는 일 | 스크립트 | 담당 | 충돌 |
| --- | --- | --- | --- | --- |
| 0, 숫자패드 0 | 적 AI 디버그 화면 | `YPH.DebugView` | YPH | 디버깅 메뉴 열기(0)와 겹침 |
| 1~5·7, 숫자패드 1~5·7 | 적 AI 디버그 명령 (0으로 개발용 표시를 켠 동안만) | `YPH.EnemyDebugTools` | YPH | 켠 동안 NGH 1~4 시험 키를 끄고, 끄면 복구 |
| 숫자패드 0~5 | 증기 HUD 시험 키 (`testKeys` 기본 켜짐) | `NMJ.SteamCylinderGauge` | NMJ | `EnemyDebugTools` 숫자패드 키와 겹침. HUD를 플레이어에 붙이면(D-086) 실제 충돌 |
| 1, 2 | 플레이어 피격(약·강) 테스트 | `NGH.PlayerController` | NGH | 기획은 ALT+1, ALT+2 |
| 3, 4 | 증기 소모·충전 테스트 | `NGH.TimeRewindTester` | NGH | 적 AI 디버그와 겹침 |
| F1~F11 | 퀘스트 진행 디버그 | `NMJ.QuestDebugTester` | NMJ | F9~F11은 시연자 키와 겹침 |
| G, R, Tab | 전투 시험 씬 입력 | `YPH.CombatTestInput` | YPH | Tab은 무기 교체와 같은 키 (시험 씬 전용) |

## 7. 확인 필요

- 개발자 창 호출 버튼·키, 창 안 메뉴 구성 (2026-10-15 회의 후속)
- 개발자 창과 시연자 키(F9~F12)·디버깅 메뉴(0)를 하나로 합칠지
- 개발자 도구 구현 담당: 주말 작업 후 회의에서 배정 (D-080)
- 지금 `NGH.TimeRewind` 디버그 표시가 기본 켜짐이라 NMJ 퀘스트 디버그 안내와 왼쪽 위에서 겹침 (요청 `NGH_요청_20261016_디버그표시기본끄기.md`)
- 시연 모드를 켜는 방법
- 키 충돌 정리: 0, 1~4, F9~F11 (위 예약표 `충돌` 칸). 누가 어느 키로 옮길지 회의에서 정함
- 발도/납도 키: 기획은 C, 구현은 F(`NGH.PlayerController`). F는 기획상 상호작용·신핵 QTE 키라 [기본조작](../전투/기본조작.md)과 함께 정함
