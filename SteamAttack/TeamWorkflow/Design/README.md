# 기획 (Design)

기능별 **현재 확정본**을 둡니다. 결정이 바뀌면 이 폴더의 문서를 고치고, 바뀐 이유는 [결정 로그](../Meetings/README.md)에 남깁니다.

- 새 기능은 [기획서 템플릿](../Templates/기획서_템플릿.md)으로 해당 분류 폴더에 `기능이름.md`를 만듭니다. `세계관/`은 B 양식, 나머지는 A 양식입니다. 범위·일정·빌드·담당처럼 기능이 아닌 결정은 [00_프로젝트.md](00_프로젝트.md)에 둡니다.
- 분류: `세계관/` · `전투/` · `성장/` · `적/` · `월드/` · `UI/` · 그림은 `images/기능명_번호.확장자`
- 기획서를 고치면 문서 맨 아래 `변경 이력`에 `날짜 | D-번호 | 바뀐 내용`을 남깁니다.
- **기획서는 그 문서의 구현 담당이 고칩니다.** 구현 담당이 미정이면 NMJ가 고칩니다. 서기 YPH는 모든 기획서를 고칠 수 있습니다(D-085). 고칠 결정은 [현황](../Meetings/현황.md)의 `반영 대기`에 나옵니다.
- 기획자·구현 담당·상태·관련 결정은 **각 문서 머리(📌)에만** 씁니다. 아래 기능 표는 `python Tools/check.py --write`가 머리 정보로 다시 만드니 직접 고치지 않습니다. 담당이 바뀌어도 파일은 옮기지 않습니다.
- 각 문서의 `확인 필요`는 [현황](../Meetings/현황.md)에 모입니다. 회의 안건은 거기서 고릅니다.

- **기획자**는 처음 쓴 사람입니다. 빈 곳은 `-`입니다.
- 채희강(CHG)은 앞으로 팀에 없는 것으로 봅니다. 기획자 칸의 `채희강`은 원작성 기록입니다. 이 문서들의 수정·확정은 회의에서 담당을 정해 진행합니다.
- **구현 담당**은 2026-10-13 회의(D-036) 기준으로 각 문서 머리에 옮겼습니다.
- **마지막 반영 결정**은 문서 `변경 이력`에 적힌 가장 큰 D-번호입니다.
- 2026-10-13 NMJ 압축기획안 v3와 세계관 설정 v3가 최신 기획입니다(D-039~D-051). 회의 결정과 다른 점은 각 문서 `확인 필요`에 있습니다.
- **상태**: `초안` → `확정` → `구현 중` → `완료`(기능 문서 링크). 정하지 않고 미룬 것은 `보류`.

## 기획안 원문 (`_원문/`)
