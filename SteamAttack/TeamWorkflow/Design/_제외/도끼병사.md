## 1. 목표

- 플레이어가 가장 먼저 만나는 적
- 일반 공격으로 구르기, 강공격으로 패링을 연습시킴

## 2. 규칙

**행동 흐름**

대기 → 플레이어 감지 → 추적 → 사거리 진입 → 공격 패턴 선택 → 공격 → 후딜레이 → 다음 행동

- 플레이어가 사거리 밖으로 나가면 다시 추적
- 공격 중에는 새 공격을 시작하지 않음

| 상태 | 행동 |
| --- | --- |
| 대기 | 제자리 대기 |
| 추적 | 플레이어에게 접근 |
| 공격 | 사거리 안에서 일반 공격 또는 강공격 |
| 피격 | 피격 반응 |
| 패링당함 | 공격 중단, 약점 노출 |
| 사망 | HP 0 이하에서 사망 |

**패턴 1. 일반 공격: 도끼 내려찍기**

- 도끼를 들어 올렸다가 내려침
- 내려오는 순간 전방 근거리 판정
- 짧은 후딜레이
- 패링 불가. 구르기나 거리 벌리기로 대응

**패턴 2. 강공격: 달려 도끼 내려찍기**

- 달려오며 점프해 도끼를 높이 듦
- 패링 예고(동심원) 표시
- 일반 공격보다 피해와 피격 반응이 큼
- 패링 가능
- 패링 성공 시 강공격 취소, 패링당함 모션, 약점 노출

## 3. 수치

| 항목 | 값 | 비고 |
| --- | --- | --- |
| HP | 50 | 초기값, [스탯 수치](../성장/스탯수치.md) |
| 일반 공격 비율 | 70% | 초기값 |
| 강공격 비율 | 30% | 초기값 |

## 4. 근거

- 특수 능력 없이 예고가 분명한 두 패턴만 둬서 첫 전투에서 규칙을 익히게 함

## 5. 연출·피드백

| 시점 | 화면(VFX·UI) | 소리(SFX) | 애니메이션 |
| --- | --- | --- | --- |
| 일반 공격 | 타격 이펙트 | 도끼 휘두르는 소리 | Attack_Normal |
| 강공격 | 패링 동심원 | 미정 | Attack_Heavy |
| 패링당함 | 약점 노출 표시 | 미정 | Parried |
| 피격 | 피격 이펙트 | 피격음 | Hit |
| 사망 | 없음 | 미정 | Death 후 비활성화 |

필수 애니메이션: Idle, Walk/Run, Attack_Normal, Attack_Heavy, Hit, Parried, Death

## 6. 연관 기능
