## 1. 목표

- 시연자가 5분 ± 30초 안에 3회 연속 완주
- 2026년 11월 3일(화) 시연

## 2. 규칙

**5분 흐름**

| 시간 | 구간 | 일어나는 일 | 보여줄 것 |
| --- | --- | --- | --- |
| 0:00~0:20 | ① 오프닝 | 전등 점화 → 발전기 폭주 → 멈춘 눈송이 → 고종의 어명 → 육조거리로 전환 | 세계관 한 번에 |
| 0:20~1:20 | ② 육조거리 | 시작 구간 허수아비로 칼 타격·증기 충전을 익힌 뒤 일반 적 전투. 근접 2 → 원거리 1 → 근접 1(내려치기), 첫 동심원에 슬로우 + "CTRL" 안내 | 증기 충전, 근접 액션, 첫 받아치기, 화승총 사격 |

| 2:20~2:40 | ③-2 궁 안 | 근정전 마당 → 향원정으로 달림. 근접 2(선택) | 멈춘 경복궁, 이동 |

| 4:40~5:00 | 엔딩 | 보스 처치 문구(예: `Boss Eliminated`) → 해빙 → 엔딩 크레딧 (D-078) | 클라이맥스, 시연의 끝을 분명히 |

**사망 처리 (D-099)**

- 다시 시작할 때 사망한 자리에서 재개
- 자동으로 재개할지 버튼을 눌러 재개할지는 미정
- 재개 시 체력·증기와 적·보스 상태의 유지·초기화 수치는 미정
- v3(D-047)의 길 체력 50%, 보스전 처음부터·체력 100·증기 0, 2회 사망 시 현무 체력 30% 감소는 이번 회의에서 재확정하지 않음. 제자리 재개와 함께 적용할지는 7번에서 확인

- 저장 지점 오브젝트 없음. 보스 입장 순간의 상태만 기억. 시연용 체크포인트·불러오기는 제외 (D-079)
- 사망 연출: 종이가 타듯 군데군데 사라지는 소멸 셰이더 우선. 어려우면 다른 방식 (D-077, NGH)

**시작과 끝 (D-078)**

- 시연의 시작(오프닝)과 끝(처치 문구 → 크레딧)을 분명히 구분
- 보스 처치 시 문구 출력, 실명을 표기한 엔딩 크레딧 (D-096)
- 보스 씬에서 Main으로 돌아왔을 때 프롤로그가 다시 재생되는 문제 수정 (D-103). 새 게임의 최초 오프닝은 유지
- 시작 구간에 허수아비를 배치해 칼 타격으로 증기가 차는 것을 확인 (D-105). 시작 증기량은 [증기 시스템](../전투/증기시스템.md) 기준

**늦어지면 버리는 순서**

1. 궁 안 잡몹
2. 원거리 잡몹
3. 오프닝 컷씬 (자막 3줄로 대체)

**끝까지 지키는 것**

- 받아치기 → 적 경직 → 강공격
- 시간 역행으로만 피할 수 있는 보스 공격을 되감아 넘기기

## 3. 수치

**일정 (D-091)**

- 기능 작업 마감은 2026년 10월 21일, 에셋 배치 완료는 2026년 10월 28일
- 수정·테스트·발표 준비의 현재 일정은 [프로젝트 일정표](../00_프로젝트.md#2-일정빌드)에서 관리
- 기존 2026년 11월 3일 시연 목표(D-050)는 유지
- 위 5분 구간표는 기존 목표 시간. 허수아비 추가 후 실제 소요 시간은 다시 확인

## 7. 확인 필요

- 제자리 재개(D-099)의 자동·수동 여부, 버튼 구성, 체력·증기·적·보스 초기화 수치. 2회 사망 시 보스 체력 보정 유지 여부
- 프롤로그 재생 상태를 초기화할 시점: 새 게임·타이틀 복귀·완전 재시작의 차이(D-103)
- 허수아비의 구현·배치 담당, 증기 충전 안내 종료 조건, 패링 연습을 겸할지와 공격 동작(D-105)
- 엔딩 세부 (NMJ, D-080): 처치 문구 표시 시간, 크레딧 전환, 종료 후 이동 화면
- 사망 연출 디테일: 색상·파티클·재시작 연결
- 개발자 도구(D-064)의 "지정 구간 이동"과 시연자 키 F9의 관계
- 10.13 회의의 시작 시네마틱 10~20초(D-038)와 v3 오프닝 20초는 같은 것으로 봄

**완료 체크리스트**

1. 육조거리 시작부터 엔딩까지 씬 전환 1번(안개문)으로 이어진다
2. 5분 ± 30초 안에 3회 연속 끝낸다
3. 육조거리에서 받아치기를 반드시 한 번 본다
4. 광화문 앞에서 증기 100(붉은 증기)을 한 번 본다
5. 받아치기 후 경직된 적에게 강공격이 들어간다
6. 시간 역행으로만 피할 수 있는 보스 공격을 되감아 넘길 수 있다
7. 사망해도 흐름이 끊기지 않는다
8. 길에서 벗어나거나 되돌아갈 수 없다
9. 시연자 키 4개가 모두 작동한다
