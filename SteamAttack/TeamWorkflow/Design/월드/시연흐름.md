## 1. 목표

- 시연자가 5분 ± 30초 안에 3회 연속 완주
- 2026년 11월 3일(화) 시연

## 2. 규칙

**5분 흐름**

| 시간 | 구간 | 일어나는 일 | 보여줄 것 |
| --- | --- | --- | --- |
| 0:00~0:20 | ① 오프닝 | 전등 점화 → 발전기 폭주 → 멈춘 눈송이 → 고종의 어명 → 육조거리로 전환 | 세계관 한 번에 |
| 0:20~1:20 | ② 육조거리 | 근접 2 → 원거리 1 → 근접 1(내려치기). 첫 동심원에 슬로우 + "CTRL" 안내 | 근접 액션, 첫 받아치기, 화승총 사격 |
| 1:20~2:20 | ③ 광화문 앞 | 포졸 무리(근접 3 + 원거리 1). 마지막 한 명이 쓰러지면 얼음 문 파괴, "한 호흡에, 한 점에" 자막 | 받아치기 → 약점 노출 반복, 증기 100 |
| 2:20~2:40 | ③-2 궁 안 | 근정전 마당 → 향원정으로 달림. 근접 2(선택) | 멈춘 경복궁, 이동 |
| 2:40~4:40 | ④ 현무 | 안개문 → 아레나 → 1페이즈(가갑 2장) → 2페이즈 합동기 1회 → 신핵 QTE | 증기발도, 시간 역행, 보스전 |
| 4:40~5:00 | 엔딩 | 해빙, 눈이 다시 떨어짐, 로고 | 클라이맥스 |

**사망 처리 (D-047)**

| 상황 | 처리 |
| --- | --- |
| 길(②, ③, ③-2)에서 사망 | 0.5초 먹물 전환 후 그 자리에서 체력 50%로 일어남. 적은 그대로 |
| 현무전에서 사망 | 먹물 전환 후 보스전 시작 상태로. 체력 100, 증기 0 |
| 현무에게 2번 사망 | 현무 체력 30% 깎고 시작 |

- 저장 지점 오브젝트 없음. 보스 입장 순간의 상태만 기억

**늦어지면 버리는 순서**

1. 궁 안 잡몹
2. 원거리 잡몹
3. 오프닝 컷씬 (자막 3줄로 대체)

**끝까지 지키는 것**

- 받아치기 → 증기 → 증기발도로 가갑 파괴
- 합동기를 시간 역행으로 넘기기

## 7. 확인 필요

- **일정 충돌:** 10.13 회의는 10/18 기능 구현 마감·10/19부터 배치(D-035), v3는 10/24 기능 동결·11/2 빌드 잠금(D-050). 어느 쪽을 따를지 팀장 확인
- 10.13 회의의 시작 시네마틱 10~20초(D-038)와 v3 오프닝 20초는 같은 것으로 봄

**완료 체크리스트**

1. 육조거리 시작부터 엔딩까지 씬 전환 1번(안개문)으로 이어진다
2. 5분 ± 30초 안에 3회 연속 끝낸다
3. 육조거리에서 받아치기를 반드시 한 번 본다
4. 광화문 앞에서 증기 100(붉은 증기)을 한 번 본다
5. 현무 가갑은 증기발도로만 부서진다
6. 합동기를 시간 역행으로 넘길 수 있고, 증기가 모자라면 보충된다
7. 사망해도 흐름이 끊기지 않는다
8. 길에서 벗어나거나 되돌아갈 수 없다
9. 시연자 키 4개가 모두 작동한다
