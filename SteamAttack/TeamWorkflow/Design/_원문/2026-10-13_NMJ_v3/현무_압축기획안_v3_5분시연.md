## 1. 길 — Main 맵 위의 동선

Main 맵에 이미 있는 배치(좌표는 씬 기준)를 그대로 쓰고, 남쪽에서 북쪽으로 **한 방향으로만** 올라간다.

```
 북 ↑
 [건청궁 (0, 137)] ······ 오프닝 컷씬만 (플레이하지 않음)
        :
 [향원정 (0, 104)] ─ 안개문 → 보스 아레나 씬 로드      ④
        │
 [근정전 마당 (0, 35~56)] ─ 얼어붙은 품계석 사이, 잡몹 소규모   ③-2
        │
 [광화문 (0, -40)] ─ 얼음 문 → 깨지면 궁 안으로
 [해태 앞 (0, -58)] ─ 포졸 무리 (중간보스 보류)                ③
        │
 [육조거리 (0, -60 ~ -111)] ─ 관아 사이 큰길, 잡몹 + 첫 받아치기 ②
 [시작 (0, -111)] ─ 버려진 수레 옆
 남 ↓
```

| 구간 | Main 맵의 실제 위치 | 길이 | 활용하는 기존 오브젝트 |
| --- | --- | --- | --- |
| ① 오프닝 | 건청궁 (0, 137), 시점 표식 `시점_어명의 순간` | 컷씬 | 조선 최초의 전등, 물불 발전기, `어명의 순간` 인물 |
| ② 육조거리 | z −111 → −60, 폭 약 40m | 약 50m | 6조 관아, 버려진 수레, 괘서, 얼어붙은 백성 |
| ③ 광화문 앞 | 해태 사이 (0, −58), 시점 `시점_광화문과 백동수` | 반경 15m | 광화문, 해태 2기 (씬의 `백검 백동수` 인물 배치는 보류 동안 숨김) |
| ③-2 궁 안 | 광화문 (0, −40) → 근정전 마당 → 향원정 | 약 140m | 어도(御道), 근정전, 품계석, 동·서행각 |
| ④ 향원정 | 연못 앞 (0, 약 85) | — | 향원정, 연못 물안개 → **안개문 트리거** |
- **뒤로 못 가게:** 시작 지점 남쪽은 쓰러진 수레와 얼음벽으로 막는다. 광화문은 얼음으로 닫아 두고, 광화문 앞 포졸 무리를 모두 쓰러뜨리면 얼음이 깨지며 문이 열린다.
- **운종가·삼청동 기기창·흑수회 제단**은 배경으로만 둔다(길에서 멀리 보이게).
- **보이지 않는 벽:** 육조거리 관아 사이, 궁 안 행각 바깥을 투명 콜라이더로 막아 길에서 벗어나지 않게 한다.
- 이동 거리는 시작부터 안개문까지 약 250m다. 달리면 40초 안쪽이라 시연 시간 대부분이 전투에 쓰인다.

## 2. 5분 흐름표

| 시간 | 구간 | 일어나는 일 | 보여줄 것 |
| --- | --- | --- | --- |
| 0:00~0:20 | ① 오프닝 | 전등 점화 → 발전기 폭주 → 멈춘 눈송이 → 고종의 어명 → 육조거리로 화면 전환 | 세계관 한 번에 |
| 0:20~1:20 | ② 육조거리 | 근접 2 → 원거리 1 → 근접 1(받아치기 가능한 내려치기). 첫 동심원에 슬로우 + “CTRL” 안내 | 근접 액션, **첫 받아치기**, 화승총 사격 |
| 1:20~2:20 | ③ 광화문 앞 | 얼음 문 앞 포졸 무리(근접 3 + 원거리 1). 받아치기 → 약점 노출 → 3배 피해를 반복해 익힘. 마지막 한 명이 쓰러지면 얼음이 깨지고 “한 호흡에, 한 점에” 자막 | 받아치기 → 약점 노출, 증기 100 체감 |
| 2:20~2:40 | ③-2 궁 안 | 광화문을 지나 근정전 마당 → 향원정으로 달림. 근접 2마리(선택) | 멈춘 경복궁 풍경, 이동 |
| 2:40~4:40 | ④ 현무 | 안개문 → 아레나 로드 → 1페이즈(가갑 2장) → 2페이즈 합동기 1회 → 신핵 QTE | 증기발도, **시간 역행**, 보스전 |
| 4:40~5:00 | 엔딩 | 해빙, 눈이 다시 떨어짐, 로고 | 클라이맥스 |
- **시간 역행을 처음 쓰는 곳은 현무 합동기다.** 합동기 직전 “피할 수 없다 — 되감아라 (Q)” 안내로 한 번에 배우게 한다. 그 전에 광화문 앞에서 체력이 절반 아래로 떨어지면 화면 가장자리에 “Q”를 한 번 띄워 미리 보여준다.
- 회복약이 없으므로 **체력을 되찾는 방법은 시간 역행 하나뿐**이다. 광화문 앞 전투가 “맞으면 되감는다”를 미리 느끼는 자리가 된다.

## 3. 시스템

### 3-1. 조작

| 키 | 동작 |
| --- | --- |
| WASD / SHIFT | 이동 / 전력질주 |
| SPACE | 구르기 (0.9초, 무적 0.5초) |
| 좌클릭 / 우클릭 | 환도: 약공격 / 강공격 · 화승총: 발사 / 조준(홀드) |
| TAB | 환도 ↔︎ 화승총 (사격용 장착 전환) |
| C | 발도·납도 |
| **CTRL** | **화승총 받아치기** — 어떤 무기를 들고 있든 등의 화승총을 돌려 근거리에서 격발 |
| Z | 증기발도 (증기 100) |
| Q | 시간 역행 |
| F | 상호작용, 신핵 QTE 시작 |
| T / 휠클릭 | 락온 |

### 3-2. 핵심 수치

| 시스템 | 값 |
| --- | --- |
| 플레이어 | 체력 100, 공격력 10, 강공격 ×2 |
| 화승총 사격 | 우클릭 조준 → 좌클릭 발사. 히트스캔 25m, 피해 = 강공격, 증기 −10 |
| 화승총 받아치기 | CTRL. 동심원 겹침 ±0.15초(**시연 ±0.2초**), 증기 −10. 성공 시 공격 무효 + 적 자세 붕괴 + **약점 노출 3초**(다음 1회 ×3) + 증기 +20. 쿨 2초 |
| 증기 | 최대 100. 약공격 적중 +5, 강공격 적중 +10, 받아치기 성공 +20 / 화승총(사격·받아치기) −10, 시간 역행 −70, 증기발도 −100. 100이면 등에서 붉은 증기 |
| 증기발도 | Z, 증기 100 전량. 전방 4.5m·180°, 약공격 ×6. **현무 가갑을 부수는 유일한 수단** |
| 시간 역행 | Q, 5초 전으로, 증기 −70. 위치·방향·체력만 되돌리고 **증기는 되돌리지 않음**. 연출 0.8초 동안 무적 |
- **배율 규칙:** 약점 노출 3배는 다음 공격 1회에만, 공격 종류와 상관없이 기본 피해에 곱한다. 다른 배율과는 곱하지 않는다.
- **받아치기와 사격이 같은 증기를 쓴다.** 증기가 10 미만이면 둘 다 쓸 수 없다.

### 3-3. 이번 시연에서 뺀 것

- 강화, 체크포인트(장승), 석탄 두더지, 수류탄, 인벤토리 UI, 사망 화면 팁
- **권총(빨리뽑기)** — 받아치기는 화승총이 맡는다
- **회복약** — 체력은 시간 역행으로만 되돌린다

### 3-4. 죽으면

5분 시연이라 죽어도 흐름이 끊기지 않게 처리한다.

| 상황 | 처리 |
| --- | --- |
| 길(②, ③, ③-2)에서 사망 | 0.5초 먹물 전환 후 **그 자리에서** 체력 50%로 일어남. 적은 그대로 |
| 현무전에서 사망 | 먹물 전환 후 **보스전 시작 상태**로 다시. 체력 100, 증기 0 |
| 현무에게 2번 사망 | 현무 체력 30% 깎고 시작 (시연 완주용) |
- 저장 지점 오브젝트는 없다. 보스 입장 순간의 상태만 코드에서 기억한다.

### 4-2. 광화문 앞 — 얼음 문 (중간보스 보류)

| 항목 | 내용 |
| --- | --- |
| 구성 | 포졸 3 + 궁수 1이 얼음으로 봉해진 광화문을 등지고 선다 |
| 역할 | 받아치기 → 약점 노출 → 3배 피해를 여러 번 반복해 손에 익히는 자리. 증기를 100까지 채워 붉은 증기를 처음 보게 한다 |
| 끝 | 마지막 한 명이 쓰러지면 얼음 문이 깨지고 “한 호흡에, 한 점에” 자막 (증기발도의 원리 예고) |
| 보류 해제 시 | 이 구간을 중간보스 1분 결투로 바꾼다. 동선, 얼음 문, 자막 위치는 그대로 쓴다 |

| 페이즈 | 목표 | 패턴 |

| 전환 | 2초 | 뱀의 목이 솟음 |

- 높이 있는 뱀 머리는 화승총 사격으로도 맞힐 수 있다.

## 7. 완료 체크리스트

1. 육조거리 시작부터 엔딩까지 씬 전환 1번(안개문)으로 이어진다.
2. 시연자가 5분 ± 30초 안에 3회 연속 끝낸다.
3. 육조거리에서 받아치기를 반드시 한 번 본다.
4. 광화문 앞에서 증기가 100까지 차는 것(붉은 증기)을 한 번 본다.
5. 현무 가갑은 증기발도로만 부서진다.
6. 합동기를 시간 역행으로 넘길 수 있고, 증기가 모자라면 보충된다.
7. 사망해도 흐름이 끊기지 않는다 (길: 제자리, 보스: 보스전 처음).
8. 길에서 벗어나거나 되돌아갈 수 없다.
9. 시연자 키 4개가 모두 작동한다.
