# 2. 세계관 및 스토리

## 2.1 시대와 사건

- 배경은 고종 시대, 서양 문물을 받아들이며 근대화하던 시기에 스팀펑크 문명이 발달한 조선이다.
- 1887년 정월, 경복궁 건청궁에 조선 최초의 전등이 켜지던 밤 사건이 일어난다. 향원정 물을 끌어 돌리던 증기 발전기(백성들이 "물불"이라 부르던 기계)가 과부하로 폭주한다.
- 폭주한 발전기가 땅속 신맥(神脈)을 뚫고, 그 아래 잠들어 있던 북방의 고대 메카닉 신수 **현무**를 깨운다.
- 현무는 열기, 증기, 흐르는 시간을 삼켜 한양 도성이 얼어붙고, 눈송이가 허공에 멈추고, 시간이 앞뒤로 튀는 구역이 생기고, 보일러가 멈추며, 병사와 백성이 기계 괴수로 변한다.

## 2.2 민심 (환경 연출 요소)

개항과 외세의 압박으로 불안하던 백성들이 "궁궐이 서양 귀신불(전등)을 켜서 하늘이 노했다"고 믿기 시작한다. 환경에서는 불타는 초가, 텅 빈 시전, 괘서, 기도하는 백성, 사재기, 폭등한 쌀과 땔감으로 보여준다.

## 2.3 주요 세력과 인물

| 대상 | 설정 |
| --- | --- |
| 주인공 | 친군영 비밀 무사. 건청궁 지하 발전 기관실에서 고종에게 장비를 받고 현무 토벌 어명을 받는다. |
| 고종 | 시작점에서 어명을 내리는 인물. 상징색은 황(黃). |
| 흑수회(黑水會) | 현무를 북방의 수호신으로 숭배하는 사교 집단. 도성을 얼려 새 세상을 열려 하며, 백성을 선동하고 일부 변이 괴수를 조종한다. 상징색은 흑(黑). |
| 백동수 | 중간보스. 실존 인물과 무관한 가상 인물. 도성 최고의 검객이자 주인공의 옛 스승으로, 민심 붕괴에 절망해 흑수회에 넘어간다. 상징색은 백(白). 자세한 전투 설정은 9장. 쓰러뜨리면 고압 참격이 해금된다(개발팀 초안). |
| 현무 | 최종보스. 흑철 가갑을 두른 거대한 거북 몸체에 뱀의 목, 내부 기어, 신핵을 가진 고대 메카닉 신수. 상징색은 흑(黑). |

## 2.3-1 10/7 회의에서 추가된 세계관 설정

- 청룡의 힘은 시간이다.
- 현무가 청룡의 힘을 흡수하며 폭주한다.
- 주인공은 청룡 측이다.

> 회의 메모의 "청료의 힘"은 청룡의 오타로 보고 반영했습니다. 기존 설정(현무가 시간을 삼킴, 주인공의 시간 역행 장비)과 어떻게 이어 붙일지는 14장에 적어 두었습니다.
> 

## 2.4 현무와 시간의 개연성 (설정 근거)

현무가 시간을 다루는 존재인 이유를 정리한 설정 근거 문서다. 청룡을 시간의 "시작"을 알리는 정적인 기호로 보고, 현무는 시간이라는 강물 자체를 품고 관리하는 관조자로 본다.

| 관점 | 시간과의 연결 |
| --- | --- |
| 거북과 뱀 | 거북은 쌓이는 시간의 기록자, 뱀은 허물을 벗는 순환과 흐름. 두 몸이 얽힌 형상이 과거(기록)와 흐르는 시간의 결합 |
| 오행의 수(水) | 되돌릴 수 없이 흐르는 물처럼, 물을 다스리는 현무는 시간의 흐름을 조율하는 주체 |
| 겨울과 북쪽 | 한 해가 마감되는 시간의 끝자락이자 저장과 휴식의 단계. 지나간 시간을 거둬 봉인하고 보존하는 관리자 |
| 현(玄) | 아득하고 깊다는 뜻. 태초부터 영원까지의 시간을 다루는 신수 |

**기획 아이디어**

- **시간의 기록자(Chronicle)**: 등껍질에 과거를 저장하고, 뱀의 눈으로 시간의 틈새나 미래를 감시
- **시간의 조율자(Flow Control)**: 시간의 속도를 늦추거나(거북) 빠르게 넘기는(뱀의 허물벗기) 능력
- **역사의 파수꾼(Guardian)**: 인과율을 흔드는 자를 겨울 서리로 동결시키는 수호자

# 3. 기본 조작

## 3.1 기본 규칙

- 조준, 공격, 락온을 제외한 주요 전투 기능은 가능한 한 **왼손으로 조작**할 수 있게 배치한다.
- 입력 방식은 기능별로 누르기 또는 홀드 중 하나로 명확히 정한다.
- 디버그 전용 입력은 사용법을 숨겨 둔다. 예: ALT+숫자
- 8방향 이동, 대각선 이동도 직선과 같은 속도를 유지한다.
- **스태미나 시스템은 사용하지 않는다.**

## 3.3 이동 상태

| 상태 | 이동 방식 |
| --- | --- |
| 납도 | WASD 조합으로 자유로운 8방향 이동 |
| 발도 | 기본 8방향 이동, 후방 입력 시 뒷걸음질 |
| 락온 | 자동 발도. 락온 대상을 바라본 채 전후좌우 이동 |
| 전력질주 | 상태와 관계없이 전방향 동일한 달리기 모션 사용 (방향별 달리기 애니메이션은 만들지 않음) |

이동 방식은 전투 여부가 아니라 **발도/납도 상태와 락온 여부**로 바뀐다.

## 3.4 발도 / 납도

- C로 발도와 납도를 전환한다.
- 납도 상태에서 공격을 입력하면 자동으로 발도한 뒤 공격한다.
- 락온하면 자동으로 발도하고, 납도하면 락온이 자동으로 해제된다.
- 일정 시간 후 자동 납도하는 기능은 쓰지 않는다. 플레이어가 직접 C로 납도한다.

## 3.5 회피 (초기 테스트값, 플레이테스트로 조정)

| 항목 | 값 |
| --- | --- |
| 구르기 애니메이션 | 0.9초 |
| 무적 시간 | 0.5초 |
| 스태미나 소비 | 없음 |

구르기가 끝나기 전에는 연속으로 다시 구를 수 없다.

## 3.6 무기 변경

현재 무기를 수납하고 선택한 무기를 장착한다. 납도 상태에서 무기를 바꾸면 선택만 바뀌고 발도하지 않는다.

## 3.7 락온

- 락온 가능 거리는 초기값 10m, 15m 이상 벗어나면 자동 해제. 실제 플레이로 조절한다.
- 락온 중에는 적을 바라본 채 이동하고, 좌우나 대각선 이동은 적을 중심으로 횡이동, 후방 이동은 적을 보며 후퇴한다.
- 대상 전환 기능은 넣지 않는다.
- 대상이 사망하면 락온이 해제되고, 일정 범위 안에 적이 있으면 자동으로 다음 대상에 락온된다.

## 3.8 상호작용

상호작용은 가능한 F키로 통일하고, 대상에 접근하면 입력 안내 UI를 표시한다.

# 4. 전투 시스템

## 4.1 기본 전투

플레이어는 환도로 약공격과 강공격을 하고, 회피와 패링으로 적과 싸운다. 일부 적의 강공격에는 카운터(패링)가 가능하다.

## 4.2 패링 = 카운터 = 빨리뽑기

적의 패링 가능한 강공격에 맞춰 **좌측 허리의 권총(리볼버)을 빠르게 뽑아 사격해 공격을 저지**하는 시스템이다. 패링, 카운터, 빨리뽑기 세 용어를 모두 쓸 수 있다.

| 항목 | 내용 |
| --- | --- |
| 발동 대상 | 적의 패링 가능한 강공격 |
| 예고 표시 | 적 또는 공격 지점에 동심원 2개가 나타나고 바깥 원이 중심 원을 향해 수축 |
| 입력 | 패링 버튼 (CTRL) |
| 판정 시간 | 약 0.3초에서 0.5초부터 테스트. 원이 겹치는 순간을 0초로 보고 앞뒤 0.1초 여유를 두며, 0.3초 구간이 Perfect 타이밍 |
| 소모 | 증기 10. 성공 여부와 관계없이 입력하는 순간 소모, 증기가 10 미만이면 사용 불가 |
| 쿨타임 | 초기값 2초 (패링 애니메이션에 맞춰 이후 확정) |
| 성공 | 공격 무효, 적 경직과 패링 모션, 약점 노출 상태 전환, 증기 획득, SFX와 VFX |
| 실패 | 적의 강공격이 그대로 진행, 약점 노출 없음 (입력이 너무 빠르거나 늦은 경우 포함) |
| 피드백 | 원이 겹치는 순간 발광 + SFX와 VFX |
| 일반 공격 | 패링 표시 없음, 회피 등 일반적인 방법으로 대응 |
- 패링은 환도, 화승총 어느 쪽을 들고 있든 사용할 수 있고, 입력하면 좌측 허리의 패링용 권총을 즉시 뽑아 쏜다. 이 권총은 일반 원거리 무기와 구분되는 **패링 전용 장비**다.
- **약점 노출 상태**는 초기값 3초에서 5초이며, 이 동안 플레이어의 **다음 공격 1회가 3배 피해**를 주고 적중 후 종료된다.

## 4.3 피격 / 경직

플레이어와 몬스터 모두에게 **일반 경직**과 **HEAVY 경직** 두 가지 상태를 둔다. 피격 종류는 실제 데미지 수치와 별도로 설정하며, 강피격은 데미지가 아니라 **패링 가능한 공격과 보스 궁극기**로 구분한다.

| 구분 | 일반 피격 | 강한 공격 피격 |
| --- | --- | --- |
| HP | 감소 | 감소 |
| 경직 | 약 0.1초의 짧은 경직 | 일반 피격보다 긴 행동 불가 |
| 연출 | 큰 피격 애니메이션 없이 VFX와 SFX로 전달 | 전용 피격 애니메이션, 필요 시 넉백 또는 다운 |

0.1초 동안 현재 행동을 끊을지, 경직 시간, 연속 피격 보호 시간은 프로토타입 플레이테스트 후 조정한다.

# 5. 증기 시스템

플레이어의 핵심 자원. 증기통(등)과 HUD 게이지로 표시한다.

- 최대 증기는 **100으로 고정**하며, 최대치를 늘리는 강화는 쓰지 않는다.
- 증기가 100에 도달하면 캐릭터의 증기통에서 **붉은 증기**가 나와 HUD를 보지 않고도 최대 압력 상태를 알 수 있다.
- 강화는 최대치가 아니라 **패링 성공 시 획득량**을 늘린다.
- 사망하고 재시작하면 증기 게이지는 0으로 초기화된다.

| 구분 | 행동 | 증기 변화 |
| --- | --- | --- |
| 획득 | 약공격 적중 | +5 |
| 획득 | 강공격 적중 | +10 |
| 획득 | 패링 성공 | +20 (강화 1단계 +30, 2단계 +40) |
| 소비 | 패링 시도 | -10 (성공 여부와 무관) |
| 소비 | 화승총 발사 | -10 |
| 소비 | 수류탄(다이너마이트) | -30 (초기 테스트값) |
| 소비 | 시간 역행 | -70 (테스트값) |
| 소비 | 근거리 특수공격 (증기발도) | 미정 |

전투 페이지에는 증기가 일정 수준 이상 쌓이면 스팀팩과 무기가 붉게 변해 **과열** 상태를 시각적으로 알리고, 쌓인 증기를 강력한 공격에 쓴다는 설명이 있다. 과열의 구체적인 수치와 효과는 아직 정해지지 않았다.

# 6. 시간 역행

## 6.1 기본 동작

- 최근 **3초** 동안 플레이어 상태를 일정 간격으로 기록하고, 3초가 지난 기록은 순차적으로 삭제한다.
- 기록 대상: 위치와 바라보는 방향, 체력, 증기 게이지, 애니메이션 상태와 진행 지점, 납도/발도 상태, 장착 무기, 진행 중인 행동
- 입력 시 연출을 실행한 뒤 **3초 전 상태로 복귀**한다. 기록이 3초 미만이면 가장 오래된 시점으로 돌아간다.
- 연출 중에는 플레이어가 **무적**이며 조작할 수 없다.
- 비용은 우선 증기 70 소모로 두고, 플레이하며 논의한다. 쿨타임과 사용 횟수 제한은 미정이다.

## 6.2 시각 효과

- 평소에는 플레이어가 이동한 자리에 가늘고 반투명한 **검은 먹선**이 남았다가 서서히 사라진다.
- 발동하면 최근 3초의 궤적이 짙은 먹색으로 드러나고, 먹선이 현재 위치에서 과거 위치로 빨려 들어간 뒤 플레이어가 그 위치에 나타난다.
- 현재 위치 → 먹물이 역방향으로 번짐 → 먹선이 3초 전 위치로 빨려감 → 플레이어 출현

# 7. 무기

## 7.1 구성

| 슬롯 | 무기 | 역할 |
| --- | --- | --- |
| 근거리 | 환도 (주무기) | 약공격, 강공격(약공격의 2배 피해), 특수기 증기발도 |
| 원거리 (보조 슬롯) | 화승총 또는 수류탄(다이너마이트) | 장승에서 사용할 보조무기를 선택 |
| 패링 전용 | 권총(리볼버) | 좌측 허리에 항상 장착, 패링 때만 사용 |

두 가지 무기를 장착하고 TAB으로 변경하며, 우측 하단 UI에서 현재 무기를 강조한다.

## 7.2 원거리 무기

- 총알은 구현하지 않고 **히트스캔**으로 처리한다.
- 별도 탄약 없이 스팀팩의 증기를 소모한다.
- 화승총은 스팀팩에 쌓인 증기 압력으로 "증기탄"을 쏘는 설정이다. 설정상 증기탄이 맞는지는 추후 검토 중이다.
- 화승총 피해에도 공격력 강화가 함께 적용된다.
- 패링용 권총은 뽑은 뒤 다시 수납한다.

| 항목 | 화승총 | 수류탄(다이너마이트) |
| --- | --- | --- |
| 역할 | 정밀 원거리 공격 | 광역 공격 |
| 증기 소모 | 10 | 30 (초기 테스트값) |
| 피해 | 근거리 강공격과 동일 | 화승총의 1.5배 |
| 범위 | 단일 대상 | 범위 피해 (상세 수치는 넣어 보고 결정) |
| 경직 | 일반 경직 | 강한 경직(Heavy) |
| 조작 | 우클릭 조준, 조준 중 좌클릭 발사 | 투척 후 충돌 시 폭발, 궤적과 폭발 범위를 간략히 표시 |
| 강점 | 안전한 거리, 정밀성, 약점 공략 | 다수의 적 처리 |
| 약점 | 단일 공격, 증기 소비 | 발동 지연, 정밀 공격 어려움 |

## 7.3 조준 시 딤드 처리

조준 영역 바깥을 반투명 검정으로 덮는다. 설계 기준은 **조준 중에도 보스의 공격 예고 동작이 주변 시야에서 보여야 한다**는 것(패링 판단에 필요)이다. 조준은 홀드로 구현한다.

| 항목 | 설정값 |
| --- | --- |
| 모양 | 원형 (조준경이 없는 무기라 스코프형보다 자연스러움) |
| 크기 | 화면 세로 높이 기준 지름 45% |
| 경계 | 반경의 25–30% 구간을 그라데이션으로 부드럽게 |
| 페이드 인 / 아웃 | 0.12–0.15초 / 0.08–0.1초 |
| HUD | 딤드 위에 표시 (어두워지지 않음) |
| 알파값 | 개발 중 0.5로 설정하고, 중간 플레이테스트(10/8)에서 최종 결정 |

**구현 가이드**

- 가운데가 투명하고 바깥으로 갈수록 검어지는 원형 그라데이션 텍스처를 전체 화면 UI Image로 깔고 알파만 애니메이션한다. URP 기본 비네트는 화면 모서리 기준이라 이 용도에 맞지 않는다.
- 딤드 Canvas의 정렬 순서는 HUD보다 아래에 둔다.
- 페이드는 unscaledDeltaTime으로 처리해 히트스탑이나 슬로우 연출 중에도 멈추지 않게 한다.
- 추가 검토(범위 미확정): 조준 시 시야각 축소(예: 60에서 50), 마우스 감도 소폭 감소
- 레퍼런스는 워프레임 메사. 구현해 보고 어색하면 일반 게임식 조준선으로 바꾼다.

# 8. 플레이어

## 8.1 스탯과 강화

- 기본 HP 100, 증기 최대 100, 기본 공격력 10으로 시작한다.
- 공격력 강화는 몬스터의 TTK(처치까지의 타수) 감소가 체감되도록 5 단위로 올린다.
- 상세 스탯은 게임 안에 직접 표시하지 않고 데이터 테이블로 관리하며, 디버그 UI에서는 확인할 수 있게 한다.

| 강화 Level | 체력 | 공격력 | 패링 증기 회복량 | 강화 필요량 (특별한 석탄) |
| --- | --- | --- | --- | --- |
| 1 | 100 | 10 | 20 | - |
| 2 | 115 | 15 | 30 | 1 |
| 3 | 130 | 20 | 40 | 2 |

## 8.2 회복약

- 사용 시 **최대 HP의 50% 회복**하며, 최대 HP를 넘겨 회복하지 않는다.
- 초기 최대 소지 개수는 2개이고, 강화로 늘릴 수 있다.
- 회복 중에는 이동속도가 감소하고(초기값 90%), 피격되면 회복이 취소된다.
- 체크포인트에서 휴식하면 최대 소지량까지 보충된다.
- 패링 성공 시 HP 회복은 일단 보류한다.

## 8.3 캐릭터 디자인

조선 후기 무사의 복식에 증기기관, 금속 장갑, 배관 등 스팀펑크 기계 장비를 결합한 전투원. 전통적인 무사 실루엣은 유지한다.

| 위치 | 장비 | 설명 |
| --- | --- | --- |
| 등 | 증기통 | 핵심 자원 저장 장치. 크게 배치하고, 최대치에서 붉은 증기를 배출 |
| 허리 또는 등 | 환도 | 비전투 시 칼집에 수납, 사용 시 뽑음 |
| 등 | 화승총 | 비사용 시 등에 장착 |
| 좌측 허리 | 권총(리볼버) | 패링 전용. 빨리 뽑는 동작이 보이도록 항상 장착 |

무기 위치가 겹치지 않는지, 장착과 해제 애니메이션이 자연스러운지는 담당자가 확인해 수정한다.

# 9. 적과 보스

## 9.1 몬스터 공통 전투 규칙

모든 전투형 몬스터는 다음 세 가지 모션을 필수로 만든다.

1. **일반 공격**: 기본 공격. 패링 불가, 회피 등으로 대응
2. **패링 가능한 강공격**: 일반 공격보다 위력이 높고, 공격 전 패링 가능 여부를 알리는 전용 시각 효과를 출력. 빨리뽑기로 저지 가능
3. **패링 당함**: 성공 시 현재 강공격을 중단하고 전용 피격(자세 붕괴) 모션을 재생한 뒤 약점 노출 상태로 전환

## 9.2 몬스터 기본 방향과 제작 목록

- 몬스터는 사람 형태를 기본으로 하고, 플레이어에게 달려드는 패턴부터 시작한다. 수와 이후 패턴은 협의한다.
- 10/7 회의에서 정한 제작 목록은 근접 1종, 원거리 1종, 크리처 1종이다.

## 9.3 일반 몬스터: 석탄 두더지

증기기관의 연료인 석탄을 채집하고 운반하는 두더지. 등에 몸집만 한 대형 석탄통을 짊어졌고, 플레이어를 발견하면 땅속으로 숨어 빠르게 접근한 뒤 튀어나와 공격한다.

- **설계 의도**: 원거리 조준과 약점 공격을 유도하고, 지형에 따라 행동이 제한되는 적으로 전투 공간을 활용하게 한다.
- 근접으로도 상대할 수 있지만, 지형으로 움직임을 막거나 원거리로 등의 석탄통을 터뜨리면 현재 체력과 관계없이 **한 방에 처치**된다.

| 패턴 | 내용 |
| --- | --- |
| 대기 | 지상에서 경계, 석탄 채집과 운반. 인식 범위가 다른 몬스터보다 넓고, 플레이어가 들어오면 전투 상태로 전환 |
| 땅굴 이동 | 지하에서 지상보다 빠르게 접근. 흙먼지, 이동 궤적, 노출된 석탄통으로 위치를 알림. 흙 지형에서만 가능하고 돌바닥에서는 지상으로 나와야 함 |
| 굴착 기습 | 땅굴에서 튀어나오며 공격 (카운터 성공 시 석탄통 파괴 여부는 검토 중) |
| 앞발 할퀴기 | 지상에서 가까운 플레이어를 발톱으로 공격 |
| 돌진 | 거리가 벌어지면 짧게 돌진 |
| 이동 | 지상에서는 걷기. 플레이어보다 느리게 |

외형은 석탄통을 원거리에서도 위험하다고 알아볼 수 있게 크게 디자인하고, 땅속 이동 중에도 등과 석탄통 일부가 지면 위로 드러나게 한다. 석탄통이 위험하다는 것을 미리 인식시키기 위해 석탄통을 터뜨리는 이벤트를 한 번 먼저 진행한다(원본 메모).

## 9.4 몬스터 스탯

| 몬스터 | 기본 HP | 기본 공격 기준 TTK | 역할 |  |
| --- | --- | --- | --- | --- |
| 근접 잡몹 | 50 | 5회 | 가장 표준적인 기준 몬스터 |  |
| 원거리 잡몹 | 40 | 4회 | 접근하면 빠르게 처치 가능 |  |
| 스팀펑크 두더지 | 100 | 10회 | 높은 체력, 약점 공략 유도 |  |
| 중간보스 백동수 | 300 | 30회 | 패링 후 약점 노출 공략 유도 |  |

| 몬스터 (HP) | 공격력 10 | 공격력 15 | 공격력 20 |
| --- | --- | --- | --- |
| 원거리 (40) | 4회 | 3회 | 2회 |
| 근접 (50) | 5회 | 4회 | 3회 |
| 두더지 (100) | 10회 | 7회 | 5회 |

"HP는 5의 배수"는 절대 규칙이 아니며, 공격력 강화 시 주요 적의 필요 타수가 실제로 줄도록 조정한다. 빌드 후 실제 TTK를 보고 다시 맞춘다.

## 9.5 중간보스: 백동수

- **모티브**: 세키로의 갑옷무사. 플레이트 아머로 일반 공격이 통하지 않는 기믹형 보스. 원본 메모는 참고 이미지의 갑옷무사를 아무리 공격해도 피해를 줄 수 없어 낙사시켜야 하는 보스로 설명한다.
- **컨셉**: 강력한 방어력을 가진, 패링을 써야 하는 보스. 다만 그냥 때려잡는 것도 불가능하지는 않게 한다. 플레이어 공격력이 10일 때 HP는 약 300, 패링 성공 후 3배 피해를 넣으면 된다.
- 튜토리얼 보스처럼 "이 게임은 패링(카운터)을 요구한다"는 것을 인식시키는 역할도 한다.
- 설정상 옛 스승이었던 흑수회 검객이다. 초기 구상은 서리 검기, 초고속 발도술, 짧은 되감기, 후반 흑화 강화 패턴이었다. (패턴은 16장의 초안 항목 참고)
- 쓰러지면 제정신을 되찾고 흑수회의 정체와 현무의 약점을 알려준다.
- (개발팀 초안) 동시에 고압 참격이 해금되며, 플레이어가 배워야 하는 것은 패링, 회피, 되감기, 공격 타이밍, 보스의 되감기 대응이다.

## 9.6 최종보스: 현무

- 고대 메카닉 신수. 흑철 가갑, 거대한 거북 몸체, 뱀의 목, 내부 기어, 신핵을 가졌다.
- 구상 단계: **Phase 1 흑철의 가갑**(둔탁한 찍기, 패링 유도, 시간 역류로 가갑 복원 시도)과 **Phase 2 쌍두의 폭주**(뱀의 고속 찌르기, 거북의 광역 냉기 브레스, 합동기). 합동기는 즉사급으로 설계해 시간 역행(초안은 5초 되감기)으로 피하게 한다.
- 기획 페이지의 "보스 크리처 현무를 구현할지" 항목은 아직 체크되지 않았다.

## 9.7 보스 배치 / 진행 구조

- 잡몹을 처치하고 퀘스트를 수행해 중간보스를 잡는 **던전 형태**로 만들고, 플레이어가 찾아가는 방식으로 구상한다. 보스 맵은 따로 만든다 (초안, 회의로 줄여 나감).
- 흐름: 궁궐 밖으로 나가 중간보스 격파 → 궁궐로 돌아와 최종보스 격파
- 중간보스와 최종보스는 입장 시 짧은 컷신으로 대화하는 방식을 검토한다.

# 10. 맵과 진행

## 10.1 맵 구상

참고 이미지와 같은 형식으로 맵을 만들고, 각 요소에 세계관이 녹아들도록 디자인을 배치한다. 크기는 타협한다. (담당: 보스전 맵은 나민재)

## 10.2 체크포인트: 석탄대장군 / 증기여장군

조선 장승을 스팀펑크로 재해석한 체크포인트 오브젝트. 두 개가 한 세트로 길 양쪽에 서서 증기를 내뿜으며 자동 저장된다.

- 주변에서 휴식 기능이 활성화되고, 일정 범위 안에는 적을 배치하지 않으며 전투 중인 적도 들어오지 못한다.
- 소울라이크처럼 휴식하면 일반 몬스터가 부활하지만, 같은 구간을 반복 돌파시키는 구조가 아니라 **적절한 위치에 자동 저장 체크포인트**를 두어 흐름이 과도하게 끊기지 않게 한다.
- **보스룸 직전에는 반드시 체크포인트를 하나 설치**한다.
- **최초 활성화**(접근 시 자동): 부활 지점 등록, 진행 상황 저장, HP 완전 회복, 활성화 VFX와 SFX, 외형 변화로 활성 상태 표시. 일반 몬스터는 부활하지 않는다.
- **재사용(휴식)**: 상호작용하면 HP 회복, 일반 몬스터 부활. 전투 상태에서는 사용 불가.
- 체크포인트에서 할 수 있는 일: 휴식, 무기 변경, 강화

## 10.3 사망 및 재시작

- HP가 0이 되면 사망 연출 후 가장 최근에 활성화한 체크포인트에서 다시 생성된다.
- 재시작 시 플레이어는 HP 완전 회복, 증기 0, 상태이상 해제, 전투 상태 해제.
- 영구 강화, 진행 상황, 완료한 이벤트와 기믹은 유지되고 일반 몬스터는 부활한다.
- 사망 화면: 전체가 어둡게 물들고 사망 메시지와 팁을 표시한다. 팁은 시스템 설명과, 특정 몬스터에게 죽었을 때 그 몬스터에 대한 팁으로 구성한다. 참고: 디아블로4·검은사막 사망 화면, 스카이림 로딩 장면.

# 11. 아이템과 강화

복잡한 인벤토리나 장비 파밍 없이 진행에 필요한 최소한의 아이템만 구현한다.

| 종류 | 내용 |
| --- | --- |
| 퀘스트 아이템 | 스테이지 진행, 이벤트와 기믹 해제에 사용. 획득 시 자동 보관, 장비 기능 없음 |
| 강화 재료 | 플레이어 강화에 사용. 특정 적 처치나 필드 탐색으로 획득, 강화 시 소모 |
| 소모품 | 먼저 회복약만 구현 |

## 11.1 강화 시스템

- **특별한 석탄**이 강화 전용 재료다. 맵 탐색(샛길, 위험 구역)과 보스·주요 적 처치(보스는 **확정 드랍**)로 얻고, 일반 몬스터는 기본적으로 떨어뜨리지 않는다.
- 활성화된 석탄대장군 / 증기여장군에서 석탄을 소비해 원하는 항목을 직접 골라 강화한다.
- 강화 항목: 최대 HP 증가, 회복약 최대 소지 개수 증가, 증기 회복량(패링 성공 시) 증가, 공격력 강화
- 석탄 종류를 나눌지는 나중에 확정한다. 강화 단계별 수치는 8.1 표를 따른다.

# 12. UI와 아웃게임

## 12.1 인게임 UI

- 상단: 보스 이름과 체력 게이지
- 좌하단: 체력바와 증기 게이지바
- 우하단: 현재 장착 무기(강조), 그 왼쪽에 회복약 남은 개수
- 퀘스트: 목표가 바뀌면 잠깐 표시하고 J키로 다시 확인. 예: "어명을 받들라"가 나타났다가 3–5초 뒤 먹물 번지듯 사라진다.
- 패링 가능한 공격에는 전용 타이밍 UI(동심원)를 표시한다.

## 12.2 아웃게임

- **게임 실행**: 팀 이미지 화면 (미정)
- **메인 화면**: 새 게임, 불러오기, 환경 설정, 게임 종료 (슬롯 하나로 두고 게임 시작으로 고정하는 안도 가능)
- **환경 설정**: 마스터 음량, SFX, BGM, 감도, 화면 해상도, 전체화면
- **ESC 메뉴(일시정지)**: 계속하기, 조작법, 설정, 타이틀로(진행 상황을 저장하고 돌아갈지 확인), 게임 종료(저장하고 종료할지 확인)
- **클리어 화면**: 세계관에 맞는 한 줄 문구, 플레이 시간, 사망 횟수, 타이틀로 버튼
- 엔딩 크레딧, 타이틀 복귀
- **화면 전환**: 먹물이 번지며 화면을 덮었다가 다음 화면으로 넘어가는 연출. UI는 전반적으로 동양적인 이미지와 먹물 느낌으로 통일한다.

# 14. 충돌·확정 필요 항목

개별 페이지끼리, 또는 개별 페이지와 개발팀 기획서 사이에 서로 다르거나 비어 있는 곳입니다. 이 문서는 "본문 채택" 열의 값을 사용했고, 팀 확정이 필요합니다.

| 항목 | 내용 | 본문 채택 |
| --- | --- | --- |
| 시간 역행 길이와 비용 | 시간 역행, 기본 조작 페이지는 3초와 증기 70 소모. 개발팀 기획서 초안은 5초, 역시 게이지 2칸, 쿨타임 20초(데모 10초), 복원 대상은 위치, 체력, 과열 게이지 | 5초, 증기 70 |

| 패링 방식 | 개별 페이지는 권총 빨리뽑기(증기 10 소모, 약점 노출 3배 피해). 개발팀 초안은 화승총 패링으로 과열 게이지를 채우는 구조 | 빨리뽑기 |

| 백동수 설정 | 중간보스 페이지는 방어력 높은 갑옷무사형(HP 300, 패링 강제). 개발팀 초안은 서리 검기, 발도술, 짧은 되감기, 흑화 강화를 쓰는 검객 | 갑옷무사형 + 검객 설정 병합 검토 |
| 원거리 무기 구성 | 화승총 + 수류탄(장승에서 선택), 기획 페이지 협업 메모는 "원거리 활 한 개와 근거리 한 개", 회의 결정은 원거리 1 + 근거리 1 고정 | 화승총 또는 수류탄 중 1개 (활은 반영 안 됨) |
| 인벤토리 | 아이템 페이지는 복잡한 인벤토리를 쓰지 않는다고 했지만 기본 조작에는 I / B 인벤토리 키가 있음 | 최소 구현 |
| 락온 대상 변경 | 기본 조작 표에는 "대상 변경 방식 추후 확정", 본문에는 "대상 전환 기능은 넣지 않는다" | 전환 없음 |
| 크리처 몬스터 | 회의에서 근접 1, 원거리 1, 크리처 1로 정함. 개별 페이지에 구체적으로 있는 몬스터는 석탄 두더지뿐이고, 몬스터 페이지는 사람 형태를 기본으로 함 | 크리처는 석탄 두더지로 가정 |
| 세계관 연결 | 회의의 "청룡의 힘은 시간, 현무가 흡수해 폭주, 주인공은 청룡 측"과 기존 "현무가 시간을 삼킴, 주인공은 역류 혼천의로 시간 역행" 설정, 그리고 2.4의 "시간은 현무 고유의 속성, 청룡은 시간의 시작을 알리는 존재"라는 근거 문서를 하나로 이어야 함 | 양쪽 모두 기재 |
| 패링 판정 시간 수치 | 전투 페이지는 "원이 겹치는 순간을 0초로 두고 ±0.1초"라고 하면서 "0.3초가 Perfect 타이밍"이라고 적어 합이 맞지 않음(±0.1초면 0.2초 구간). 별도로 판정 시간은 0.3~0.5초부터 테스트한다고 함 | 테스트로 확정 (Perfect 구간 길이 정의 필요) |
| 시간 역행이 증기·체력까지 복원 | 시간 역행 페이지는 체력과 증기 게이지도 기록해 3초 전 상태로 되돌림. 그러면 역행에 쓴 증기 70과 그 사이 입은 피해가 함께 되돌아가 비용이 상쇄되고 사실상 회복 수단이 될 수 있음. 개발팀 초안은 과열로 소모한 체력은 되돌리지 않는다고 예외를 둠 | 기록 대상 그대로 기재 (복원 범위 확정 필요) |
| 시간 역행 중 무적 | 시간 역행 페이지는 연출 중 무적과 조작 불가. 개발팀 초안 체크리스트는 "되감기 입력 중 무적 여부"를 미확정으로 둠 | 무적 |
| 보스의 시간 되감기 | 개발팀 초안에는 "되감기는 플레이어만 되돌린다", "적과 보스는 되감기지 않음"이라는 원칙이 있지만, 백동수의 짧은 되감기와 현무의 시간 역류(가갑 복원)도 있음. 플레이어의 되감기가 적에게 영향을 주지 않는다는 뜻으로 해석됨 | 해석대로 기재 (확인 필요) |
| 증기 획득량 표기 | 증기 시스템 페이지는 약공격 +5, 강공격 +10. 스탯 수치 페이지는 "일반 공격 적중 +5"만 적고 강공격 값이 없음 | 약 +5, 강 +10 |
| 체크포인트 형태 | 기획 메인 협업 사항은 "체크포인트는 장비 제작하는 곳을 기본으로", 체크포인트 페이지는 석탄대장군 / 증기여장군(장승). 장승에서 강화와 보조무기 선택을 하는 것은 장비 제작 기능과 비슷함 | 장승 체크포인트 |
| 특수기 명칭 | 전투 시스템 페이지와 근거리 무기 페이지는 "증기발도", 기본 조작 페이지의 Z 키는 "특수기(과열 발도)". 내용, 소모량, 효과는 모두 비어 있음 | 같은 기술로 보고 미정 처리 |
| 화승총 탄 처리 | 원거리 무기 페이지는 총알 없이 히트스캔, 전투 시스템 페이지는 "증기탄을 발사"(설정상 맞는지 검토 중) | 히트스캔 + 증기 소모 |
| 두더지 명칭과 패링 모션 | 일반 몬스터 페이지는 "석탄 두더지", 스탯 페이지는 "스팀펑크 두더지". 몬스터 공통 규칙은 패링 가능한 강공격이 필수인데, 두더지의 패턴(굴착 기습, 앞발 할퀴기, 돌진) 중 어느 것이 패링 가능한 강공격인지 정해져 있지 않음 | 같은 몬스터로 처리 |
| 피해 배율 중첩 | 환도 강공격은 약공격의 2배, 약점 노출 중 다음 공격은 3배, 화승총은 강공격과 같고 수류탄은 화승총의 1.5배. 강공격이 약점 노출 상태에서 3배와 중첩되는지, 원거리 공격에도 3배가 적용되는지는 없음 | 미정 |
| 강화 재료 획득처 | 아이템 페이지는 "특정 적 처치 또는 필드 탐색", 강화 페이지 첫 문단은 "보스 및 주요 적 처치"이고 뒤에서는 "보스 확정 드랍, 일반 몬스터는 기본 비드랍" | 탐색 + 보스 확정 드랍 + 주요 적 |
| 수류탄 장착 위치 | 캐릭터 디자인 페이지는 환도, 화승총, 권총의 위치만 있고 수류탄(다이너마이트)의 장착 위치가 없음 | 미정 |
| 페이지 상단 정보 | 대부분의 기획서에서 담당자 칸이 비어 있음 | - |

# 15. 논의 중인 사항 (기획 페이지 메모)

- 프로토타입 빌드 후 현재 게임의 재미와 게임성 논의
- 증기 게이지를 어디에 소모할지: 강공격, 스팀발도(특수기), 원거리 공격, 시간 역행
- 시간 역행의 비용과 제한
- 무기를 몇 개나 더 추가할지: Mixamo와 Varco3D로 도끼, 펀치 추가는 가능. 현재 카메라에서 무기가 눈에 띄지 않아 장착 무기를 2개로 제한하는 안이 있음
- 맵: 스테이지 구성, 보스룸, 튜토리얼 맵 / 높이 구현(사다리, 계단, 엘리베이터, 언덕 등) / 기믹 맵(어둠 맵, 기름등, 증기로 문 열기 등 증기 활용처 확대)
- 보스 배치: 보스룸 구성, 근접과 원거리 태그를 따로 둘지 데미지만 다르게 할지, 입구 진입 방식(높이차를 이용한 되돌아가기 방지, 룸 처리, 일반 필드 배치), 등장 방식(컷신 또는 목표 지점에 배치)
- 재화와 인벤토리는 구현만 하는 수준으로, 스탯은 진행 상황에 따라 자동 증가하는 방식도 가능
- 피격: 일반 게임처럼 체력 구조를 바꾸고, 경직은 애니메이션 짧은 역재생으로, 큰 데미지에는 피격 애니메이션 재생
- 스팀펑크 배경이므로 탈것(증기기관차, 광화문 시계탑, 서울역 증기기관차, 비행선) 아이디어

# 16. 개발팀 기획서(초안)에만 있는 항목

개별 기획서에는 아직 반영되지 않은 내용입니다. 채택 여부는 팀 확정이 필요합니다.

- 펼쳐서 보기
    
    **전투**
    
    - 과열 모드: 공격이나 패링으로 스팀 팩 압력이 100%에 닿으면 발동. 공격력과 공격 속도 증가, 무기가 적색으로 달아오르며 대가로 체력이 지속 감소
    - 고압 참격: 과열 모드 전용 스킬. 현무의 흑철 가갑을 부술 수 있는 유일한 수단
    - 공중 띄우기, 공중 콤보
    
    **시간 역행 (5초 버전)**
    
    - 링 버퍼로 5초 × 60FPS = 300개 상태 저장, 1칸 소모, 최대 2칸, 쿨타임 20초(데모 10초), 20히트 연속 타격 또는 완벽 패링 시 회복 가속
    - 되감기 직후 1초간 "선견": 방금 맞은 적 공격의 궤적이 잔상으로 표시
    - 적과 보스는 되감기지 않음. 과열 모드로 소모한 체력은 되돌리지 않음
    
    **레벨 구조**
    
    - Act 1 (풀 버전 00:00–00:20): 흉흉한 저잣거리에서 멈춰 선 광화문까지 (전등 점화, 발전기 폭주, 어명, 운종가, 변이병, 백동수)
    - Act 2 (00:20–00:30): 삼청동 기기창과 증기 포대. 파괴된 증기 압축 연발 포대를 5초 되감기로 복구해 현무를 공격
    - Act 3 (00:30–00:55): 현무. Phase 1 흑철 가갑, Phase 2 쌍두의 폭주, 신핵 QTE
    - 엔딩 (00:55–01:00): 과열 대검으로 신핵 관통, 역류 혼천의 결합, 해빙
    
    **10분 데모 타임라인**
    
    - 00:00–02:00 오프닝과 잡몹 2마리, 02:00–04:00 기기창 포대, 04:00–09:00 현무 1, 2페이즈, 09:00–10:00 신핵 QTE와 엔딩
    - 데모에서는 패링 판정을 완화하고 되감기 쿨타임을 10초로 줄임
    
    **보스·레벨 추가 설정**
    
    - Act 2 결과: 복구한 포대가 현무에게 화염 폭격을 가하고, 현무가 향원정 연못 위로 추락
    - 엔딩 연출: 처형(과열 대검 → 신핵 관통 → 역류 혼천의 결합 → 역회전 → 폭발), 해빙(열기·시간 해방, 눈송이 낙하, 도성 해빙), 에필로그(백성들이 거리로 나옴, 떠오르는 해, 괘서가 바람에 찢김, 흑수회 잔당이 어둠으로 사라짐)
    - 보스 공략 의도: Phase 1 "패링해서 과열을 만들고 가갑을 깨야 한다", Phase 2 "위험한 순간을 되감아야 한다", 최종 "신핵을 파괴한다". 현무의 가갑은 고압 참격으로만 파괴할 수 있다.
    - 백동수의 사용 스킬은 서리 검기, 발도술, 짧은 되감기(자신의 공격 결과를 되돌림), 흑화 강화. 현무는 시간 역류로 파괴된 가갑 복원을 시도하고, 시전 중 집중 공격해 끊는다. 보스 FSM: 백동수(Idle, Approach, SwordAttack[FastSlash, FrostSlash, DrawSlash], Parry, ShortRewind, Enraged, Death), 현무(Phase1[HeavyStrike, ArmorAttack, TimeReversal, ArmorBreak], Phase2[SnakeThrust, TurtleFrostBreath, CombinedAttack, Death])
    
    **카메라·사운드·제작 원칙**
    
    - 카메라: 3인칭 백뷰. 콤보와 회피가 잘 보이고, 보스 공격 궤적이 읽히며, 되감기 연출이 화면 전체에서 느껴지게 한다.
    - SFX 연출 포인트(구체적 에셋 명세는 미정): 증기 발전기 폭주, 기계 괴수, 현무의 기계음, 패링 충격음, 과열 상승음, 되감기 시간 역행음, 신핵 처형, 해빙
    - 제작 원칙: 시간 되감기는 장식이 아니라 핵심 플레이 시스템, 패링→과열→고압 참격 구조 유지, 되감기는 플레이어만 되돌림, 오방색은 시스템 피드백의 시각 언어, 10분 데모는 세계관 설명보다 플레이 경험 우선, 확정되지 않은 수치는 팀 합의 후 결정
    
    **개발팀 초안의 미확정 항목**
    
    - 전투: 약·강공격 데미지, 콤보 단계 수, 공격 프레임, 패링 판정 프레임과 경직, 과열 상승·감소량, 과열 중 초당 체력 감소량
    - 되감기: 기록 주기, 정확한 복원 시점, 프레임 보간, 입력 중 무적 여부, 충돌 처리, 보스·적 AI와의 상호작용, 선견 잔상 구현 방식
    - 보스: 백동수 HP와 패턴별 데미지, 현무 HP와 가갑 HP, 현무 패턴 쿨타임, Phase 전환 HP, 즉사급 공격 판정
    - 데모: 컷신 길이, 카메라 타임라인, 오프닝 스킵 여부, 자동 리셋 시간, 입력 안내 UI
    
    **구현 구조 참고**
    
    - Player, Enemy, Boss, DemoManager 클래스 구조와 Player FSM(Idle, Move, Attack, Airborne, Dodge, Parry, Overheat, Rewind, Death), 백동수와 현무의 보스 FSM
    - MVP 우선순위: P0 이동, 공격, 콤보, 회피, 패링, 과열, 고압 참격, 되감기, 기본 적, 현무 1, 2페이즈, 신핵 QTE, 데모 타임라인 / P1 수묵 VFX, 카메라 연출, UI, SFX / P2 환경 디테일, 추가 컷씬
