## 퀘스트

목표 변경시 잠깐 표시, J키로 확인할 수 있도록.

어명을 받들라
라고 나타났다가 3~5초뒤 먹물 번지듯 사라지기

퀘스트 세부 내용 : 없다시피 한 수준으로 어디로 가라, 누구를 죽여라 같은 진행만 만들기. .

목표 발생 조건, 완료 조건, UI표시(J로 할지 체[크포인트에서 확인할지 완료처리어떻게할지)

예시) 이렇게 진행하면 될 거 같긴함

| 진행 단계 | 퀘스트 목표 |
| --- | --- |
| 시작 | 어명을 받고 궁궐을나선ㄷ |
| 일반 전투 | 적의 방어선을 돌파하라 |
| 장승 | 장승을 활성화하라 |
| 중간 보스 직전 | 백동수가 있는 곳으로 이동하라 |
| 중간보스전 | 백동수를 처치하라 |
| 종료 | 임무 완료 |

시연 흐름과 연관지어서 완성할 수 있도록.
