# 현무 (최종보스)

<aside>
📌

**기획자:** NMJ (v3), BHS

**구현 담당:** BHS

**상태:** 초안

**관련 결정:** D-002, D-007, D-030, D-031(대체됨), D-044

**한 줄 요약:** 1페이즈는 증기발도로 흑철 가갑 2장을 깨고, 2페이즈는 체력 300을 깎고 합동기를 시간 역행으로 넘긴 뒤 신핵 QTE로 끝내는 2분짜리 보스전.

</aside>

## 1. 목표

- 받아치기 → 증기 → 증기발도로 가갑 파괴 (끝까지 지키는 것)
- 합동기를 시간 역행으로 넘기기 (끝까지 지키는 것)

## 2. 규칙

- 보스는 현무 하나 (D-002)
- 향원정 안개문을 넘으면 보스 아레나 씬 로드

**1페이즈: 흑철의 가갑**

- 목표: 가갑 2장 파괴
- 가갑은 증기발도로만 부서짐
- 공략 순서: 흑철 찍기 받아치기 → 증기 +20 → 100 → Z(증기발도)
- 패턴: 흑철 찍기(동심원, 받아치기 가능), 꼬리 휩쓸기(적색 고리, 구르기)

**전환**

- 등이 갈라지며 뱀의 목이 솟음

**2페이즈: 쌍두의 폭주**

- 목표: 체력 300 깎기
- 패턴: 뱀의 목 찌르기(미래 잔상 + 동심원, 받아치기 가능), 냉기 브레스(청색 부채꼴, 구르기), 합동기 1회
- 합동기: 4초 충전 후 체력 90% 피해. 체력이 1 아래로 내려가지 않음. Q(시간 역행)로 넘김
- 합동기 직전 증기가 70 미만이면 바닥에 증기 구슬을 떨궈 채움
- 높이 있는 뱀 머리는 화승총으로도 맞힐 수 있음

**마무리: 신핵 QTE**

- F → Z → 좌클릭 → Q 순서 입력

## 4. 근거

- 흑철은 한 점에 몰린 고열에만 금이 감. 세계관 [법칙 6](../세계관/세계관.md)
- 뱀 머리는 시간을 다뤄서 공격 전에 미래 잔상이 먼저 도착함
- 면으로 오는 공격(꼬리, 브레스)은 받아칠 수 없음. 세계관 [법칙 7](../세계관/세계관.md)
