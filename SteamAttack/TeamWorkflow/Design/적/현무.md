<aside>
📌

**구현 담당:** BHS

**상태:** 구현 중

**관련 결정:** D-002, D-007, D-030, D-031(대체됨), D-044, D-063, D-067, D-071, D-072, D-079, D-080, D-087, D-093, D-097

**한 줄 요약:** 다리 4개를 부수면 넘어지고 등껍질 위로 코어가 솟는 유일한 보스. 돌진·근접 내려찍기·브레스와 시간 역행 전용 공격을 사용. 코어 공격·후속 페이즈 세부는 확인 필요.

## 1. 목표

- 시연 5분 중 보스전이 중심 (D-030)
- 받아치기 → 경직 → 강공격, 그리고 시간 역행으로만 피할 수 있는 공격을 보여줌 (D-072)
- 1페이즈 우선 완성. 완료 시점을 공유하고 후속 작업으로 넘김 (D-063)

## 2. 규칙

**확정**

- 보스는 현무 하나 (D-002)
- 향원정 안개문을 넘으면 보스 아레나 씬 로드
- 파츠별 부위파괴. 공격할 수 있는 부위는 붉은색으로 표시 (D-007)
- 다리 4개 파괴 → 넘어짐 → 코어가 등껍질 위로 솟아오름 (D-093). 등껍질 파괴로 노출하는 방식은 사용하지 않음. 코어 상승 방식은 2026년 10월 19일 YPH 추가 확인
- 1페이즈 우선 완성. 2페이즈는 1페이즈 완성 후 구체화 (D-063)
- 기본 패턴: 돌진, 근접 내려찍기, 브레스 (D-072)
- 원거리·광역 패턴 보완 (D-072)
- 시간 역행으로만 피할 수 있는 공격·필살기를 둠 (D-072)
- 받아칠 수 있는 공격의 예고 표시(동심원) 유지 (D-072). 받아칠 수 있는 패턴은 BHS가 고름 ([받아치기](../전투/패링.md))
- 받아치기 성공 시 공격 취소, 현무 경직. 약점 노출 없음 (D-067, D-068)
- 패턴 속도·범위는 인스펙터에서 조정 (D-072)
- 돌진에 측면 개방·로켓 전개·수납 애니메이션 연결 (D-072)
- 제외: 보스 공격 데칼, 페이즈 전환용 건물 파괴 연출 (D-079)

**압축기획안 v3의 패턴 구조 (공략 구조 재결정 중)**

아래는 미확정 세부를 포함한 v3 원안입니다. 증기발도 전용 가갑 파괴는 D-071로, 가갑 2장과 등껍질이 갈라지는 노출 방식은 D-093의 다리 4개·코어 상승 구조로 대체됐습니다. 남은 2페이즈·QTE 세부는 BHS가 확인합니다(D-080).

- 1페이즈 공격 후보: 흑철 찍기(받아치기 가능), 꼬리 휩쓸기(구르기). 실제 적용 패턴은 확인 필요
- 2페이즈 쌍두의 폭주: 체력 300. 뱀의 목 찌르기(받아치기 가능), 냉기 브레스(구르기), 합동기 1회(4초 충전, 체력 90%, 1 미만 불가, 시간 역행으로 넘김)
- 마무리 신핵 QTE: F → Z → 좌클릭 → Q

## 4. 근거

- 기능 마감(2026-10-18)이 가까워 1페이즈부터 완성 (2026-10-15 회의)
- 시간 역행을 체력 회복뿐 아니라 회피에도 쓰게 하려고 시간 역행 전용 공격을 둠 (D-072, D-073)
- 면으로 오는 공격(돌진, 브레스)은 받아칠 수 없음. 세계관 [법칙 7](../세계관/세계관.md)

## 7. 확인 필요

- **보스 공략 구조 (BHS):** 다리 4개 파괴·넘어짐·코어 상승은 D-093으로 확정. 코어 공격 방식·노출 시간·총기 사용 연계·후속 페이즈는 미정
- 일정 횟수 이상 피격 시 추가 경직을 주는 안이 제안됨. 채택 여부·횟수·경직 시간은 미정(2026년 10월 19일 회의)
- 현무 숨소리·발소리의 최종 파일과 재생 타이밍. 회의 중 후보 선호 의견은 최종 선정이 아님(D-097)
- 보스방 증기 회복 방식·수치 (BHS)
- 시간 역행 전용 공격·필살기 구성과 회피 타이밍 (BHS)
- 원거리·광역 패턴 형태·범위, 낙하·추적·분산 방식 (BHS)
- 2페이즈 패턴 강화·전환 연출 (1페이즈 완성 후)
- 받아칠 수 있는 패턴 선택
- 보스 체력 표시: 부위파괴·체력바 없음(D-007)과 2페이즈 체력 300
- 데칼 제외 후 받아칠 수 없는 공격의 바닥 예고(v3의 적색 고리·청색 부채꼴)를 어떻게 보일지
- 보스방 규모: 보스 모델 배치 후 크기·활동 공간 확인
- 피격 판정 태그를 공통 보스 태그로 정리 (BHS 작업, 2026-10-15)
- **다리 수 불일치:** 2026년 10월 16일 보고는 `BHS_Boss` 다리 2개와 `BossHealth.WallCount = 4`의 불일치. D-093의 다리 4개 구조에 맞춰 프리팹·판정·체력바 연결을 확인. 이번 문서 작업에서 구현 수정·검증은 하지 않음 (요청 `BHS_요청_20261016_보스다리수와체력기준.md`)
- 보스 체력바는 다리 이름 번호 순서로 칸을 연결함(D-087). 다리 이름: 4개면 `Leg_0_FL` `Leg_1_FR` `Leg_2_BL` `Leg_3_BR`, 2개면 `Leg_0_L` `Leg_1_R` (요청 `BHS_요청_20261016_보스다리이름번호.md`)
