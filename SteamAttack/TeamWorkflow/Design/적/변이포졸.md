# 변이 포졸

<aside>
📌

**기획자:** NMJ (v3), 행동 구조는 도끼병사 원안

**구현 담당:** YPH

**상태:** 초안

**관련 결정:** D-045

**한 줄 요약:** 한기에 삼켜진 창 든 포졸. 찌르기와 받아칠 수 있는 내려치기를 씀.

</aside>

## 1. 목표

- 가장 먼저 만나는 적
- 찌르기로 구르기, 내려치기로 받아치기를 연습시킴

## 2. 규칙

**행동 흐름**

대기 → 플레이어 감지 → 추적 → 사거리 진입 → 패턴 선택 → 공격 → 후딜레이 → 다음 행동

- 플레이어가 사거리 밖으로 나가면 다시 추적
- 공격 중에는 새 공격을 시작하지 않음

**패턴 1. 창 찌르기**

- 받아치기 불가. 구르기나 거리 벌리기로 대응

**패턴 2. 내려치기**

- 창을 크게 들어 내려침
- 창끝에 흰 동심원 표시
- 받아치기 가능
- 받아치기 성공 시 공격 취소, 자세 붕괴, 약점 노출

## 3. 수치

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 체력 | 50 | |
| 창 찌르기 피해 | 10 | |
| 내려치기 피해 | 15 | |
| 찌르기 : 내려치기 비율 | 70 : 30 | 초기값 (도끼병사 원안) |

## 4. 근거

- 한기에 삼켜져 의지 없이 움직이는 적. 세계관 [법칙 2](../세계관/세계관.md)

## 5. 연출·피드백

| 시점 | 화면(VFX·UI) | 소리(SFX) | 애니메이션 |
| --- | --- | --- | --- |
| 찌르기 | 타격 이펙트 | 미정 | Attack_Thrust |
| 내려치기 예고 | 창끝 흰 동심원 | 미정 | Attack_Heavy |
| 자세 붕괴 | 약점 노출 표시 | 미정 | Parried |
| 피격 | 피격 이펙트 | 피격음 | Hit |
| 사망 | 없음 | 미정 | Death |
