**한 줄 요약:** 길 위의 적 2종(변이 포졸, 흑수회 궁수)의 공통 규칙과 배치.

## 1. 목표

- 길에서 근접 액션, 받아치기, 화승총 사격을 차례로 익히게 함

## 2. 규칙

**종류 (D-045)**

| 종류 | 적 | 받아칠 수 있는 공격 |
| --- | --- | --- |
| 근접 | [변이 포졸](변이포졸.md) | 있음 (내려치기) |
| 원거리 | [흑수회 궁수](흑수회궁수.md) | 없음 |

- 두 적 모두 기본 공격 패턴만 둠. 쓸 수 있는 기존 모델·모션 사용 (D-074)

**공통**

- AI는 `YPH.EnemyAI`(`Scripts/YPH/Enemy/EnemyAI.cs`)를 사용
- 근접 적은 받아칠 수 있는 공격과 경직 모션을 반드시 가짐
- 받아치기 성공 시 공격 중단, 경직. 경직 동안 플레이어가 강공격을 넣을 기회 (D-068)
- 약점 노출·다음 공격 피해 증가 없음 (D-068)

**체력바**

| 상황 | 동작 |
| --- | --- |
| 피해를 줌 | 거리와 관계없이 표시 |
| 카메라 밖 | 숨김 |
| 다시 화면에 들어옴 | 다시 표시 |
| 벽·장애물에 가려짐 | 숨김 |
| 사망 | 숨김 |
| 전투·추적 종료 | 숨김 |

## 3. 수치

**배치**

| 구간 | 근접 | 원거리 |
| --- | --- | --- |
| 육조거리 | 3 (근접 2 → 원거리 1 → 근접 1 순서) | 1 (관아 지붕 위) |
| 광화문 앞 | 3 | 1 (해태 뒤) |
| 궁 안 | 2 (선택) | 0 |

- 스폰 위치 후보: Main 맵의 `13_인물 / 변이병`, `흑수회 광신도` 배치 위치

## 4. 근거

- 육조거리 마지막 근접 1명은 받아치기 가능한 내려치기를 써서 첫 받아치기를 반드시 보게 함

## 7. 확인 필요

- 받아치기 공통 규약(`YPH.IParryTarget`, `YPH.ParryTargets`)은 YPH가 만듦. 플레이어 받아치기도 YPH가 새로 구현하고(D-065), 옛 `NGH.PlayerParry` 정리·패링 모션은 NGH, 현무 규약 구현은 BHS에 요청함
- 경직 시간: 플레이어 강공격이 들어갈 만큼. 강공격 실행 시간이 정해지면 맞춤
- 적 에셋: 애니메이션·의상(Cloth) 문제, 멘토 자료 공유 여부, 에셋 구매·도구 선택 미정 (2026-10-15 회의)
- 담당: 적 모델링·AI YPH (D-036)
- 늦어지면 버리는 순서: 궁 안 잡몹 → 원거리 잡몹
