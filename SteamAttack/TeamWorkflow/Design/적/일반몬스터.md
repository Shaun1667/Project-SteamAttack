# 일반 몬스터

<aside>
📌

**기획자:** CHG, NMJ

**구현 담당:** YPH

**상태:** 초안

**관련 결정:** D-033, D-045, D-052

**한 줄 요약:** 길 위의 적 2종(변이 포졸, 흑수회 궁수)의 공통 규칙과 배치.

</aside>

## 1. 목표

- 길에서 근접 액션, 받아치기, 화승총 사격을 차례로 익히게 함

## 2. 규칙

**종류 (D-045)**

| 종류 | 적 | 받아칠 수 있는 공격 |
| --- | --- | --- |
| 근접 | [변이 포졸](변이포졸.md) | 있음 (내려치기) |
| 원거리 | [흑수회 궁수](흑수회궁수.md) | 없음 |

**공통**

- AI는 `YPH.EnemyAI`(`Scripts/YPH/Enemy/EnemyAI.cs`)를 사용
- 근접 적은 받아칠 수 있는 공격과 자세 붕괴 모션을 반드시 가짐
- 받아치기 성공 시 공격 중단, 자세 붕괴, 약점 노출

**체력바**

| 상황 | 동작 |
| --- | --- |
| 피해를 줌 | 거리와 관계없이 표시 |
| 카메라 밖 | 숨김 |
| 다시 화면에 들어옴 | 다시 표시 |
| 벽·장애물에 가려짐 | 숨김 |
| 사망 | 숨김 |
| 전투·추적 종료 | 숨김 |

## 3. 수치

**배치**

| 구간 | 근접 | 원거리 |
| --- | --- | --- |
| 육조거리 | 3 (근접 2 → 원거리 1 → 근접 1 순서) | 1 (관아 지붕 위) |
| 광화문 앞 | 3 | 1 (해태 뒤) |
| 궁 안 | 2 (선택) | 0 |

- 스폰 위치 후보: Main 맵의 `13_인물 / 변이병`, `흑수회 광신도` 배치 위치

## 4. 근거

- 육조거리 마지막 근접 1명은 받아치기 가능한 내려치기를 써서 첫 받아치기를 반드시 보게 함

## 7. 확인 필요

- 받아치기 훅(동심원 예고, 자세 붕괴, 약점 노출)은 `YPH.EnemyAI`에 이미 있음(CHG 원작). 플레이어 쪽 `NGH.PlayerParry`가 `YPH.EnemyAI`만 찾아서 현무는 받아치기 대상이 아님. 보스까지 묶는 공통 규약 필요
- 담당: 적 모델링·AI YPH (D-036)
- 늦어지면 버리는 순서: 궁 안 잡몹 → 원거리 잡몹
