## 확인 필요 (회의 안건 후보)

### [프로젝트 (범위·일정·담당)](../Design/00_프로젝트.md)

- **공용 플레이어 프리팹이 어느 것인지:** NMJ 브랜치에서 Main·BossArena 씬의 플레이어를 `YPH_HeroPlayerIntegration`(안에 `NGH_Player`)으로 바꿈(2026-10-16 NMJ 알림). D-081·D-083은 `NGH_Player.prefab`을 기준으로 소유를 정함. 병합 후 어느 프리팹이 공용인지, NMJ가 프리팹에 붙인 HUD(D-086)와 YPH 받아치기 작업이 겹치지 않는지 확인
- 발도·납도는 F로 확정(D-095). 기존 F 상호작용·신핵 QTE와 겹칠 때의 입력 우선순위·대체 키는 [기본조작](../Design/전투/기본조작.md)에서 확인
- 동적 폰트 `Fonts/NGH/NotoSerifKR SDF Hanja (Dynamic).asset`이 플레이할 때마다 바뀌어 커밋 충돌이 남. 이 파일 변경을 커밋하지 않을지, 고정(Static) 폰트로 바꿀지 협의 (NMJ 제안. NMJ HUD는 전용 고정 폰트로 옮김)
- UI·환경 설정·엔딩의 세부 구현 담당은 확인 필요(D-080). 개발자 창은 NMJ로 확정(D-098)
- 10월 19일 후속 작업 중 발언자 이름이 명확하지 않은 배정: 락온 제거, 프롤로그 반복 수정, Cloth·대체 소매, 허수아비. 회의록의 논의·작업·확인 표 참고
- 에셋 3~4개 구간의 경계·개별 담당과 공용 씬 인계 시점(D-092)
- 추가 기능 채택 여부: 중간 보스 추가, 강공격 차지 입력, 조작키 안내·키 재지정 (2026-10-15 회의 미정)
- 보스 태그: BHS가 피격 판정 태그를 공통 보스 태그로 정리하기로 함 (2026-10-15). 아래 태그 정리 안건과 함께 확인
- 태그(D-013) 정리: `TagManager`에 결정에 없는 `PlayerLongAttack`이 있음. BHS `DummyBullet`이 등록되지 않은 `BossWall` 태그를 씀. 두 태그를 정식 목록에 넣을지 회의에서 정함
- D-015의 "프로토타입 이후 CHG↔NGH 파트 교체 여부": CHG가 팀에 없어 D-036으로 정리된 것으로 보임. 다음 회의에서 D-015 상태를 `대체됨→D-036`으로 바꿀지 확인

### [디버깅 메뉴·시연자 도구](../Design/UI/디버깅메뉴.md)

- 개발자 창 호출 버튼·키. 메뉴 구성은 D-098로 확정

- 구역 리젠 시 퀘스트·트리거·보스 페이즈의 초기화 범위와 플레이어 위치 처리
- 지금 `NGH.TimeRewind` 디버그 표시가 기본 켜짐이라 NMJ 퀘스트 디버그 안내와 왼쪽 위에서 겹침 (요청 `NGH_요청_20261016_디버그표시기본끄기.md`)

- 키 충돌 정리: 0, 1~4, F9~F11 (위 예약표 `충돌` 칸). 누가 어느 키로 옮길지 회의에서 정함

### [아웃게임](../Design/UI/아웃게임.md)

- 사망 후 그 자리에서 재개(D-099). 자동·수동 여부와 회복 수치는 [시연 흐름](../Design/월드/시연흐름.md)의 확인 필요 항목. 사망 화면 팁 없음
- 엔딩 세부: 처치 문구 표시 시간, 크레딧 전환, 종료 후 이동 화면 (NMJ, D-080). 클리어 화면을 둘지 함께 정함. 실명 표기는 D-096으로 확정
- ESC 메뉴에서 "계속하기"·"조작법"이 빠짐(D-076). ESC를 다시 누르면 닫히는지 확인
- ESC 키 충돌: 지금 `NGH.ControlsOverlay`가 ESC로 조작 안내 이미지를 열고 게임을 멈춤. NMJ 제안은 ESC 메뉴 안에 "조작법" 버튼을 두고 거기서 조작 안내를 띄우기. ESC 메뉴 구현 담당이 정해지면 함께 정리
- UI·환경 설정·엔딩 구현 담당: 주말 작업 후 회의에서 배정 (D-080)
- 담당: UI 디자인 NMJ (D-036)

### [인게임 UI](../Design/UI/인게임UI.md)

- 등 가방의 증기 표시(유리형)와 HUD 실린더의 역할 나누기 (YPH·NMJ)
- 안내 문구 표시 시간

- 현무 숨소리·발소리의 최종 파일과 재생 타이밍. 회의 중 후보 선호 의견은 최종 선정이 아님(D-097)
- 보스방 증기 회복 방식·수치 (BHS)
- 시간 역행 전용 공격·필살기 구성과 회피 타이밍 (BHS)
- 원거리·광역 패턴 형태·범위, 낙하·추적·분산 방식 (BHS)
- 2페이즈 패턴 강화·전환 연출 (1페이즈 완성 후)
- 받아칠 수 있는 패턴 선택
- 보스 체력 표시: 부위파괴·체력바 없음(D-007)과 2페이즈 체력 300
- 데칼 제외 후 받아칠 수 없는 공격의 바닥 예고(v3의 적색 고리·청색 부채꼴)를 어떻게 보일지
- 보스방 규모: 보스 모델 배치 후 크기·활동 공간 확인
- 피격 판정 태그를 공통 보스 태그로 정리 (BHS 작업, 2026-10-15)
- **다리 수 불일치:** 2026년 10월 16일 보고는 `BHS_Boss` 다리 2개와 `BossHealth.WallCount = 4`의 불일치. D-093의 다리 4개 구조에 맞춰 프리팹·판정·체력바 연결을 확인. 이번 문서 작업에서 구현 수정·검증은 하지 않음 (요청 `BHS_요청_20261016_보스다리수와체력기준.md`)
- 보스 체력바는 다리 이름 번호 순서로 칸을 연결함(D-087). 다리 이름: 4개면 `Leg_0_FL` `Leg_1_FR` `Leg_2_BL` `Leg_3_BR`, 2개면 `Leg_0_L` `Leg_1_R` (요청 `BHS_요청_20261016_보스다리이름번호.md`)

### [원거리 무기 (증기 격발 화승총)](../Design/전투/원거리무기.md)

- 줌은 채택(D-101, D-102). 시야각·확대량·전환 시간·감도 감소 수치는 미정
- 조준 UI 레퍼런스와 가장자리 흐림 표현. 위 딤드 수치는 기존 시안이며 새 UI의 확정 수치가 아님
- 이동 중 조준할 때 몸 회전·옆걸음 처리와 조준 해제 후 회전 복귀
- 발사 비용 10(D-040)과 임시 5 중 확정값
- 발사할 때 증기를 내는 방식은 YPH 브랜치에 적용됨(A1, 2026-10-15). NMJ 브랜치(10/13 기준)에는 옛 R 충전 코드가 남아 있음. 비용 5는 S1에서 적용 (요청 `YPH_요청_20261016_화승총발사당증기.md`)
- 화승총을 들고 받아칠 때 발사 비용을 내는지 (D-067 "화승총 발사 비용은 따로"가 D-082 이후에도 적용되는지)
- 담당: 원거리 YPH (D-036)

### [증기 시스템](../Design/전투/증기시스템.md)

- 증기가 부족할 때의 피드백. 강공격이 안 나갈 때 포함 (NMJ)
- 칼 일반 공격 적중 회복량. 2026년 10월 19일 회의는 시작량 0만 확정했으며 +10을 새 확정값으로 정하지 않음
- 중복 가방 중 남길 오브젝트와 씬·프리팹 참조. 통합 후 HUD·칼 회복·시간 역행 동작 확인(D-100)
- 사망 후 제자리 재개 시 증기 유지·초기화 수치(D-099)
- 화승총 발사 비용: 기존 결정 10(D-040)과 회의 임시값 5 중 어느 쪽을 쓸지. 지금은 임시 5
- 화승총을 들고 받아칠 때 발사 비용을 내는지, 실패했을 때도 내는지 (D-067과 D-082)
- 등 가방의 증기 잔량 표시와 HUD 실린더 게이지의 역할 나누기 (YPH·NMJ)

### [받아치기 (패링)](../Design/전투/패링.md)

- 화승총을 들고 받아칠 때 화승총 발사 비용을 내는지. 10.15 회의는 "화승총 발사 비용은 따로", 이후 받아치기는 들고 있는 무기로 바뀜(D-082)
