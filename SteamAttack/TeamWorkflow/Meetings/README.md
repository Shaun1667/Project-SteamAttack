# 회의록과 결정 로그

- 회의록은 [회의록 템플릿](../Templates/회의록_템플릿.md)으로 `YYYY-MM-DD_제목.md`를 만듭니다. **작성 후에는 고치지 않습니다**(오타 제외). 바뀐 결정은 다음 회의록에 새 결정으로 남깁니다.
- **회의 반영은 YPH가 합니다.** 회의가 끝나면 결정을 아래 **결정 로그**에 한 줄씩 추가하고 `반영 기획서` 칸에 고칠 문서를 적습니다. `미반영`은 쓰지 않습니다. 기능이 아닌 결정(범위·일정·빌드·담당)은 [프로젝트](../Design/00_프로젝트.md), 코드 규칙은 `Rules/`로 보냅니다.
- **기획서는 그 문서의 구현 담당이 고칩니다**(미정이면 NMJ). **서기 YPH는 담당과 관계없이 모든 기획서를 고칠 수 있습니다**(D-085). 고칠 결정은 [현황](현황.md)의 `반영 대기`에 자동으로 나타납니다. 반영하면 기획서 `변경 이력`에 D-번호를 적고, 그러면 대기 목록에서 사라집니다.
- 옛 결정을 뒤집을 때는 옛 줄을 지우지 않고 상태를 `대체됨→D-0xx`로 바꿉니다.
