## 1. 제외 항목 (확정)

- 보스 공격 데칼 기능
- 백동수(중간보스)
- 시연용 체크포인트·불러오기 기능
- 페이즈 전환용 건물 파괴 연출

## 2. 논의 사항

- **개발 순서:** 이번 주 주말까지 기능 구현 우선. 애니메이션·이펙트·맵 디테일은 그 후 보완. 불필요한 시스템 축소
- **핵심 유지:** 시간 역행을 쓰는 핵심 전투 기능 유지. 시간 역행은 체력 회복 외 회피에도 활용
- **보스 순서:** 1페이즈 우선 완성. 완료 시점 공유 후 후속 작업 연결
- **개발자 도구:** 기능 구현 후 QA·버그 수정 단계에 추가
- **받아치기 담당:** YPH가 플레이어 패링·적 공통 인터페이스 구현, 공용 플레이어 프리팹 수정 후 패링 가능한 상태로 NGH에게 인계. NGH는 인계 후 근접 전투·패링 모션
- **받아치기 구현 원칙:** 근거리·원거리 하나의 시스템·공통 규칙. 기획과 맞지 않는 기존 패링 코드는 다시 구현. 쓸 수 있는 기존 애니메이션 재사용. 적 AI의 기존 호출 방식 유지. 바꿔야 할 부분은 요청 문서로
- **증기:** 칼 일반 공격 적중 시 회복. 화승총은 발사 시 소모, 명중 시 회복 없음
- **강공격:** 증기 소모형 강한 공격. 선딜 있음. 받아치기 후 안정적으로 쓰는 공격. 특수 기술·과열은 별도 시스템 없이 강공격으로 통합
- **받아치기 규칙:** Ctrl. 대상은 일반 적 강공격과 보스 일부 패턴. 성공 시 적 공격 무효, 적 경직, 경직 중 강공격 기회. 성공 시 증기 회복·추가 소모 없음(화승총 발사 비용은 따로). 성공 피드백은 시각 이펙트·효과음
- **받아치기 실패:** 타이밍이 안 맞으면 정상 피해. 빠름·늦음 구분 없음. 실패 시 증기 차감은 기능만 임시 구현, 지금 플레이에는 미적용
- **받아치기 판정:** 판정 시점 전후 허용 폭으로 판정
- **받아치기 보상:** 적 경직과 강공격 기회만. 약점 노출·다음 공격 피해 증가 보상 제외
- **보스 패턴:** 돌진·근접 내려찍기·브레스 기본 패턴 완성. 원거리·광역 패턴 보완. 시간 역행으로만 피할 수 있는 공격·필살기 마련. 받아칠 수 있는 공격의 예고 표시 유지. 패턴 속도·범위는 인스펙터에서 조정
- **보스 애니메이션:** 돌진에 측면 개방·로켓 전개·수납 연결. 기존 애니메이션 연결 문제 보완
- **보스 태그:** BHS가 피격 판정 태그를 공통 보스 태그로 정리
- **일반 적:** 창을 쓰는 근접형 적과 궁수. 기본 공격 패턴. 쓸 수 있는 기존 모델·모션 사용
- **맵:** 기존 맵의 큰 틀 유지, 내부 배치·동선 보완. 길 차단·바위·소품은 기능 구현 후. Blender에서 지형과 개별 오브젝트를 나눠 가져오기
- **UI·환경 설정:** 타이틀(게임 시작 / 환경 설정 / 게임 종료). 인게임 ESC 메뉴(타이틀로 / 환경 설정 / 게임 종료), 열면 일시정지. 환경 설정은 소리(마스터 / 배경음 / 효과음, 마스터 기본 70), 게임(마우스 감도), 화면(해상도 / 전체 화면·창 모드)
- **사망 연출:** 종이가 타듯 군데군데 사라지는 소멸 셰이더 우선. 어려우면 다른 방식으로
- **보스 처치·엔딩:** 보스 처치 시 문구 출력(예: `Boss Eliminated`). 시연의 시작·끝을 분명히 구분. 엔딩 크레딧 마련
- **개발자 도구(개발자 루트):** 버튼 하나로 개발자 창 열기, 창 안에서 클릭으로 기능 조절, 보스전 등 지정 구간으로 바로 이동

## 4. 컨셉·근거

- 기능 마감이 2026년 10월 18일이라 디테일보다 기능을 먼저 끝내야 한다.
- 받아치기 보상을 경직 후 강공격 기회 하나로 줄여 규칙을 단순하게 하고 싶었다.
- 과열·특수 기술을 따로 만들 시간이 없어 강공격 하나로 합쳤다.

**담당자가 정할 것**

- BHS: 보스방 증기 회복 방식·수치
- BHS: 보스 공략 구조. 다리·무릎 공략과 넘어짐의 관계, 코어 공격·총기 사용 연계
- BHS: 시간 역행 전용 공격·필살기 구성과 회피 타이밍
- BHS: 원거리·광역 패턴 형태·범위, 낙하·추적·분산 방식
- BHS: 2페이즈 패턴 강화·전환 연출 (1페이즈 완성 후)
- NMJ: 시연 재시작. 자동·수동 여부, 버튼 구성, 부활 위치·재개 흐름
- NMJ: 엔딩 세부. 처치 문구 표시 시간, 크레딧 전환, 종료 후 이동 화면
- NMJ: UI·증기 게이지 최종 시안. 후보는 실린더형 용기, 흰색 증기·어두운 빈 영역, 선명한 테두리
- YPH: 등 가방의 증기 표시. 내부가 보이는 유리형 가방에 증기 잔량을 보일지 검토

**후속 회의·추가 확인**

- UI·환경 설정·엔딩·개발자 도구 구현 담당 (주말 작업 후 회의)
- 개발자 도구 세부: 창 호출 버튼·키, 창 안 메뉴
- 보스방 규모: 보스 모델 배치 후 크기·활동 공간 확인
- 사망 연출 디테일: 색상·파티클·재시작 연결
- 일반 적 에셋: 애니메이션·의상(Cloth) 문제, 멘토 자료 공유 여부, 에셋 구매·도구 선택
- 추가 기능 채택 여부: 중간 보스 추가, 강공격 차지 입력, 조작키 안내·키 재지정

**정리하며 발견한 충돌**
